# 컨셉 안 P0 수정안 — F1·F2

대상: [`concept.md`](concept.md) · 근거: [`concept-review.md`](concept-review.md) F1·F2 · 작성 2026-09-21

**`concept.md`는 고치지 않았다.** 무편집 보존이 이 프로젝트의 규칙이라 수정안을 패치 문서로 낸다.
아래 아홉 개 패치는 각각 독립이라 부분 채택이 가능하다. 승인되면 그때 `concept-v2.md`로 합친다.

줄 번호는 현재 `concept.md` 기준이며 전부 실물 대조했다. 원문 문체(한 문장 한 줄, 빈 줄로 띄우기)를 따랐다.

## 이번 수정이 하는 일

**F1** — 작품의 훅이 딛고 설 바닥을 깐다. 지금 §5의 공식 역사는 "인류는 대규모 탈출을 감행한다"다.
탈출한 문명이라면 못 떠난 사람이 남은 것은 당연하고, 11시간 뒤 아이 목소리는 슬프긴 해도 놀랍지 않다.
공식 역사가 **"18시 이후 지구에 살아 있는 인간은 없었다"**를 명시적으로 주장하게 바꾼다.

새 설정은 만들지 않는다. 이미 있는 JANUS PROTOCOL 1항(데이터 연결 차단)과 2항(기록 삭제)만으로 푼다.
**18시에 끊긴 것은 사람이 아니라 관측이었다.** 우주는 관측이 멈춘 것을 죽음으로 읽었고, 그렇게 기록했다.

**F2** — 레이의 나이를 없앤다. 현재 2335년(2198+137)과 131년 전 사진 사이의 모순은 "31세"라는 숫자
하나에서만 나온다. 그 숫자를 빼면 모순을 풀 필요가 없어진다. 대신 **공백을 명시한다** — 다른 인물은
나이가 다 적혀 있어서 그냥 지우면 다음 작업자가 빠진 줄 알고 채워 넣는다.

# F1 — 공식 역사가 11시간의 충격을 만들게 한다

## P1-1 · `concept.md:118~122` — §5 공식 역사에 사망 시각을 박는다

**before**

```
인류는 대규모 탈출을 감행한다.

이것이 현재 학교에서 가르치는 역사다.

> “인간이 AI에게 너무 많은 권한을 넘긴 결과 지구가 멸망했다.”
```

**after**

```
탈출은 그 전부터 이미 몇 년째 진행 중이었다.

떠날 수 있는 사람은 떠났고, 떠나지 못한 사람이 남았다.

그리고 2198년 7월 17일 18시.

지구 전역의 관측·통신·생체 신호가 동시에 끊겼다.

인류는 그 시각을 지구의 사망 시각으로 확정했다.

이것이 현재 학교에서 가르치는 역사다.

> “인간이 AI에게 너무 많은 권한을 넘긴 결과 지구가 멸망했다.
> 18시 이후 지구에 살아 있는 인간은 없었다.”
```

**왜** — 인용문의 둘째 줄이 이 작품의 훅 전체를 떠받친다. 이 한 줄이 없으면 11시간 뒤의 목소리는
그저 "못 떠난 사람이 있었구나"로 읽힌다. 있으면 **물리적으로 존재할 수 없는 기록**이 된다.
탈출을 ZERO FALL 이전으로 분리한 것도 같은 이유다 — 탈출과 사망 시각이 같은 순간이면 둘이 서로를 흐린다.

## P1-2 · `concept.md:180~184` — §5 진실에 여섯 번째 사실을 더한다

**before**

```
### 지구에 존재했던 상당수의 디지털 기록을 의도적으로 파괴한다.

지구는 AI에게 멸망한 것이 아니다.

**인류가 스스로 지구를 봉인했다.**
```

**after**

```
### 지구에 존재했던 상당수의 디지털 기록을 의도적으로 파괴한다.

그리고 아무도 말하지 않은 여섯 번째 사실이 있다.

18시에 끊긴 것은 사람이 아니었다.

1항과 2항이 동시에 걸리면서 지구에서 우주로 나가는 신호가 그 시각에 전부 멈췄다.

관측이 끊긴 것이다.

우주는 그것을 죽음으로 읽었다.

그리고 그렇게 기록했다.

지구는 AI에게 멸망한 것이 아니다.

**인류가 스스로 지구를 봉인했다.**

그리고 봉인 안쪽에 사람이 있었다는 사실을 지웠다.
```

**왜** — 이 작품에서 가장 중요한 설정 수정이다. 새 장치를 하나도 도입하지 않고 **이미 적혀 있는
JANUS PROTOCOL 1·2항**만으로 "왜 공식 역사가 틀렸는데 아무도 모르는가"를 설명한다.
마지막 한 줄이 §15의 폭로("ZERO FALL 당시 지구인은 즉시 죽지 않았다")와 정확히 맞물린다.

## P1-3 · `concept.md:457~461` — §10-⑤ GROUNDERS의 기원을 확정한다

**before**

```
## ⑤ GROUNDERS

지구에서 살아가는 인간들.

공식적으로는 존재하지 않는다.
```

**after**

```
## ⑤ GROUNDERS

지구에서 살아가는 인간들.

대부분은 ZERO FALL 이후에 내려가 눌러앉은 밀입국자와 그 후손이다.

사냥꾼들은 그들이 있다는 걸 안다.

공식 기록에 없을 뿐이다.

그런데 그중 일부는 자기 가계가 ZERO FALL 이전까지 끊기지 않고 이어진다고 주장한다.

아무도 믿지 않는다.
```

**왜** — 지금 상태로는 "지구에 사람이 산다"가 세력 목록에 이미 있어서 11시간의 폭로가 김이 샌다.
기원을 **멸망 이후 이주민**으로 못 박으면 원주 생존자와 구별되고 훅이 산다.
마지막 두 줄은 EP.10이 회수할 씨앗이다 — 설정이 아니라 **소문**으로 심어야 회수될 때 값이 난다.

## P1-4 · `concept.md:822~830` — EP.10을 P1-3의 회수 지점으로 바꾼다

**before**

```
## EP.10 — EARTHBORN

레이 일행은 처음으로 지구에서 태어난 인간을 만난다.

그녀는 우주인을

‘하늘 사람’

이라고 부른다.
```

**after**

```
## EP.10 — EARTHBORN

레이 일행은 GROUNDERS를 만난다.

그중 한 명의 가계가 ZERO FALL 이전까지 끊기지 않고 이어진다.

밀입국자의 후손이 아니다.

봉인 안쪽에서 살아남은 사람의 후손이다.

그녀는 우주인을

‘하늘 사람’

이라고 부른다.

공식 역사가 틀렸다는, 처음으로 살아 있는 증거다.
```

**왜** — 원문의 "처음으로 지구에서 태어난 인간"은 GROUNDERS가 존재하는 세계에서 성립하지 않는다.
이미 지구에서 태어난 사람들이 있기 때문이다. 조건을 **혈통의 연속**으로 바꾸면 '처음'이 진짜 처음이 되고,
EP.10이 세계관 관광에서 **메인 미스터리의 증거 회차**로 승격한다.

## P1-5 · `concept.md:676` — §14가 공식 역사를 정확히 인용하게 한다

**before**

```
에 발생했다고 기록돼 있다.
```

**after**

```
에 발생했다고 기록돼 있다.

그리고 그 시각 이후 지구에 살아 있는 인간은 없었다고 기록돼 있다.
```

**왜** — 한 줄이지만 §14가 미스터리를 제시하는 자리다. 공식 주장과 녹음 타임스탬프가 **같은 문단 안에서**
충돌해야 독자가 계산한다.

## P1-6 · `concept.md:980` — 1화 독자에게 충격의 근거를 준다

**before**

```
MORROW:

> “ZERO FALL 이후 11시간입니다.”

그리고 스피커에서 어린 여자아이의 목소리가 들린다.
```

**after**

```
MORROW:

> “ZERO FALL 이후 11시간입니다.”

잠시 뒤.

> “그 시각엔 지구에 살아 있는 사람이 없었습니다.”

그리고 스피커에서 어린 여자아이의 목소리가 들린다.
```

**왜** — 1화 독자는 §5를 읽지 않았다. "11시간 뒤"라는 말만으로는 그게 왜 불가능한지 모른다.
MORROW의 무표정한 어조가 설명을 감정 없이 통과시킨다 — 인물이 놀라면 독자가 대신 놀랄 자리가 없어진다.

**그 뒤는 한 글자도 건드리지 않는다.** "엄마." / 잠시 침묵 / "하늘에서 또 목소리가 들려." / CUT.
리뷰가 축14의 모범으로 지목한 대목이다.

# F2 — 레이의 나이를 없앤다

## P2-1 · `concept.md:485` — 나이를 지우고 공백을 명시한다

**before**

```
### 레이 한 / RAY HAN

31세.
```

**after**

```
### 레이 한 / RAY HAN

나이 — 기록 없음.

사냥꾼 등록증에는 나이 칸이 있다.

레이의 칸은 비어 있다.

레이 자신도 왜인지 모른다.
```

**왜** — 131년 모순은 "31세"라는 숫자 하나에서만 나온다. 빼면 모순이 사라진다.
다만 미나 29세·JUN 37세·SOL 24세는 나이가 적혀 있어서 **그냥 지우면 누락으로 읽힌다.**
공백을 명시해야 다음 작업자가 채워 넣지 않는다.

덤으로 얻는 것이 있다. MORROW의 소개가 이미 "나이는 알 수 없다"다. 레이가 같은 줄에 서면
MORROW의 집착 질문 — "기억이 복사될 수 있다면 원본 인간은 누구인가" — 이 레이를 겨냥하게 된다.
§19의 주제가 주인공 본인에게 적용된다.

## P2-2 · `concept.md:556` — 지워진 것이 기억만이 아님을 심는다

**before**

```
12살 이전 기억 대부분이 사라져 있다.
```

**after**

```
12살 이전 기억 대부분이 사라져 있다.

그 12살이 언제였는지도 모른다.

사진이 정말 131년 전 것이라면, 지워진 것은 기억이 아니라 나이다.
```

**왜** — P2-1이 만든 공백을 여기서 회수한다. 나이를 없애는 것만으로는 독자가 그냥 넘어간다.
**공백이 의도라는 신호**가 한 번은 문서 안에 있어야 한다.

## P2-3 · `concept.md:698` — §14 끝에 두 번째 질문을 세운다

**before** (§14 마지막 줄, 그 뒤는 `# 15.`)

```
그 목소리가 인간의 목소리라는 것이다.
```

**after**

```
그 목소리가 인간의 목소리라는 것이다.

그리고 시즌1이 여는 질문은 하나가 아니다.

레이의 사진은 131년 전에 찍혔다.

사진 속 아이는 레이다.

이것은 오타가 아니다.
```

**왜** — 이 문서에서 **가장 중요한 한 줄은 "이것은 오타가 아니다"**다.
131년 격차를 문서가 의도로 선언하지 않으면 콘티·작화 담당이 단순 실수로 처리해 고쳐 버린다.
시즌1 최종 반전(사진 속 여성 = JANUS 책임자 = 레이의 어머니)이 이 숫자 위에 서 있다.

## 이 수정안이 닫지 않는 것

**F5 — 연대 산술.** 2198 + 137 = **2335년**이고 이것은 24세기인데 §4는 "시대는 약 25세기"라고 적는다.
§6-②에도 "25세기의 인터넷"이 한 번 더 나온다. 나이를 없애도 이 충돌은 그대로 남는다.
P1 등급이라 이번 범위가 아니다. 고칠 때는 "약 24세기"로 두 곳을 바꾸는 것이 가장 싸다 —
137년과 2198년은 여러 곳에 박혀 있어 움직이면 파급이 크다.

나머지 P1(F3 ECHO와 유물 경제의 단절, F4 JANUS 통과 규칙)과 P2 다섯 건은
[`concept-review.md`](concept-review.md)에 그대로 남아 있다.
