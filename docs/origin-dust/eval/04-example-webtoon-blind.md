# 04 — 블라인드 채점 시연: 웹툰 트랙

[`00-rubric.md`](00-rubric.md) §5(웹툰 축 11~14)를 실제로 돌린 기록이다. 세 개의 회차 도입 콘티를
라벨을 가린 채 채점했다. 샘플 C가 이 문서의 핵심이다 — **훅은 서지만 연출이 무너지는 중간 원고**,
현장에서 가장 자주 나오는 형태다.

## 2. 채점 전 측정 (M1·M2·M3)

**M1 회수 문장**
- A: "어떤 세계에서 종족들이 먼지를 두고 싸운다." → 계약의 약속 문장과 **불일치**. 지운도 장갑도 회수되지 않음 → 축1 상한 4.
- B: "지운의 장갑을 어젯밤 누군가 끼고 갱도에 들어갔고, 갱도 벽에 그의 이름이 새겨져 있었다." → 일치.
- C: "지운이 장갑이 젖은 걸 이상해하다가 갱도에 들어갔다." → 약속의 절반만 회수. 어둠 속의 눈은 남지 않음.

**M2 이탈 표시**
- A: [01], [02], [03] — **3곳**(3컷짜리 발췌 전부) → 축10 상한 3.
- B: 없음 — **0곳**.
- C: [03] 내레이션 중간, [05] 말풍선 중간, [41]~[43] 반복 구간 — **3곳** → 축10 상한 3.

**M3 화자 가리기**
- A: 대사 0, 내레이션만 → 축8 1점(인물의 목소리 자체가 없음).
- B: 3줄 중 2줄 적중(67%). 직원과 지운의 말끝이 갈리나 표본이 적음 → 게이트 미발동, 3.
- C: 4줄 중 1줄 적중(25%) — 지운이 혼잣말·질문·설명을 모두 같은 톤으로 한다 → **게이트 발동, 축8 상한 3**.

## 4. 축별 근거

**축1 훅** — A: 조감도 + 연호. 3컷 안에 어긋나는 것 없음(게이트) + M1 불일치. B: [01] 비어 있는 손가락 두 개, [04]~[05] 등록증 모순. 5컷에 훅 완성(운영 기준 15컷 이내). C: 같은 물증으로 열지만 [02] "어? 분명히"가 독자보다 먼저 놀라 긴장을 가져가 4.

**축2 장면성** — B: 감정어 0. [05] "표정 없음"이 표정을 그리게 한다. C: [03] 내레이션이 독자가 할 추론을 대신 해 버린다("그것은 곧 …라는 뜻이었다"). 물증은 좋은데 해설이 덮었다 → 3.

**축5 정보 격차** — B: [05]에서 질문을 열고 [79]까지 닫지 않는다. C: [03]에서 열자마자 같은 컷에서 닫았다. A: 격차 대신 설정을 쏟았다 — 고유명사 5개(먼지력·세이렌·카르한·남부 갱도·채굴 연합), 게이트 발동.

**축8 대사** — A: 대사 없음, 인물 목소리 부재 → 1. C: [05] 한 풍선 62자, [43] "내가 헛것을 봤나"는 독자에게 하는 설명. M3 25% 게이트 → 상한 3, 실제 2.

**축10 계속 읽힘** — M2 결과 반영. C는 [41]~[43] 세 컷이 같은 정보를 반복해 이탈 구간을 만든다.

**축11 컷 분할** — B: [33] 소등, [35] 눈 — 결정적 순간이 각각 독립 컷. C: [40]에 소등·넘어짐·눈 뜨기 세 사건이 겹침(게이트 발동) → 상한 3.

**축12 스크롤 연출** — B: 여백 2·6·4가 박자를 만든다. 특히 [33] 뒤 여백 6이 어둠을 스크롤 시간으로 바꾼다. C: 여백 0회(게이트 발동), [41]~[43] 컷 높이 균일 → 3. A: 여백 0회 → 2.

**축13 그림-글 분업** — C: [04] "비가 내리는 아침이었다"는 그림이 이미 말한 것(게이트 후보 1), [03]·[05] 말풍선이 운영 기준 40자를 크게 넘김 → 2. B: 대사 3줄 전부 그림이 말하지 않은 것만 말한다 → 5.

**축14 끝 컷** — B: [79] 아직 들어가지 않은 갱도에 자기 이름. 정보를 빼는 컷 → 5. C: [66] 상황 요약 + 미래 회고 독백. "그때의 나는 알지 못했다"는 **화자의 생존을 알려 줘** 긴장을 없앤다(게이트) → 3.

## 6. 판정

- **A** — 연재 불가. 세계 설명을 1화 도입으로 썼다. 규칙은 내레이션이 아니라 **규칙이 깨지는 컷**으로 세운다.
- **B** — **수렴**. 평균 4.57, 게이트 0건, 핵심 3축 5·5·5. 축8만 3이며 이는 대사 표본이 적은 탓이다.
- **C** — **미수렴**. 평균 3.07. 훅의 재료(젖은 장갑·없는 손가락)는 B와 같다. **재료가 아니라 연출에서 졌다.**

## 7. C가 다음 패스에서 고칠 것 (큰 것부터)

1. **축13·2 — [03]·[04] 내레이션을 지운다.** 검은 가루와 회색 먼지를 두 컷으로 나란히 보여 주면 추론은 독자가 한다. [04] "비가 내리는 아침이었다"는 그림이 이미 했다.
2. **축11·12 — [40]을 세 컷으로 나누고 앞에 여백을 넣는다.** 소등 / 여백 / 어둠 속 눈. 지운이 넘어지는 동작은 뺀다 — 결정적 순간과 경쟁한다.
3. **축14 — [66] 회고 독백을 삭제하고 물증 한 컷으로 닫는다.** 갱도 벽의 손톱 자국처럼, 설명되지 않은 것을 마지막에 놓는다.
4. **축8 — [05] 62자 말풍선을 두 줄 이하로 자른다.** 등록증 번호와 경력은 직원의 화면이 대신 말하게 한다.
