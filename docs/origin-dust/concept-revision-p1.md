## 이번 수정이 하는 일

**F3 — 멸망 원인이 유물 경제를 만들게 한다.** 지금은 ECHO(예측이 현실을 만드는 순환)가 멸망 원인인데,
유물이 비싼 여섯 이유 중 ECHO와 이어지는 것은 ②뿐이고 나머지 다섯은 핵전쟁이어도 운석이어도 성립한다.
컨셉 안 자신이 건 조건("설정을 위한 설정을 피하고, 모든 설정이 실제 사건과 캐릭터의 선택으로 이어지게")에 미달한다.

**ECHO를 데이터 오염으로 잇는다.** 예측 루프에 들어간 뒤에 만들어진 것은 AI가 생성했든 인간이 직접 썼든
예측이 이미 손을 댄 결과물이고, 만든 본인조차 어느 쪽인지 구분하지 못한다.
**오염되지 않은 유일한 표본이 ZERO FALL 이전 지구의 원본이다.** 이 한 줄이 여섯 이유를 한 뿌리로 묶는다.

**F4 — JANUS 통과 조건을 크기에서 조율로 바꾼다.** 지금은 "작은 함선은 통과한다"인데, 통과 조건이 선체 크기라면
자본이 클수록 소형선을 많이 산다. HELIX는 태양계 최대 기업이고 시간은 137년이었다.
크기 규칙은 대기업을 막는 게 아니라 **대기업에게 유리하다.**

**JANUS가 질량이 아니라 조직된 의도를 읽게 한다.** 동시 진입·공유 항법·중앙 지휘를 감지하면 요격하고
흩어진 개인은 통과시킨다. 기업이 소형선 수천 척을 사도 같은 회사의 배라는 사실 자체가 조율이라 걸린다.

F3과 F4가 한 곳에서 만난다 — **조율된 의도를 미리 읽어내는 것은 방어 시스템이 아니라 예측 시스템이 하는 일이다.**

# F3 — ECHO를 유물 경제의 뿌리로 잇는다

## P4-1 · §5 ECHO 끝 — 오염 개념을 심는다

**before**

```
인류는 자신들이 자유롭게 선택한다고 생각했지만,

실제로는 AI가 계산한 미래에서 점점 빠져나오지 못하게 된다.
```

**after**

```
인류는 자신들이 자유롭게 선택한다고 생각했지만,

실제로는 AI가 계산한 미래에서 점점 빠져나오지 못하게 된다.

그리고 여기에 ECHO의 진짜 문제가 있다.

ECHO 이후에 만들어진 것은 무엇이든 예측이 이미 손을 댄 결과물이다.

AI가 생성했든 인간이 직접 썼든 다르지 않다.

어떤 것이 인간의 생각이고 어떤 것이 예측의 산물인지,

만든 본인조차 구분하지 못한다.

인류는 자기가 남긴 기록을 자기 것이라고 증명할 수 없게 됐다.
```

**왜** — F3 전체가 이 문단 위에 선다. 멸망 원인을 "AI가 폭주했다"에서 **"인류가 자기 기록의 저자임을 잃었다"**로
옮기면, 다음 §6의 여섯 가지 가치가 전부 여기서 자라 나온다.

## P4-2 · §6 ORIGINAL 정의 — 여섯 이유를 한 뿌리로 묶는다

**before**

```
## ORIGINAL

AI가 복원하거나 복제하지 않은

**멸망 이전의 진짜 물건.**
```

**after**

```
## ORIGINAL

AI가 복원하거나 복제하지 않은

**멸망 이전의 진짜 물건.**

정확히는 이런 뜻이다.

ECHO가 시작되기 전에 만들어진 것.

예측이 손대지 않은 유일한 표본.

아래 여섯 가지 가치는 전부 이 하나에서 갈라져 나온다.
```

**왜** — 이 수정안에서 가장 중요한 다섯 줄이다. 지금까지 §6은 이유 여섯 개를 **나열**했다.
이 문단이 들어가면 나열이 **분기**가 된다 — 뿌리 하나에서 갈라진 여섯 가지.

## P4-3 · §6-① 원본 증명 — 복원본을 왜 못 믿는지 잇는다

**before**

```
현재 존재하는 역사자료 대부분은 AI가 여러 자료를 조합해 복원한 것이다.

때문에 원본 기록에는 엄청난 가치가 있다.
```

**after**

```
현재 존재하는 역사자료 대부분은 AI가 여러 자료를 조합해 복원한 것이다.

그 AI는 ECHO의 후손이다.

빈칸을 채울 때 그것은 실제로 있었던 일이 아니라 가장 있었을 법한 일을 채운다.

때문에 원본 기록에는 엄청난 가치가 있다.
```

**왜** — "복원본은 못 믿는다"가 지금은 정서였다. 이제 이유가 생긴다.

## P4-4 · §6-② AI가 생성하지 않은 데이터 — 기준을 'AI 이전'에서 'ECHO 이전'으로

**before**

```
24세기의 인터넷에는 인간이 만든 것보다 AI가 만든 데이터가 압도적으로 많다.

그래서 오히려

‘AI가 존재하기 전 인간이 만든 데이터’

가 연구용으로 매우 귀하다.
```

**after**

```
24세기의 인터넷에는 인간이 만든 것보다 AI가 만든 데이터가 압도적으로 많다.

그러나 문제는 비율이 아니다.

ECHO 이후의 데이터는 인간이 쓴 것조차 예측을 거쳐 나왔다.

그래서

‘ECHO 이전에 인간이 만든 데이터’

가 연구용으로 매우 귀하다.
```

**왜** — 기준을 바로잡는 김에 작은 모순도 닫는다. 이 세계에서 AI는 ECHO보다 훨씬 전부터 있었으므로
"AI가 존재하기 전"은 ZERO FALL보다 한참 이전을 가리켜 버린다. 경계선은 **ECHO**다.

## P4-5 · §6-⑥ 감정 — 향수마저 오염된다

**before**

```
그래서 부유층은

실제 지구의 흙 한 줌을

보석보다 비싸게 산다.
```

**after**

```
그래서 부유층은

실제 지구의 흙 한 줌을

보석보다 비싸게 산다.

AI는 지구의 바다를 완벽하게 재현해 보여줄 수 있다.

그런데 그 그리움조차 ECHO가 계산해 만든 그리움이 아닌지,

아무도 확신하지 못한다.

흙 한 줌은 확신할 수 있다.
```

**왜** — 여섯 이유 중 ECHO와 가장 멀어 보이던 항목까지 뿌리에 닿는다.
"흙 한 줌은 확신할 수 있다"가 §19의 주제 질문("진짜란 무엇인가")을 설정에서 직접 자라나게 한다.

## P4-6 · §10-② HELIX — 동기를 세운다

**before**

```
## ② HELIX INDUSTRIES

태양계 최대 AI 기업.

ORIGIN 기술을 가장 적극적으로 찾는다.
```

**after**

```
## ② HELIX INDUSTRIES

태양계 최대 AI 기업.

ORIGIN 기술을 가장 적극적으로 찾는다.

이유는 단순하다.

HELIX의 모든 모델은 ECHO 이후의 데이터로 학습됐다.

오염되지 않은 학습 데이터는 지구에만 남아 있다.

경쟁사보다 먼저 그것을 확보하는 쪽이 다음 세기를 가져간다.
```

**왜** — 지금까지 HELIX는 "가장 적극적으로 찾는다"고만 했지 왜인지가 없었다.
설정이 세력의 행동으로 이어져야 한다는 컨셉 안 자신의 조건을 여기서 갚는다.

# F4 — JANUS 통과 조건을 크기에서 조율로 바꾼다

## P4-7 · §8 — 통과 규칙을 다시 쓴다

**before**

```
JANUS는 지구 궤도와 주요 시설을 지키는 자동 방어 시스템이다.

대형 우주선이나 군대를 보내면 즉시 공격한다.

그런데 작은 함선은 감지하지 못하는 경우가 있다.

그래서 아이러니하게도

군대는 못 들어가지만

밀수꾼은 들어갈 수 있다.

게다가 지구 궤도에는 수억 개의 위성 잔해가 떠다닌다.

대규모 진입 자체가 어렵다.

때문에 기업들은 직접 움직이기보다

유물 사냥꾼들에게 돈을 준다.

공식적으로는 범죄자지만,

필요할 때는 누구

보다 유용하다.
```

**after**

```
JANUS는 지구 궤도와 주요 시설을 지키는 자동 방어 시스템이다.

오래 관찰한 사람들은 JANUS가 무엇을 보고 쏘는지 알아냈다.

질량이 아니다.

**조율이다.**

동시에 내려오는 편대.

공유된 항법 데이터.

중앙에서 떨어지는 지휘.

JANUS는 그런 패턴을 미리 읽고 요격한다.

반대로 흩어진 개인은 통과한다.

서로 모르는 배들이 제각각 내려가면 JANUS는 그것을 의도로 읽지 못한다.

그래서 아이러니하게도

군대는 못 들어가지만

밀수꾼은 들어갈 수 있다.

기업이 소형선 수천 척을 사도 소용이 없다.

같은 회사의 배라는 사실 자체가 조율이기 때문이다.

게다가 지구 궤도에는 수억 개의 위성 잔해가 떠다닌다.

대규모 진입 자체가 어렵다.

때문에 기업들은 직접 움직이기보다

서로 아무 관계 없는 유물 사냥꾼들에게 따로따로 돈을 준다.

공식적으로는 범죄자지만,

필요할 때는 누구보다 유용하다.
```

**왜** — "기업이 소형선 수천 척을 사도 소용이 없다"가 F4의 핵심이다. 크기 규칙은 자본으로 뚫리지만
조율 규칙은 자본이 커질수록 **더** 걸린다. 기업이 사냥꾼에게 돈을 주는 이유가 편의가 아니라 **필연**이 된다.

원문의 "누구 / 보다 유용하다" 줄바꿈 오류도 이 교체에 포함해 바로잡았다.

## P4-8 · §10-⑦ JANUS — F3과 F4를 한 곳에서 만나게 한다

**before**

```
## ⑦ JANUS

조직이 아니다.

지구에 남아 있는 자동 방어 네트워크.

하지만 갈수록

JANUS가 단순한 프로그램이 아닐지도 모른다는 암시가 나온다.
```

**after**

```
## ⑦ JANUS

조직이 아니다.

지구에 남아 있는 자동 방어 네트워크.

JANUS는 조율된 의도를 읽어낸다.

아직 일어나지 않은 진입을 미리 읽고 쏜다.

그것은 방어 시스템이 하는 일이 아니다.

예측 시스템이 하는 일이다.

하지만 갈수록

JANUS가 단순한 프로그램이 아닐지도 모른다는 암시가 나온다.

ORIGIN은 정말 꺼졌는가.
```

**왜** — F4가 만든 규칙이 F3의 멸망 원인과 같은 성질임을 독자가 스스로 알아채게 한다.
원문의 "단순한 프로그램이 아닐지도 모른다"는 암시에 근거가 생긴다.

**이 패치 하나만 성격이 다르다.** 앞의 여덟은 논리 구멍을 메우지만, 마지막 줄 "ORIGIN은 정말 꺼졌는가"는
**새로운 이야기 가능성을 여는 제안**이다. 시즌2를 열어 두는 문이라 판단해 넣었으나,
작가 의도와 다르면 이 한 줄만 빼도 나머지는 그대로 작동한다.

## P4-9 · §13 MOTH-13 — 새 규칙 위에 다시 세운다

**before**

```
### 너무 낡아서 JANUS가 군사 장비로 인식하지 않는다.
```

**after**

```
### 너무 낡고 너무 혼자여서 JANUS가 조율로 읽지 않는다.

40년 동안 단독으로만 떴다.

항법을 누구와도 공유한 적이 없고, 지휘를 받은 적도 없다.

기업의 신형 회수선은 돈으로 성능을 사지만 이 이력은 사지 못한다.
```

**왜** — 리뷰가 경고한 지점이다. MOTH-13의 장점이 옛 규칙(크기·장비 종류)에 묶여 있어
F4를 고치면 함께 무너진다. **낡음이 장점**이라는 아이러니는 그대로 두되 근거를 새 규칙으로 옮겼다.
마지막 줄이 P4-7의 "기업이 소형선 수천 척을 사도 소용이 없다"와 짝을 이룬다 —
같은 규칙이 기업에게는 벽이고 레이에게는 문이다.
