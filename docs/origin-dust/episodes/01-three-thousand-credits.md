## 리뷰 2회차 대응 (평균 3.86 · 게이트 1건 — 축4)

패스 1 대비 **게이트 4건 → 1건.** 축1이 3→4로 올랐다(첫 3컷 게이트·데우스 엑스 마키나 게이트 둘 다 닫혔다).
평균이 제자리인 것은 축13이 5→4로 내려간 리뷰어 변량이 상쇄했기 때문이다.

| 지적 | 대응 |
|---|---|
| **축4 게이트** — [31]~[45] 15컷(넓게 21컷) 무장애. 드론전도 첫 시도에 그대로 성공한다 | **[27] 벨트에 이미 있던 구형 탐지기를 쓴다.** [39] 바늘이 초록 끝 → [45] 노란 칸 → [50] 붉은 칸 앞에서 떤다. 컷 셋으로 탐사 전체가 압력 구간이 된다. 드론전에는 **[59] 케이블이 한 번 미끄러진다**를 넣어 좌절을 만들었다 |
| **축6·축7** — [66]에서 "EMP는 전자기기를 죽인다"는 규칙을 세워 놓고 [69]부터 녹음기가 멀쩡하다. **선택의 비용이 사라져 9비트 7번이 무효화된다** | 규칙을 지켰다. **[70][71] 버튼을 눌러도 아무 반응이 없다.** 녹음기는 죽었다. 그래서 MORROW가 **뚜껑을 열고 자기테이프의 릴을 손으로 돌린다.** 소리는 스피커가 아니라 **MORROW의 입에서** 나온다. 레이가 치른 값이 실재하고, 그 값을 치렀기 때문에 기계식 매체라는 사실이 드러난다 |
| **축1 M1** — 약속 한 문장의 "복제할 수 없는 원본"이 회수되지 않는다. 판정기가 장식이다 | 위 수정이 같이 갚는다. 테이프를 판정기에 올리고 미나가 **"이건 복제가 안 돼. 세상에 한 개야."** 복제 불가가 설명이 아니라 **물리적 사실**로 선다 |
| **축3** — 레이가 이 회차에서 아무것도 걸지 않는다 | [17] 의뢰 목록 아래 붉은 줄 **〈정비비 미납 · 4개월〉**, [30] SOL의 대사를 **"이번 거 빈손이면 배 판다."** 로 교체. 컷 추가 0, 말풍선 증가 0 |
| **9비트 8번** — 귀환 자체가 컷으로 없다(어둠 → 선실 직행) | **[68] 어둠 속. 손이 벽을 짚으며 위로 올라간다.** |
| **축13** — [87] "그 시각엔 지구에 살아 있는 사람이 없었습니다"가 회차 최고점에 놓인 설명 대사다 | 대사를 지우고 **[92] 화면의 공식 기록 〈지구 생존자 0 · 확정 18:00〉** 으로 바꿨다. 그림이 말을 대신하고, 프롤로그 [36]과 같은 문자열이라 독자가 스스로 잇는다 |
| **축5** — [53] "이름 석 자"가 끝까지 회수되지 않는다 | 이번 패스에서 닫지 못했다. 시즌 단위 회수처로 남긴다 — 다음 지시 때 처리 |

**MORROW가 목소리를 대신 내는 것**은 리뷰가 제안한 (b)안을 따르면서 한 발 더 간 것이다.
§12의 MORROW는 "기억이 복사될 수 있다면 원본 인간은 누구인가"에 집착한다. 그가 죽은 아이의 목소리를
자기 입으로 재생하는 장면이 그 질문을 설명 없이 세운다.

**루프 상태** — 리뷰 2회 소진. 이 판본은 채점되지 않았다. 3회차 채점 대기.
