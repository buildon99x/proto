## 리뷰 3회차 대응 — 루프 종료 (3.36 → 3.93 → **4.00** · 게이트 7 → 1 → 1)

**세 원고 중 최고점.** 축6 삭제 테스트를 다시 통과했고(노트가 회차 안에서 **다섯 번** 일한다는 판정),
축7 데우스 엑스 마키나도 통과했다("새로 생긴 능력·도구·우연이 한 건도 없다").
남은 게이트는 축4 하나였다.

| 지적 | 대응 |
|---|---|
| **축4 게이트** — [16]~[47] **32컷** 무장애. 원고가 장애물을 **적극적으로 치운다**(문은 스르륵 열리고, 필터 바늘은 초록에 있고, 조명은 알아서 밝아진다) | 부품은 이미 벨트에 있었다. **탐지기 바늘을 3단으로 움직였다** — 초록 칸 끝 → [41] 노란 칸 → [47] 붉은 칸 앞에서 떤다. 노트를 읽는 구간 전체가 초읽기가 된다. **[22] 문은 반쯤 열리다 멈추고 레이가 어깨로 민다.** 의뢰에도 저항을 되살렸다 — [15] "선금 절반." / [16] "전액 후불이야." 1화의 "안 합니다"와 다른 형태다 |
| **축4** — [32][33] 헬멧 벗기가 위험을 세우자마자 3컷 만에 해제되고 회수되지 않는다. 미나가 안 벗는 차이도 끝까지 안 쓰인다 | 결과를 붙였다. **[57] 레이가 먼저 고개를 든다. 공기 맛이 바뀌었다.** 벗은 사람만 아는 것이 생긴다 |
| **1화와의 동형성** — 끝 5컷이 1화와 **글자 단위로 같다**(여백 4 → 검정 → CUT). 단서 제시 리듬도 같다. "클리프행어는 예측되는 순간 정보를 빼는 컷이 아니라 주는 컷이 된다" | 리듬을 바꿨다. **정지 → 날짜 → 미완의 물증 → 암전**에서 **손가락이 칸을 따라 미끄러지는 시간**으로. [84] 첫 칸에 닿고 → [85][86] 날짜를 따라가다 → [87] 7.23에서 멈추고 → [88] 물방울이 그려지다 말았다. **검정 CUT을 뺐다.** 1화는 귀로 듣는 단서, 2화는 손가락으로 세는 단서다 |
| **1화 재활용** — [18] 벨트 컷과 [09] 정비 청구 UI가 1화의 재활용이라 2화가 변주로 읽힌다 | 벨트 컷을 바꿨다. **[18] SOL이 케이블 발사기를 던진다. 레이가 받는다. / [19] 레이가 탐지기를 손목에 채운다.** 같은 정보를 다른 그림으로 주고, 던지는 동작이 [73] 파손의 대비가 된다 |
| **축5·13** — '11'을 여섯 번 준다. 독자는 [64]에서 끝나는데 그 뒤는 격차가 아니라 확인이다 | **표찰 재제시 컷을 지웠다.** "열한 그루." 다음에 바로 멈춘 손으로 간다 |
| **축11** — [34]에 미나의 헬멧 거부(인물)와 식물 이름표(물증)가 경쟁. [71]은 금속 소리와 탈출이 한 컷 | 둘 다 쪼갰다 |
| **축2** — 내면 연기가 "손이 멈춘다" 하나뿐인데 세 번 쓴다 | 중간 것을 **"하나씩, 천천히"**로 바꿔 마지막 정지를 살렸다 |

**받아들이되 닫지 못한 것**: [68] 물은 재개되는데 [69] 문은 계속 내려오는 이유가 없다("연출을 위해 규칙이 반쯤 휘었다") ·
