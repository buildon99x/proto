## 리뷰 1회차 대응 (평균 3.93 · 축1 3 · 축3 3 게이트 발동)

| 지적 | 대응 |
|---|---|
| **축1 게이트** — 첫 3컷([01][02][03])이 전부 정상 상태. 어긋남이 [05]에 있었다 | 재배열했다. **[02] 여덟 차선에 차가 없다 → [03] 도시는 불이 다 켜져 있다.** 3컷 안에 모순이 선다. 관측소 전경은 이상 신호를 본 뒤로 미뤘다 |
| **축3 게이트** — 유안이 잃는 것이 "지구 생존자 전원"뿐. 개인 층위 손실 0 | **[07][08] 콘솔에 테이프로 붙인 사진**을 넣고, **[22] 암전에서 비상등이 유안의 얼굴과 그 사진만 남기도록** 고쳤다. 대사 0줄로 [29] "생존자 0 확정"이 유안 개인의 손실로 내려온다. 사진 속 얼굴은 끝까지 보이지 않는다 |
| **축14** — 가장 강한 컷 뒤에 "137년 뒤." 자막이 붙어 긴장을 식힘 | **자막을 뺐다.** [35] 창이 닫힘 + 여백 5로 닫는다. "137년 뒤."는 1화 첫 컷으로 옮긴다 |
| **M2 이탈** — "유안, 다시 화면으로 시선을 돌린다"가 정보를 원위치시킴 | 삭제했다. 여자의 아날로그 시계[16] → 벽의 시계[17]로 바로 물린다 |
| **M2 이탈** — [03]과 [04]가 같은 기능("지구는 살아 있다")을 연속으로 냄 | 재배열이 같이 닫았다. 두 컷이 더 이상 연속하지 않는다 |
| **축4** — 억압은 3연타인데 유안이 한 번도 밀지 않는다 | **[33] 유안이 반쯤 일어선다. 손이 화면 쪽으로 간다. "저건—"** 을 넣었다. 늦는다는 것이 압력이다 |
| **축13** — 지문의 해설조 3곳 | 전부 지웠다. "사흘 못 잔 얼굴이다"(빈 종이컵이 이미 한 말), "앉으라는 뜻이다"(누르는 손이 이미 한 말), "그의 말을 끊지 않는다"(부정 서술이라 그릴 수 없다) |
| **축12** — 여백 외에 컷 높이·앵글 지시가 0 | `〔세로 N〕` 표기를 도입해 [04][21][35] 세 곳에 달았다 |

**반영하지 않은 것**: §5가 "동시에 끊겼다"인데 [19]~[21]은 순차 소등이라는 지적(축7 미세 불일치).
순차가 연출상 우월하다는 리뷰의 판단에 동의한다. **설정 쪽을 고치는 편이 맞다** —
`concept-v2.md` 216~224행의 "동시에"를 "초 단위로 연쇄적으로"로 바꾸는 안을 P2 목록에 올린다.

## 집필 노트

- **[07][08] 사진** — 유안의 손실. [16] 여자의 시곗줄과 같은 회수용 심기다. 둘 다 얼굴을 보여주지 않는다.
- **[26]→[29]** — `concept-v2.md` §5의 핵심이 그림이 되는 자리. **관측 종료**가 두 줄 만에 **생존자 0 확정**이 된다.
  유안의 "관측 종료요? 사망이 아니라—"가 그 도약을 독자 대신 지적하고, 대답이 없는 것이 답이다.
- **[33]~[35]** — 유안이 먼저 움직이는데 여자의 손이 먼저 닿는다. 그 반 박자가 이 장면의 전부다.
- **끝 컷** — [35]는 정보를 뺀다. 누가 왜 닫았는지 말하지 않는다.
