# 03 — 시스템

> MSW 주식회사 · v1.1 · 2026-09-25 · [README](./README.md) · 바뀐 점은 [05 리뷰](./05-review.md)
>
> **이 문서가 답하는 질문:** 플레이어의 경험([02](./02-player-experience.md))은 어떤 규칙과 수치로 돌아가는가.
>
> 수치는 전부 **초기값**이다. 몬스터 이름과 레벨은 **예시**다. MSW 공식 리소스 목록과 대조해 확정한다.
>
> **이 문서의 규칙은 코드로도 있다.** [prototype/sim.js](./prototype/sim.js)가 이 문서와 같은 수치로 월드를 굴리고, [prototype/pacing-check.js](./prototype/pacing-check.js)가 02의 대본·달력이 이 규칙으로 실제로 나오는지 확인한다. 둘이 어긋나면 코드가 아니라 **이 문서를 먼저 고친다.**

## 1. 개념 계층

```
월드
 ├─ 스마일 (자원) · 월드 인기 ★ (진척) · 입구 (Lv 1 모험가가 들어오는 곳) · 졸업선 (열린 길의 끝)
 └─ 지역 × 5  ─  던전 부지 × 3
                   └─ 던전
                       ├─ 몬스터 슬롯 × 3~5   ← 몬스터 (직원)
                       ├─ 자리 8~20            ← 모험가 (NPC)
                       └─ 이벤트 칸 × 1        ← 경험치 2배 | 드랍 2배
```

## 2. 규칙 다섯 줄

**플레이어가 기억해야 할 규칙은 이 다섯 줄이 전부다** (P1). 튜토리얼도 이 순서로 하나씩 가르친다.

| # | 규칙 | 한 줄 |
|---|---|---|
| **R1** | 던전 레벨 | **던전 레벨 = 배치된 몬스터의 평균 레벨.** 모험가는 던전 레벨 ±5 안에서 즐겁다 |
| **R2** | 모험가 이동 | 모험가는 **자기 레벨에 맞는 던전을 스스로 찾아간다.** 없으면 기다리다 떠난다. 졸업선까지 오르면 졸업한다 |
| **R3** | 레벨업 | 즐거운 모험가만 레벨업한다. 레벨이 오르면 **더 높은 던전으로 옮긴다** |
| **R4** | 진화 | 몬스터는 **퇴근(쓰러짐)할수록 근속이 쌓이고**, 가득 차면 진화할 수 있다. 진화하면 레벨이 오른다 |
| **R5** | 이벤트 | 경험치 2배는 **모험가를 위로 올려보내고**, 드랍 2배는 **모험가를 불러 모은다** |

**둘을 잇는 고리:** R1 + R4. 몬스터가 진화하면 던전 레벨이 오르고(R1), 그 던전이 담당하던 아래 구간이 빈다(R2). 이것이 이 게임의 **핵심 긴장**이다.

## 3. 엔티티

**P4에 따라 필드는 최소한만 둔다.** 플레이어에게 보이지 않거나 결정에 쓰이지 않는 속성은 만들지 않는다.

| 엔티티 | 필드 | 플레이어에게 보이는가 |
|---|---|---|
| **월드** | 스마일, ★(0~5), 입구 도착률, 졸업선(파생: 지금 챕터의 목표 레벨) | 전부 |
| **지역** | 이름, 레벨 범위, 부지 3, 개방 여부, 결재 조건 | 전부 |
| **던전** | 부지, 몬스터 슬롯(3~5), 자리(8~20), 이벤트{종류, 종료 시각}, 던전 레벨(파생), 던전 ★(0~3) | 전부 |
| **몬스터** | 계열, 단계(1~4), 레벨(파생), 근속, 위치(던전 or 대기실) | 전부 |
| **모험가** | **개체 없음.** 던전별 `레벨 → 인원` 분포 + 대기 인원 + 누적(도착·졸업·떠남 사유별) | 분포와 표정 |

**모험가는 집단으로 계산하고, 화면은 필요한 만큼만 그린다.** 월드 길(S1)은 모험가를 전원 그린다(프로토타입에서 150명까지 문제없음). 수백 명이 되는 4장부터는 레벨 칸마다 대표 한 명 + 인원 숫자로 바꾼다. 던전 현장(S2)은 즐거운 모험가를 12명까지 샘플로 그린다. 직업은 외형 랜덤이다(P4).

## 4. 규칙 상세

### R1 · 던전 레벨

```
던전 레벨 D = round( 슬롯에 있는 몬스터 레벨의 평균 )
적정 구간   = [D − 5, D + 5]
몬스터가 없는 던전 = 휴업 (모험가가 들어오지 않는다)
```

- 섞어 쓸 수 있다. 예: 달팽이(Lv 2) + 주황버섯(Lv 8) + 주황버섯(Lv 8) → D = 6 → 적정 Lv 1~11.
- 보스는 던전당 1마리까지다.

### R2 · 모험가 이동

매 계산 단계(1분)마다 각 모험가 무리가 판정한다.

```
if 레벨 ≥ 졸업선                   → 🎓 졸업 (좋은 퇴장)
elif 지금 던전의 적정 구간 안        → 머문다
else:
    후보 = 적정 구간에 내 레벨이 드는 던전들
    if 후보 없음                     → 😐 찾는 중 → 60분 지나면 😢 떠남 (사유: 갈 곳 없음)
    elif 후보 전부 자리 없음          → 😠 마을 대기 → 30분 지나면 😢 떠남 (사유: 자리 없음)
    else                             → 이동. 우선순위: ① 드랍 이벤트 중 ② 빈자리 많은 곳 ③ 레벨 높은 곳
```

- **졸업선** = 결재로 열린 길의 끝 = 지금 챕터의 목표 레벨(1장 Lv 15, 2장 Lv 30, 3장 45, 4장 60, 5장 70). 거기까지 오른 모험가는 "다 즐겼다"며 **졸업**한다. 졸업은 실패가 아니라 **최선의 퇴장**이다.
- **왜 던전 레벨이 아니라 결재로 정하는가 (v1.1):** v1.0은 "열린 던전의 `D + 5` 중 최댓값"이었다. 그러면 달팽이 들판 하나뿐인 월드(D2)에서 모험가가 Lv 7에 졸업해 버려, 빈틈이 영영 생기지 않고 **작은 월드가 최적**이 된다. 졸업선을 결재에 묶으면 결재할 때마다 길이 늘어 **새 수요**가 생긴다.
- **빈틈** = 1 ~ 졸업선 사이에서 어느 던전의 적정 구간에도 들지 않는 레벨. 화면은 둘로 나눠 보여 준다: 멈춘 모험가가 없으면 **끊긴 길**(옅은 점선), 있으면 **빈틈**(빨간 빗금 + ! + 인원). 규칙은 하나다([04](./04-screens.md)).
- **입구:** 새 모험가는 Lv 1로 들어온다. Lv 1이 드는 던전(D ≤ 6)이 없으면 **입구에서 😐로 멈춰 기다리다** 60분 뒤 떠난다(사유: 입구 막힘). v1.0은 바로 떠났는데, 그러면 빈틈에 멈춘 사람이 없어 입구가 막혀도 빨간 경고가 뜨지 않았다([05](./05-review.md)).
- 떠남은 벌이 아니다. 월드 수치는 줄지 않고, **즐기는 모험가가 덜 늘 뿐**이다(P5).

### R3 · 표정과 레벨업

| 표정 | 조건 | 결과 |
|---|---|---|
| 😊 즐거움 | 적정 구간 안 + 자리 있음 | 레벨업 진행, 스마일 생산, 몬스터 퇴근 발생 |
| 😐 찾는 중 | 맞는 던전이 없음 (레벨이 적정 구간 밖) | 아무것도 생산 안 함 |
| 😠 붐빔 | 맞는 던전이 전부 꽉 참 | 아무것도 생산 안 함 |
| 😢 떠남 | 대기 시간 초과 | 월드에서 사라짐. 사유 기록 |
| 🎓 졸업 | 졸업선 도달 | 스마일 +20, 사라짐 |

```
즐거운 모험가의 레벨업 간격 = (10 + 현재 레벨) 분
경험치 2배 이벤트 중       = 절반
레벨이 올라 적정 구간을 벗어나면 그 자리에서 레벨업을 멈춘다 (더는 즐겁지 않다)
```

마지막 줄은 v1.1에서 명시했다. 계산 한 걸음(1분)에 레벨업이 여러 번 일어나도 **빈틈을 건너뛰지 못한다.** 입사 첫날 버프(×30) 중에 Lv 13 모험가가 한 걸음에 Lv 15로 올라 끊긴 길 너머에서 졸업하던 문제를 막는다.

Lv 1 → 15는 약 4시간, Lv 1 → 70은 약 52시간이다. 모험가 한 명이 월드를 끝까지 오르는 데 **이틀 남짓**이 걸린다.

### R4 · 근속과 진화

```
즐거운 모험가 1명 = 분당 퇴근 1회를 발생시킨다 → 던전 안 몬스터들에게 균등 분배
```

예: 즐거운 모험가 12명, 몬스터 3마리 → 몬스터마다 분당 4회 퇴근 → 시간당 240.

| 진화 | 필요 근속 | 모험가 12명 · 직원 3 던전 기준 소요 | 레벨 변화 |
|---|---|---|---|
| 1 → 2단계 | 2,000 | 약 8시간 (하룻밤) | +8 |
| 2 → 3단계 | 12,000 | 약 2일 | +8 |
| 3 → 보스 | 45,000 | 약 8일 | +8 (보스 계열만) |

v1.0의 8,000 / 30,000은 봇 매니저가 2장을 D4에 끝낼 만큼 빨랐다. 1단계는 첫 출근(Day 2) 진화를 보장해야 해서 그대로 두었다.

- **진화는 자동이 아니다.** 근속이 차면 보라 `▲` 배지가 뜨고, 매니저가 누른다. 보류해도 근속은 계속 쌓인다. 벌칙은 없다.
- **진화 전에 결과를 미리 보여준다.** 던전 레벨이 어떻게 바뀌고, 어느 레벨 구간이 비게 되는지 **월드 길 위에** 유령 발판과 빨간 예고 빗금으로 표시한다. 계산은 월드 전체 기준이다(다른 던전이 덮어 주면 빈틈이 아니다)([04](./04-screens.md) S3).
- 모든 직원은 다른 던전·빈 부지·대기실로 옮길 수 있다(드래그). 옮겨도 근속은 유지된다. 대기실에서는 근속이 쌓이지 않는다.

### R5 · 이벤트 (매니저 권한)

| | **경험치 2배** | **드랍 2배** |
|---|---|---|
| 한 줄 | 모험가를 **위로 올려보낸다** | 모험가를 **불러 모은다** |
| 효과 | 이 던전의 레벨업 간격 절반 | 이 던전의 스마일 2배 + 이동 우선순위 1위 |
| 부작용 | 빨리 크니 **다음 던전에 부하**가 몰린다 | 몰려오니 **과밀**이 된다 |
| 쓰는 때 | 병목 해소, 다음 챕터 구간 채우기 | 스마일 벌기, 새 던전 띄우기 |
| 지속 | 4시간 | 4시간 |
| 비용 | 스마일 30 × D | 스마일 30 × D |
| 동시 이벤트 수 | 월드 전체 2개 (3장부터 3개) | 같은 수를 나눠 쓴다 |

던전 하나에는 이벤트 하나만 걸 수 있다(던전의 **이벤트 칸**은 1개). 월드 전체에서 동시에 돌릴 수 있는 이벤트 수는 **동시 이벤트 수**로 따로 제한한다. 원작 메이플의 이벤트 문법을 그대로 빌려서, 설명 없이도 뜻이 통한다.

## 5. 경제 — 스마일 하나

**재화는 스마일 하나다** (P1). 모험가의 즐거움이 곧 돈이고, 곧 목표다.

| 들어오는 곳 | 양 |
|---|---|
| 즐거운 모험가 | 1명당 **4분에 1** (드랍 이벤트 던전 ×2, 🎁 계열이 있는 던전 ×1.3, 보스가 있는 던전 ×1.5) |
| 레벨업 | 1회당 2 |
| 졸업 | 1명당 20 |

v1.0은 1명당 분당 1이었다. 첫 밤에 +6,800이 들어와 모든 구매가 공짜처럼 느껴졌고 "스마일을 어디에 쓸까?"가 결정이 아니게 됐다. 지금은 첫 밤에 약 +2,000, 즉 부지 하나와 채용 한두 번이다.

| 나가는 곳 | 비용 |
|---|---|
| 신입 채용 (1단계만 채용 가능) | 100 × 계열 기본 레벨 (달팽이 200, 주황버섯 800, 스텀프 2,800) |
| 자리 확장 (+4) | 500 → 1,000 → 2,000 (최대 20) |
| 슬롯 확장 (+1) | 1,000 → 3,000 (최대 5) |
| 던전 개설 (부지) | 1,000 × 지역 번호 |
| 이벤트 | 30 × 던전 레벨 |

- 시작 상태: 스마일 500, 헤네시스 들판 개설, 달팽이 2마리(그중 한 마리는 **고참 — 근속 1,600**). 던전 자리 8석(들판은 입사 선물로 12석), 직원 칸 3개. 월드 시계는 저녁 9시에서 시작한다.
- 입사 선물(튜토리얼 지급): 두 번째 부지(헤네시스 사냥터) 개설, 첫 채용권 1장(주황버섯), 첫 이벤트 1회 무료, 들판 자리 +4(12석). 마지막 것은 첫날 밤 입구가 막혀 첫 출근 리포트의 😊가 줄어 보이지 않게 한다.
- **높은 단계 몬스터는 살 수 없다.** 오직 키워서만 얻는다. 월드를 위로 넓히려면 반드시 진화가 필요하다. 이것이 진화에 목적을 주는 규칙이다.
- 대기실: 배치하지 않은 몬스터 보관, 최대 10마리. 대기실 몬스터는 근속이 쌓이지 않는다.

## 6. 진척 — 결재와 월드 인기

**챕터 = 지역 = 결재 서류 한 장.** 결재 조건은 항상 두 개다.

| 장 | 지역 | 졸업선 | 조건 ① 구간 연결 | 조건 ② 즐기는 모험가 (동시) | 결재 보상 |
|---|---|---|---|---|---|
| 1 | 헤네시스 | Lv 15 | Lv 1~15 빈틈 없음 | 20명 | ★1, 엘리니아 개방 (부지 +3, 슬라임 채용), 졸업선 → 30 |
| 2 | 엘리니아 | Lv 30 | Lv 1~30 빈틈 없음 | 60명 | ★2, 페리온 개방 (부지 +3, 스텀프 채용), 졸업선 → 45, 동시 이벤트 +1 |
| 3 | 페리온 | Lv 45 | Lv 1~45 빈틈 없음 | 110명 | ★3, 커닝시티 개방, 졸업선 → 60 |
| 4 | 커닝시티 | Lv 60 | Lv 1~60 빈틈 없음 | 160명 | ★4, 슬리피우드 개방, 졸업선 → 70 |
| 5 | 슬리피우드 | Lv 70 | Lv 1~70 빈틈 없음 **+ 발록 던전 개장** | 220명 | ★5, **엔딩** |

- **결재는 졸업선을 민다.** 결재 직후에는 새 구간 전체가 끊긴 길이 된다(예: 1장 결재 직후 Lv 16–30). Lv 15에서 졸업하던 모험가들이 이제 갈 곳을 찾는다. 결재가 곧 다음 챕터의 첫 문제다.

- **월드 인기 ★ = 끝낸 결재 수.** 따로 계산하는 점수가 없다.
- ★가 오를수록 입구 도착률이 오른다: 시간당 `6 × (1 + 0.5 × ★)` (★0 = 6명, ★5 = 21명).
- 조건은 서버가 상시 판정한다. 매니저가 없을 때 달성해도 **결재함에 서류가 올라와** 기다린다. 도장은 매니저가 직접 찍는다(연출의 주인공은 플레이어다).
- **발록 던전:** 5장 결재 서류에 **"주니어 발록 입사 지원서"**가 붙어 온다. 주니어 발록은 **Lv 70 보스**다. 던전 하나에 배치하면(단독이면 던전 Lv 70, 적정 65~75) 조건이 채워진다. 진화 계열이 아니라 스토리로 합류하는 유일한 직원이다.

### 던전 ★ (완전 클리어용)

던전마다 **누적 즐거움**으로 ★1 = 100, ★2 = 500, ★3 = 2,000. 단위는 **명·시간**이다(즐거운 모험가 1명이 1시간 머물면 1).

### 입사 첫 세션 보정 (튜토리얼)

첫 세션 **15분 동안만** 적용한다. 이후에는 사라지고 다시 오지 않는다. 연출 이름은 **"입사 첫날 버프"**다.

| 보정 | 값 | 이유 |
|---|---|---|
| 레벨업 속도 | ×30 | 첫 레벨업 0:25, 첫 빈틈(Lv 8) 3:25 ([02 §6.2](./02-player-experience.md#62-첫-10분--입사), 페이싱 점검값) |
| 근속 속도 | ×30 | 고참 달팽이(근속 1,600)가 약 4~5분 뒤 진화할 수 있게 된다 |
| 입구 도착 | 첫 3명 즉시, 이후 분당 1명 | 빈 월드에서 기다리지 않게 한다 |
| 진화 배지 숨김 | 튜토리얼이 진화를 가르칠 때까지 | 한 번에 하나만. 빈틈을 배우는 동안 ▲가 끼어들지 않는다 |
| 진화 보장 | 진화 단계에서 20초 넘게 기다리면 근속을 채운다 | 플레이어가 느려 버프가 끝나도 튜토리얼이 막히지 않는다 |

### 완전 클리어

| 항목 | 수량 |
|---|---|
| 엔딩 (5장 결재) | 1 |
| 던전 ★3 | 15곳 |
| 직원 도감 | 36종 (10계열 × 3단계 + 보스 5 + 발록) |

## 7. 콘텐츠 — 지역과 몬스터 계열

**변화는 새 규칙이 아니라 새 몬스터 계열로 준다** (P1). 계열마다 특성 하나.

| 특성 아이콘 | 이름 | 효과 |
|---|---|---|
| ⏩ | 빨리 큰다 | 근속 ×1.5 |
| 🎁 | 잘 퍼준다 | 이 던전 스마일 ×1.3 |
| 💪 | 튼튼하다 | 이 던전 레벨업 ×1.2 |
| — | 표준 | 없음 |

| 지역 | 계열 (1단계 → 2단계 → 3단계 → 보스) | 기본 레벨 | 특성 |
|---|---|---|---|
| 헤네시스 | 달팽이 → 파란 달팽이 → 빨간 달팽이 → **마노** | 2 | ⏩ |
| 헤네시스 | 주황버섯 → 뿔버섯 → 좀비버섯 (보스 없음 — "그 자리는 사장님 자리입니다") | 8 | — |
| 엘리니아 | 슬라임 → 버블 슬라임 → 퍼플 슬라임 → **킹 슬라임** (2·3단계 이름은 가칭) | 15 | 🎁 |
| 엘리니아 | 숲 계열 1종 (확인 후 확정) | 20 | — |
| 페리온 | 스텀프 → 다크 스텀프 → 액스 스텀프 → **스텀피** (3단계 이름은 가칭) | 28 | 💪 |
| 페리온 | 멧돼지 계열 (와일드보어 → 파이어보어 → 확인) | 34 | — |
| 커닝시티 | 2계열 + 보스 1 (확인 후 확정) | 42, 48 | ⏩, 🎁 |
| 슬리피우드 | 2계열 + 보스 1 (확인 후 확정) + **주니어 발록** (스토리) | 55, 60 | 💪, — |

**계열 레벨은 지역을 넘나든다.** 헤네시스의 달팽이는 마노(Lv 26)가 되면 엘리니아 구간을 맡는다. **아래 지역에서 자란 몬스터가 위 지역으로 발령 가는** 흐름이 챕터를 잇는다.

## 8. 시뮬레이션 — 서버 시간

```
월드 상태 = step^n(마지막 저장 상태),   n = min(경과 분, 1440)
step = 1분: 도착 → 이동 판정 → 레벨업 → 퇴근 분배 → 스마일 → 결재 판정
```

- 클라이언트 틱에 의존하지 않는다. 화면이 켜져 있든, 탭이 뒤로 갔든, 접속이 끊겼든 **같은 함수**로 계산한다.
- 계산 단위는 던전별 레벨 분포다. 던전 15 × 레벨 70 칸 × 1,440단계라서 서버 부담이 작다.
- 화면이 켜져 있으면 같은 `step`을 작은 걸음(초 단위)으로 부른다. 결과는 1분 걸음과 같은 규칙을 따른다. R3의 "구간을 벗어나면 레벨업 중단"이 걸음 크기와 상관없이 같은 결과를 보장한다.
- 2분 안에 돌아오면(새로고침 등) 리포트 없이 흐른 시간만 조용히 계산한다. 2분을 넘기면 출근 리포트를 띄운다.
- 오프라인 상한 24시간. 넘으면 월드는 멈추고, 복귀 시 오렌이 "매니저님 어디 가셨었어요?!"라고 한다. 손해는 없다.
- 난수는 월드 시드로 결정적이다. 같은 입력이면 같은 결과가 나온다(재현성, 서버-클라 일치).
- **화면은 결과를 그릴 뿐 바꾸지 않는다.** 현장 연출(퇴근, 레벨업 빛기둥)은 이번 분의 계산 결과를 샘플링해 재생한다.

## 9. 튜닝 레버와 리스크

| 리스크 | 증상 | 레버 |
|---|---|---|
| 할 일이 없다 | 체크인마다 결정이 0개 | 진화 임계값을 낮춘다 → 월드가 더 빨리 "위로 자란다" |
| 할 일이 너무 많다 | 체크인이 3분을 넘는다 | 진화 임계값을 올린다, 이벤트 칸을 줄인다 |
| 과밀 지옥 | 후반에 😠만 보인다 | 자리 확장 비용을 낮춘다, 도착률 곡선을 누른다 |
| 정답 배치가 굳는다 | 진화를 영영 보류한다 | 도감·결재가 진화를 요구한다. 그래도 굳으면 3단계 몬스터의 근속 효과 추가를 검토 |
| 떠남이 스트레스다 | 😢에 민감한 플레이어 | 떠남 사유를 **다음 행동 제안**으로만 보여준다 ("숲 자리 +4?"). 누적 떠남 수는 표시하지 않는다 |
| 후반 스마일 과잉 | 2장 이후 수만 스마일이 쌓인다 (봇 D7 기준) | 부지·자리 비용을 챕터 곡선으로 올린다. 또는 후기 스펙의 치장을 사용처로 연다. 1단계 플레이테스트로 정한다 |

**페이싱 점검 결과 (v1.1 수치, `node prototype/pacing-check.js`):** 첫 레벨업 0:25 · 첫 빈틈 3:25 · 10시간 뒤 첫 출근 리포트 😊 14·레벨업 678·스마일 +3,269·진화 가능 2 · 봇 매니저(하루 2~3회, 체크인당 2~3수) 1장 결재 D2 · 2장 결재 D6~8 · 체크인당 행동 2.2~3.0. 봇은 가능한 수를 전부 계산하므로 사람보다 빠른 쪽이다.

**가장 중요한 동역학:** 월드는 가만히 두면 **위로 자란다.** 몬스터는 일할수록 진화할 수 있게 되고, 진화하면 아래가 빈다. 매니저가 신입을 뽑아 아래를 채운다. 이 순환이 체크인마다 고칠 거리를 만든다.
