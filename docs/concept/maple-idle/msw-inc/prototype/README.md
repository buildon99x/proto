# MSW 주식회사 — 플레이 프로토타입

컨셉 v1.1([../README.md](../README.md))을 실제로 만져 보기 위한 브라우저 프로토타입이다. 설치 없이 `index.html`을 브라우저로 열면 된다.

- **범위:** 입사 컷 → 첫 10분 튜토리얼 → 1장 헤네시스 → 2장 엘리니아 → 3장 페리온 (3장 결재 서류는 "프로토타입은 여기까지"로 닫힌다)
- **저장:** 이 브라우저에만 저장된다. 창을 닫았다 열면 떠나 있던 시간만큼 월드가 굴러가 있고 출근 리포트가 뜬다(최대 24시간)
- **테스트 도구:** HUD 오른쪽 점선 칸. 배속 ×1 / ×60 / ×600, ⏭8h(8시간 뒤 출근), ↺(처음부터, 두 번 누른다). 실제 게임에는 없다
- **도트:** 코드로 그린 자리표시다. 실제 게임은 메이플스토리 월드 공식 리소스를 쓴다

| 파일 | 역할 |
|---|---|
| `sim.js` | 규칙 R1~R5와 수치. [03-systems.md](../03-systems.md)와 같다. 화면과 분리돼 Node에서도 돈다 |
| `pacing-check.js` | `node pacing-check.js` — 첫 10분 시각, 첫 출근 리포트, 봇 매니저의 챕터 달력을 확인한다 |
| `art.js` | 자리표시 도트 |
| `core.js` | 공통: 저장, 소리(WebAudio 합성), HUD, 독, 오렌, 토스트 |
| `world.js` | S1 월드 길: 발판, 모험가, 빈틈, 드래그 미리보기 |
| `dungeon.js` | S2 던전 현장 + S4 매니저 권한 |
| `sheets.js` | S3 진화 · S5 채용 · S6 결재 · S0 출근 리포트 · S7 매니저 퇴근 · 도감 |
| `tut.js` | 입사 첫 10분 ([02 §6.2](../02-player-experience.md#62-첫-10분--입사)) |
| `demo.js` | `index.html?demo=<장면>` 시연 장면. 문서 그림용 |
| `main.js` | 시작과 매 프레임 루프 |
| `render.sh` | `bash render.sh` — 시연 장면을 `shots/*.png`로 굽는다(Chrome headless) |
