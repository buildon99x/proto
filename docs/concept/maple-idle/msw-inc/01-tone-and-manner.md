# 01 — 톤앤매너

> MSW 주식회사 · v1.1 · 2026-09-25 · [README](./README.md) · 바뀐 점은 [05 리뷰](./05-review.md)
>
> **이 문서가 답하는 질문:** 이 게임은 어떤 느낌이고, 그 느낌을 어떤 규칙으로 지키는가.

## 1. 톤 한 줄

> **"월드를 운영하는 몬스터 회사의 밝은 사무실 코미디."**

| 키워드 | 뜻 | 반대편 (하지 않는 것) |
|---|---|---|
| **밝다** | 원작 메이플의 하늘색과 햇살. 실패해도 웃는다 | 어둡거나 냉소적인 풍자 |
| **수다스럽다** | 몬스터와 모험가의 표정이 쉴 새 없이 바뀐다 | 조용한 경영 시뮬레이션 |
| **흐뭇하다** | 사람이 늘고, 몬스터가 자라고, 불이 켜진다 | 압박, 경쟁, 마감 |

## 2. 오마주 원칙 — 몬스터 주식회사

| 빌려오는 것 (구조와 정서) | 우리 게임의 형태 |
|---|---|
| 몬스터가 **회사원**이다 | 몬스터 = MSW 주식회사 직원. 사원증을 단다 |
| 인간의 **감정이 회사의 에너지**다 | 모험가의 즐거움 = **스마일**. 캔에 모아 월드를 밝힌다 |
| 실적 경쟁 게시판 | **퇴근왕** — 매니저가 떠나 있던 동안 가장 많이 쓰러진 직원이 1등 |
| 회사가 **공포에서 웃음으로** 방향을 바꾼다 | 이 회사는 처음부터 웃음을 판다. "맞아드리는 게 저희 일입니다" |

**빌려오지 않는 것:** 원작 영화의 인물, 이름, 장면, 대사, 문(door) 설정. 오마주는 **구조와 정서**까지이고, 소재는 전부 메이플에서 가져온다.

## 3. 시놉시스

> 빅토리아 아일랜드는 사실 **MSW 주식회사**가 운영한다.
>
> 몬스터는 전부 직원이다. 모험가에게 맞아주고, 쓰러지면 **퇴근**하고, 리젠되면 다시 **출근**한다. 회사는 모험가들이 레벨업하고 득템할 때 터지는 웃음, **스마일**을 캔에 모아 월드의 불을 밝힌다.
>
> 요즘 모험가가 줄었다. 스마일 캔이 비어가고, 섬의 불빛도 하나씩 꺼지고 있다. 사장 **머쉬맘**은 결단을 내린다. 월드 전체를 맡을 **신입 월드 매니저**를 뽑는 것. 한때 이 섬에서 모험가였던 당신이다.
>
> 첫 출근 날, 헤네시스 들판에는 달팽이 두 마리와 의욕 넘치는 비서 **오렌**뿐이다. "매니저님!! 모험가님들이 이 월드를 좋아하게 만들면 돼요!! 간단하죠?!"
>
> 몬스터를 키우고, 던전을 잇고, 모험가가 레벨 1부터 끝까지 즐겁게 올라가는 월드를 만든다. 섬에 불이 다시 켜질 때마다 새 지역이 열린다. 그리고 가장 깊은 슬리피우드에서, 오래전 아무도 찾아오지 않던 **주니어 발록**이 입사 지원서를 낸다.

**세 문장 요약:** 모험가의 웃음이 월드의 전기다. 매니저는 몬스터를 키워 모험가를 끝까지 올려보낸다. 섬 전체에 불이 켜지면 엔딩이다.

## 4. 인물 — 셋이면 충분하다 (P4)

| 인물 | 정체 | 역할 | 말투 | 등장 빈도 |
|---|---|---|---|---|
| **머쉬맘 사장** | MSW 주식회사 대표. 보스 몬스터이자 직장 보스 | 챕터 목표를 내리고 **결재 도장**을 찍는다 | 짧고 무게 있다. "좋아요. 결재." | 챕터 시작과 끝 |
| **오렌** | 주황버섯, 매니저 전담 비서 | 안내, 알림, 개그. 플레이어가 가장 자주 보는 얼굴 | 느낌표 두 개. "매니저님!!" | 체크인마다 1줄 |
| **주니어 발록** | 슬리피우드 깊은 곳의 외톨이 | 5장의 동기. 아무도 오지 않아 외로웠다 | 무뚝뚝하다. "…손님인가." | 5장, 엔딩 |

**모험가는 인물이 아니라 군중이다.** 이름도 대사도 없다. 표정과 레벨업 빛기둥으로만 말한다.

## 5. 개그 규칙 — 용어 사전

게임의 모든 용어는 **회사 말투로 치환**한다. 이 표가 UI 문구, 연출, 기획서의 기준이다.

| 게임 사건 | 회사 용어 | 연출 |
|---|---|---|
| 몬스터가 쓰러진다 | **퇴근** | 연기 "펑" + 작은 "퇴근!" 글자 |
| 몬스터가 리젠된다 | **출근** | 사원증을 흔들며 등장 |
| 몬스터 진화 | **진화** — 사원증 사진이 바뀐다 | 번쩍임 → 새 사원증 카드 |
| 몬스터 고용 | **신입 채용** | 신입 사원증 발급 |
| 쓰러진 만큼 차는 게이지 | **근속** — 퇴근할수록 찬다(⏩ 계열은 1.5배). 진화하면 0부터 | 사원증 뒷면의 근속 게이지. 퇴근왕은 따로 실제 퇴근 횟수를 센다 |
| 모험가의 즐거움 | **스마일** | 노란 캔이 차오른다 |
| 챕터 목표 | **결재 서류** | 사장 도장 "쾅" |
| 매니저 접속 종료 | **매니저 퇴근** | 화면이 사무실 소등 컷으로 바뀐다 |
| 매니저 접속 | **매니저 출근** | 출근 도장 + 출근 리포트 |
| 떠나 있던 동안 가장 많이 쓰러진 직원 | **퇴근왕** (리포트에서는 "밤사이 퇴근왕") | 출근 리포트 한 칸. 왕관 쓴 직원 |
| 어느 던전도 맡지 않은 레벨 (막힌 사람 없음) | **끊긴 길** | 땅 위 옅은 빨간 점선. 아직 경고가 아니다 |
| 어느 던전도 맡지 않은 레벨 (막힌 사람 있음) | **빈틈** | 빨간 빗금 + `!` + 멈춘 인원. 메우면 "뚫렸다!" |
| 모험가가 다 즐기고 떠나는 레벨 | **졸업선** | 길 끝의 보라 아치 "🎓 졸업". 결재할 때마다 오른쪽으로 옮겨 간다 |
| 아직 던전이 없는 땅 | **빈 부지** → 직원을 놓으면 **개업** | 독의 점선 칸. 개업 비용이 적혀 있다 |
| 배치하지 않은 직원이 기다리는 곳 | **대기실** | 독 왼쪽 칸. 막 뽑은 신입은 튀어 오른다 |

**개그의 한계선:** 모험가를 비웃지 않는다. 농담의 대상은 항상 **회사와 몬스터 자신**이다.

## 6. 비주얼

### 6.1 두 층의 스타일

| 층 | 스타일 | 근거 |
|---|---|---|
| **월드·던전·캐릭터** | 메이플스토리 공식 2D 리소스 그대로 | IP의 핵심 자산. 새로 그리지 않는다 (P4) |
| **월드 길 (메인 화면)** | 원작 필드처럼 **옆으로 긴 지형 + 떠 있는 발판.** 가로축이 레벨이다. 지역마다 원작 배경(헤네시스 들판, 엘리니아 숲, 페리온 바위…)이 구간으로 이어진다 | 메이플 플레이어에게 익숙한 문법 그대로 "왼쪽에서 오른쪽으로 오른다"가 읽힌다. 섬 지도는 쓰지 않는다([05 B1](./05-review.md)) |
| **UI 크롬** | 메이플 기본 창(흰 둥근 창, 하늘색 머리) + **회사 문구류 액센트** 세 가지: 사원증, 결재 도장, 스마일 캔 | 톤의 "회사"는 UI 소품으로만 표현한다. 월드 그림은 건드리지 않는다 |

### 6.2 색 토큰

| 토큰 | 값 | 쓰는 곳 | 규칙 |
|---|---|---|---|
| `smile` | `#FFC531` | 스마일 캔, 즐기는 모험가 수, 레벨업 빛 | **긍정의 색은 노랑 하나** |
| `flow` | `#3CC47C` | 땅 위 연결 띠, 빈틈 해소 쓸림, 추천 자리 발광 | 잘 돌아간다 |
| `alert` | `#FF5A4E` | 레벨 빈틈, 입구 막힘 | **빨강은 "지금 고칠 곳"에만** |
| `busy` | `#FF9F2E` | 과밀 | 주의 (급하지 않음) |
| `evolve` | `#8B6CFF` | 진화 가능 배지, 진화 연출 | 좋은 소식 |
| `exp-event` | `#3FA9F5` | 경험치 이벤트 링 | 원작 EXP 바의 파랑 계열 |
| `drop-event` | `#FF7BB0` | 드랍 이벤트 링 | |
| `paper` | `#FFFDF6` | 결재 서류, 리포트 카드 | 회사 문서 |
| `ink` | `#2D2A3E` | 본문 글자 | |

**상태 색은 다섯 개뿐이다** (노랑·초록·빨강·주황·보라). 화면에 여섯 번째 의미 색이 생기면 설계를 의심한다.

### 6.3 형태 언어

- **표정이 곧 상태다.** 모험가 머리 위 말풍선에 원작 표정 네 가지만 쓴다: 😊 즐거움, 😐 찾는 중, 😠 붐빔, 😢 떠남. 🎓 졸업은 특별 표시다.
- **알림 배지는 세 가지뿐이다.** 빨간 `!`(빈틈), 주황 소용돌이(과밀), 보라 `▲`(진화 가능). **배지는 문제가 있는 그 물건 위에 뜬다:** `!`는 땅 위, 🌀는 발판 끝, ▲는 직원 머리 위.
- **레벨은 색 그라데이션**으로 읽힌다: 낮은 레벨 연두 → 높은 레벨 보라.

### 6.4 모션

| 순간 | 모션 질감 |
|---|---|
| 퇴근 | 짧고 가볍다 (0.3초 펑) |
| 레벨업 | **원작 그대로 크게.** 빛기둥 + 징글. 이 게임의 가장 큰 긍정 신호 |
| 진화 | 번쩍임 1초 → 사원증 카드가 뒤집힌다 |
| 스마일 획득 | 노란 알갱이가 상단 캔으로 빨려 들어간다 |
| 결재 | 도장이 쾅. 화면이 살짝 흔들린다 |
| 월드 불 켜짐 | 카메라가 천천히 물러나며 다음 지역의 안개가 걷히고, 언덕 위 등불이 하나씩 켜지고, 졸업 문이 오른쪽으로 옮겨 간다 (챕터 완료) |
| 빈틈 해소 | 빨간 빗금이 왼쪽부터 초록으로 쓸린다 + "뚫렸다!". 멈춰 있던 모험가들이 새 발판으로 뛰어오른다 |
| 월드의 레벨업 | 모험가 머리 위 작은 빛기둥 + UP, 오른쪽으로 한 칸 걷는다 (현장보다 작게) |

## 7. 사운드

| 층 | 소리 | 원칙 |
|---|---|---|
| BGM | 원작 지역 BGM 그대로 (헤네시스, 엘리니아, …) | 월드 길에서는 가장 최근에 열린 지역의 BGM, 던전 현장에서는 그 던전 지역의 BGM |
| 긍정 SFX | 원작 레벨업 징글, 원작 메소 소리(→ 스마일 획득음으로 전용) | **익숙한 소리 = 좋은 일** |
| 회사 SFX (신규 4종) | 퇴근 "펑", 출근 도장 "탁", 결재 도장 "쾅", 진화 팡파르 | 회사 소품의 소리로만 신규 제작 |
| 흐름 SFX (신규 2종) | 빈틈 해소 "뽁", 졸업 팡파르(짧게) | 좋은 일에만. 전체 신규 SFX는 이 6종이 전부다 |
| 원작 대체음 | 채용 = 원작 아이템 획득음, 결재 조건 달성·이벤트 시작 = 원작 알림음, 월드의 작은 레벨업 = 원작 레벨업 징글을 짧게, 스마일 = 원작 메소 소리 | 새로 만들지 않는다. 익숙한 소리 = 좋은 일 |
| 경고 | 없음 | 빨간 배지도, 못 하는 행동도 소리를 내지 않는다. 저관여 게임에서 경고음은 스트레스다 (P5) |

## 8. 글 톤

| 종류 | 규칙 | 예 |
|---|---|---|
| UI 라벨 | 명사형, 4자 안팎 | "신입 채용", "결재함", "퇴근왕" |
| 알림 | 10자 안팎, 원인 + 장소 | "숲 입구 자리 없음" |
| 오렌 | 느낌표 두 개, 1줄 | "매니저님!! 버섯이 진화할 수 있대요!!" |
| 머쉬맘 | 마침표, 짧게 | "Lv 30까지 이어요. 그럼 결재." |
| 발록 | 말줄임표 | "…오늘도 아무도 안 오는군." |

**글 총량 목표:** 게임 전체 대사 200줄 이내. 오렌 알림 약 120, 챕터 컷 약 60, 기타 약 20. 리뷰 문장 800줄 계획은 폐기한다.

## 9. 일관성 점검 — 톤과 시스템의 대응

| 시스템 ([03](./03-systems.md)) | 톤 표현 | 일치 여부 |
|---|---|---|
| 몬스터 쓰러짐 → 근속 게이지 → 진화 | 퇴근할수록 성장한다 | ✅ "많이 맞는 게 일 잘하는 것" 개그가 성장 규칙과 같은 방향 |
| 모험가 즐거움 → 스마일 → 월드 운영 자원 | 웃음이 회사의 에너지 | ✅ 궁극 목표와 자원이 같은 것 |
| 월드 인기 상승 → 지역 개방 | 섬에 불이 켜진다 | ✅ 진척이 월드 길의 밝기(안개가 걷힌 구간)로 보인다 |
| 졸업선 → 결재로 연장 | 길이 끝까지 이어지면 "다 즐겼다"며 졸업 | ✅ 졸업은 최선의 퇴장. 보라 아치 + 폭죽 |
| 접속 종료 | 매니저 퇴근 | ✅ 플랫폼 제약이 개그가 된다 |
| 경험치·드랍 이벤트 | 회사 프로모션 | ✅ 원작 메이플 이벤트 문법 그대로 |
| 경고음 없음, 하락 없음 | 밝다, 흐뭇하다 | ✅ |
