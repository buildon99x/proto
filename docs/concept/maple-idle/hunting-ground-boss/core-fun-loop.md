# 사냥터 사장님 — 핵심 재미 & 코어 루프

> 2026-09-24 · v0.2 · 상위 문서: [concept.md](./concept.md) · 관련: [lifecycle.md](./lifecycle.md), [synopsis.md](./synopsis.md)

## 1. 한 문장

> **텅 빈 옛 사냥터에 몬스터를 출근시켜, 모험가들이 다시 "자리 있어요!"를 외치게 만드는 게임.**

플레이어가 파는 것은 사냥이 아니라 **북적임**이다. 그리고 그 북적임은 한때 플레이어 자신이 서 있던 풍경이다.

## 2. 핵심 재미 — 플레이어가 느끼는 다섯 가지

재미를 "플레이어가 실제로 내뱉을 말"로 정의한다. 다섯 개 모두 루프의 특정 순간에 걸려 있어야 하고, 그 순간을 만드는 메커닉이 있어야 한다.

| # | 플레이어의 말 | 감정 | 언제 일어나는가 | 만드는 메커닉 | MDA 축 |
|---|---|---|---|---|---|
| **F1** | **"ㅋㅋ 이거 나잖아"** | 알아보는 웃음 | 리뷰 말풍선을 읽을 때 | 손님 성향 × 상황 문장 풀. 원작 사냥터 밈("자리 있어요", "쩔 구함", "템 줍지 마세요") | Fantasy · Narrative |
| **F2** | **"오늘은 뭐라고 써 있으려나"** | 돌아오는 설렘 | 출근(재접속) 직후 | 오프라인 정산을 숫자가 아니라 **리뷰 더미**로 보여준다. 보스 예약 결과 | Discovery · Submission |
| **F3** | **"아, 딱 맞췄다"** | 퍼즐이 풀리는 쾌감 | 배치를 고친 뒤 불만 색이 사라질 때 | 3축 교환(경험치·자리·드랍). 까다로운 손님이 늘어나는 자기조절 | Optimization (Functional) |
| **F4** | **"여기 다시 사람 많아졌네"** | 되살림의 뿌듯함 | 등급 상승, 지역 개업, 심사 통과 | 텅 빈 맵 → 붐비는 맵의 **시각적 변화 자체가 진척 UI** | Progression · Melancholy → Catharsis |
| **F5** | **"느릿 영감…"** | 애착 | 챕터 컷, 직원 근속 이벤트 | 이름 붙은 직원, 근속 기록, 시놉시스 인물 | Parasocial (서사형) |

**재미의 중심축은 F1 + F3이다.** F1은 이 게임이 메이플이어야 하는 이유이고, F3는 이 게임이 게임인 이유다. F2는 저관여 루프를 굴리는 엔진이고, F4·F5는 10시간을 끌고 가는 장거리 동기다.

### 팔지 않는 재미 (의도적 부재)

| 팔지 않는 것 | 이유 |
|---|---|
| 숫자가 폭증하는 쾌감 | 메이플 키우기의 칸이다. 여기서 성장은 **사람 수와 표정**으로 보인다 |
| 경쟁 압박 | 순위표는 구경거리일 뿐 보상이 걸리지 않는다 |
| 놓치면 손해인 긴박함 | 저관여 약속. 안 들어온 날에도 사냥터는 망하지 않는다 |
| 조작 실력 | 사장은 사냥하지 않는다 |

## 3. 플랫폼 확정 사항과 설계 결정

| 확인된 사실 | 설계 결정 |
|---|---|
| 브라우저 안에서 플레이 | 탭이 뒤로 가면 브라우저가 렌더링과 타이머를 멈춘다. **시뮬레이션을 클라이언트 틱에 맡기지 않는다** |
| 장시간 무입력 시 접속이 끊긴다 | 끊김을 막는 핑이나 가짜 입력은 **만들지 않는다.** 끊김을 디제시스로 쓴다: 화면이 **"사장님 퇴근"**으로 바뀐다 |
| 세션 유지 선호, 단 게임성 우선 | **세션 무관 설계 채택.** 아래 원칙 참조 |
| 치장 판매 가능, 후기 검토 | 이 문서에는 BM이 없다. Fair Progression 가드레일(진척·순위 영향 상품 금지)만 유지한다 |

### 원칙: "시뮬레이션은 서버 시간, 연출은 화면"

```
사냥터 상태 = f(마지막 정산 시각, 현재 시각, 배치 구성)
```

- 사냥터는 **서버 시간 기준 기대값 공식**으로 진행된다. 켜둔 상태, 탭이 뒤로 간 상태, 접속이 끊긴 상태가 **전부 같은 공식**을 쓴다.
- 화면을 보고 있을 때만 **연출**(손님이 걸어 다니고, 몬스터가 퇴근하고, 말풍선이 뜬다)이 재생된다. 연출은 공식 결과를 시각화할 뿐, 결과를 바꾸지 않는다.
- **왜 이게 게임성에 맞는가:** 이 게임의 재미 F2(돌아오는 설렘)는 **떠나 있어야 생긴다.** 세션 유지를 보상하면 F2가 죽고, 끊김 정책과도 싸우게 된다. 떠나는 것을 플레이의 일부로 만든다.

## 4. 코어 루프

### 4.1 한 바퀴 (체크인 1회, 1~3분)

```
 ┌──────────────────────────────────────────────────────────────┐
 │                                                              │
 ▼                                                              │
[출근]  출근 도장 → 밤사이 리뷰 더미 쏟아짐                  (F2)  │
 │                                                              │
 ▼                                                              │
[읽기]  리뷰를 넘기며 웃는다 · 불만 색 점이 어디에 몰렸나 본다  (F1)  │
 │                                                              │
 ▼                                                              │
[진단]  3축 레이더: 경험치 / 자리 / 드랍 중 무엇이 비었나          │
 │                                                              │
 ▼                                                              │
[고치기] 슬롯 교체 · 시설 1개 · 보스 출근 예약 (결정 2~3개)  (F3)  │
 │                                                              │
 ▼                                                              │
[확인]  3초 안에 손님 반응 변화 → 불만 색이 바뀐다          (F3)  │
 │                                                              │
 ▼                                                              │
[퇴근]  떠난다 (또는 잠깐 구경한다 → 현장 모드)                   │
 │                                                              │
 └──────────── 몇 시간 뒤, 사냥터는 계속 돈다 ───────────────────┘
```

**코어 동사:** **배치한다 → 떠난다 → 돌아와서 읽는다 → 고친다.**

### 4.2 두 가지 화면 상태

| | **현장 모드** (화면을 보고 있음) | **정산 모드** (떠나 있었음) |
|---|---|---|
| 진행 | 서버 공식 (동일) | 서버 공식 (동일) |
| 보이는 것 | 실시간 연출: 손님이 걷고, 때리고, 말한다 | 출근 시 리뷰 더미 + 정산서 |
| 할 수 있는 것 | 배치 변경 + **현장 돌발**(원탭) | 배치 변경 |
| 켜두면 생기는 것 | **발견뿐:** 현장 돌발을 해결하면 그 손님이 **단골 도감**에 오른다 | — |
| 켜두지 않으면 잃는 것 | **없음.** 현장 돌발은 기본 결과로 자동 정리된다 | — |

**현장 돌발 예시** (평균 10분에 1회, 원탭, 30초 창)
- "쩔러 전사 난동!" → [경비 달팽이 보내기] → 싹쓸이가 멈추고 초보자가 "감사합니다ㅠㅠ".
- "포션 품절" → [긴급 입고] → 체류가 이어진다.
- "희귀 손님 등장: 전직관 헬레나가 사복으로 방문" → [인사하기] → 단골 도감에 희귀 칸이 찍힌다.

### 4.3 3축 교환 — F3의 심장

모든 배치는 세 축을 **교환**한다. 한 축만 올리는 선택지는 없다.

```
            경험치 (노랑)
               ▲
     밀도↑ 리젠↑ │ 과밀 → 자리 불만
               │
   자리 (파랑) ◀┼▶ 드랍 (분홍)
   발판·쉼터   │   드랍 좋은 몬스터
   = 경험치↓   │   = 수수료↓
```

| 축 | 올리는 법 | 대가 | 대표 불만 |
|---|---|---|---|
| 경험치 | 몬스터 밀도↑, 리젠↑ | 과밀, 월급↑ | "여기 경험치 구림" |
| 자리 | 밀도↓, 발판 확장, 쉼터 | 경험치↓, 시설비 | "자리 있어요!!!" |
| 드랍 | 리본돼지 같은 드랍 좋은 직원 | 수수료 수입↓ | "30분째 템이 하나도 안 떠요" |

**자기조절:** 별점이 오르면 까다로운 손님(효율충, 드랍충)이 늘어난다. 어제의 최적 배치가 오늘은 불만을 만든다. **잘할수록 다음 퍼즐이 온다.** 사냥터가 솔브드되는 것을 막는 핵심 규칙이다.

**지역마다 축 하나가 깊어진다** (세부는 [lifecycle.md](./lifecycle.md) §3)

| 지역 | 깊어지는 것 | 새 규칙 |
|---|---|---|
| 헤네시스 | 3축 기본 | 슬롯 배치 |
| 엘리니아 | **자리** | 층 — 나무 위 여러 층, 동선 시설(밧줄·사다리) |
| 페리온 | **경험치** | 위험 — 몬스터가 반격, 손님이 쓰러지면 마을로 귀환 |
| 커닝시티 | **손님 시장** | 라이벌 사냥터와 손님을 나눠 갖는다, 쩔 시간대 |
| 슬리피우드 | **드랍** | 깊이 — 던전 층 연결, 깊을수록 드랍↑ 도달 손님↓ |

### 4.4 시간 스케일 루프

| 스케일 | 주기 | 무엇이 도는가 | 주 감정 |
|---|---|---|---|
| **초** | 1~5초 | 손님이 때린다 → 몬스터 퇴근(펑) → 드랍 → 수수료 짤랑 → 말풍선 | 구경의 흐뭇함 |
| **분** | 2~5분 | 손님 입장 → 사냥 → 만족/불만 → 퇴장 리뷰 1줄 · 현장 돌발 | F1 |
| **체크인** | 1~3분, 하루 2~4회 | §4.1의 한 바퀴 | F2 → F3 |
| **일** | 하루 | 별점 누적 → 손님 구성 변화 → 새 불만 → 보스 예약 결과 | F3 |
| **챕터** | 약 1주 | 지역 개업 → 새 규칙 → 등급 C→S → 전직관 심사 → 챕터 컷 | F4 · F5 |
| **메타** | 5~7주 | 지역 5곳 + 개미굴 → 엔딩 → 완전 클리어 | F4 · F5 |

**루프 교차점** — 전환 순간에 감정 보상을 몰아준다.

| 순간 | 넘어가는 것 | 연출 |
|---|---|---|
| 출근 | 정산 → 체크인 | 리뷰 말풍선이 쏟아지는 컷 (F2의 정점) |
| 등급 상승 | 일 → 챕터 | 조합 승진 편지 + 슬롯 확장 + 맵에 손님이 눈에 띄게 늘어남 |
| 전직관 심사 | 챕터 절정 | 사복 전직관이 하루 동안 손님으로 다녀가고 **심사평 리뷰**를 남긴다 |
| 지역 개업 | 챕터 → 챕터 | 텅 빈 새 맵, 녹슨 표지판 → 첫 손님 입장 |

### 4.5 관여도 예산 (v0.2 개정)

| 항목 | 예산 |
|---|---|
| 체크인 | 하루 2~4회, 각 **1~3분** |
| 체크인당 결정 | **2~3개** |
| 현장 모드 구경 | 선택. 하루 0~10분 |
| 체크인 사이 필수 입력 | **0회** |
| 안 들어온 날의 손해 | 별점 성장이 멈출 뿐, **하락이나 폐업 없음** |
| 동시 운영 사냥터 | **최대 3곳.** A등급 이상 사냥터는 위탁 운영으로 넘길 수 있다(성장은 느려지고 관리 목록에서 빠진다). S등급은 직접 운영해야 달성된다 |
| 오프라인 정산 상한 | 24시간 |

**하루 평균 활성 시간 목표:** 10~20분 (체크인 3회 × 3분 + 구경 5분). 누적 계산은 [lifecycle.md](./lifecycle.md) §2.

## 5. toy-first 점검

**보상을 전부 빼도 만지는 게 즐거운가?**

- 주황버섯 한 마리를 놓으면 3초 안에 초보자가 달려와 때린다. → **예.**
- 슬라임을 과하게 넣으면 분열해서 맵이 난장판이 되고 말풍선이 폭발한다. → **예.** 망치는 것도 재밌다.
- 리뷰를 읽는 것 자체가 웃기다. → **문장 품질에 달렸다.** 이 컨셉의 최대 제작 리스크다([concept.md](./concept.md) §13).
