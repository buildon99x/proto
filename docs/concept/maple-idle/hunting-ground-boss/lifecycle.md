# 사냥터 사장님 — 플레이어 라이프사이클 (진입 → 완전 클리어)

> 2026-09-24 · v0.2 · 상위 문서: [concept.md](./concept.md) · 관련: [core-fun-loop.md](./core-fun-loop.md), [synopsis.md](./synopsis.md)
>
> 수치(일수·분·개수)는 **초기 목표치**다. 1단계 플레이테스트로 교정한다.

## 1. 클리어 정의

| 단계 | 조건 | 목표 달력 기간 | 목표 활성 시간 |
|---|---|---|---|
| **메인 엔딩** | 5개 지역 전부 A등급 + 5장 합동 심사 통과 → 엔딩 컷 | 약 5주 | **약 12시간** |
| **완전 클리어** | 메인 엔딩 + 사냥터 10곳 전부 S등급 + 직원 도감 30/30 + 손님 도감 30/30 + 에필로그(오르비스 지부) 완료 | 약 7주 | **약 15시간** |

**요구사항 "완전 클리어까지 10시간 이상" 충족:** 표준 플레이어 기준 약 15시간이다. 메인 엔딩만으로도 10시간을 넘는다.

**"활성 시간"의 정의:** 화면을 보고 있는 시간(체크인 + 현장 모드 구경). 사냥터가 혼자 돌아가는 오프라인 시간은 넣지 않는다.

## 2. 볼륨 산정 — 10시간은 어디서 나오는가

### 2.1 표준 플레이어 모델

하루 체크인 3회(각 약 3분) + 현장 구경 약 5분 = **하루 약 15~20분.** 초반과 챕터 절정에는 조금 더 길다.

| 구간 | 달력 | 일평균 활성 | 소계 | 누적 |
|---|---|---|---|---|
| 진입 + 온보딩 (프롤로그) | Day 1 | 75분 | 1.3h | 1.3h |
| 1장 헤네시스 | Day 2~5 | 25분 | 1.7h | 3.0h |
| 2장 엘리니아 | Day 6~11 | 20분 | 2.0h | 5.0h |
| 3장 페리온 | Day 12~18 | 18분 | 2.1h | 7.1h |
| 4장 커닝시티 | Day 19~26 | 18분 | 2.4h | 9.5h |
| 5장 개미굴 + 엔딩 | Day 27~35 | 20분 | 3.0h | **12.5h — 메인 엔딩** |
| 완전 클리어 구간 | Day 36~49 | 12분 | 2.8h | **15.3h — 완전 클리어** |

### 2.2 플레이 성향별 편차

| 성향 | 하루 활성 | 완전 클리어 달력 | 완전 클리어 활성 시간 |
|---|---|---|---|
| 가벼운 플레이어 (하루 2회, 구경 없음) | 약 8분 | 약 9주 | 약 9~10시간 |
| **표준** (하루 3회 + 구경 5분) | 약 18분 | **약 7주** | **약 15시간** |
| 열성 플레이어 (하루 4회 + 구경 많이) | 약 35분 | 약 6주 | 약 25시간 |

**진행 속도의 결정 요인:** 별점은 서버 시간에 따라 쌓이지만, **쌓이는 속도는 배치 적합도**가 정한다. 손님 구성이 바뀌면 적합도가 떨어지므로 고치러 와야 한다. 그래서 자주 오는 플레이어가 조금 더 빠르다. 다만 켜둔 시간 자체로는 빨라지지 않는다. 열성 플레이어의 추가 시간은 **구경, 단골 도감, 꾸미기**로 채운다.

### 2.3 콘텐츠 인벤토리 — 15시간을 채우는 물량

| 항목 | 수량 | 비고 |
|---|---|---|
| 지역 | 5 + 에필로그 1 | 지역마다 새 규칙 1개 |
| 사냥터 맵 | 10 + 개미굴 5층 | 지역당 2곳. 원작 맵 재사용 |
| 몬스터 직원 | 30종 | 지역당 5~6종. 종마다 특성 1개 |
| 지역 보스 | 5종 | 보스 출근 예약 |
| 손님 유형 | 30칸 (일반 20 + 희귀 10) | 희귀: 전직관 6, 라이벌 사장, 메이플 아일랜드 출신 초보 등 |
| 시설 | 20종 | 지역당 3~4종 해금 |
| 리뷰 문장 | 약 800줄 | 상황 × 성향 × 지역 조합. **최대 제작 비용** |
| 챕터 컷 | 약 14개 | 개업·심사·엔딩·에필로그 |
| 느릿 영감 혼잣말 | 약 150줄 | 체크인 1회에 1줄 |

## 3. 라이프사이클 전 과정

### 3.0 한눈에

```
감정
 ▲                                                        ★엔딩
 │                                               발록 ─┐   "자리 있어요!!!"
 │                          다크로드 심사 ─┐          │  ╱‾‾‾‾╲ 에필로그
 │             헬레나 심사    ╱‾‾‾‾‾╲      ╱‾‾╲    ╱‾‾‾╲ ╱       ╲___
 │   첫 리뷰   ╱‾‾╲    ╱‾‾╲ ╱       ╲    ╱    ╲__╱    ╲╱   아련함
 │  ╱‾‾╲    ╱    ╲__╱    ╲╱ 층 발견  ╲__╱ 라이벌 긴장
 │ ╱ 쓸쓸 ╲__╱ 첫 출근의 설렘
 └──────────────────────────────────────────────────────────────▶ 시간
   D1   D2~5     D6~11    D12~18   D19~26   D27~35   D36~49
   프롤  1장      2장      3장      4장      5장+엔딩  완전 클리어
```

**설계 원칙:** 챕터마다 **새 규칙 → 적응 → 심사 절정** 한 번씩. 절정 사이 골짜기에 **다음 챕터의 새 규칙**이 도착한다.

### 3.1 진입 — 첫 10분

**목표:** 3분 안에 첫 리뷰(F1), 10분 안에 "떠나도 돌아간다"를 이해시킨다.

| 시각 | 일어나는 일 | 플레이어가 하는 것 | 느끼는 것 |
|---|---|---|---|
| 0:00 | 텅 빈 헤네시스 들판. 녹슨 표지판. 원작 BGM이 조용히 흐른다 | — | 아련함. "여기 이렇게 비었었나" |
| 0:20 | 조합장 머쉬맘이 열쇠를 건넨다. **"옛날 첫 직업이 뭐였어요?"** | 5직업 중 하나 선택 | 내 과거가 불렸다 |
| 0:40 | 오렌 등장. "사장님!! 직원을 출근시켜 볼까요!!" | 빈 슬롯에 주황버섯 드래그 | — |
| 1:00 | 주황버섯 5마리가 발판 위에 선다. 사원증을 달고 있다 | — | 피식 |
| 1:30 | **개업 첫날 버프**(오렌이 전단지를 뿌렸다): 첫 세션만 손님 유입이 빠르다. 내가 고른 직업의 초보자가 들어와 버섯을 때린다. 버섯이 연기 속에 "퇴근" | 구경 | "ㅋㅋ 퇴근" |
| 2:30 | **첫 리뷰:** "여기 사람 없어서 좋아요 ㅎㅎ" | 리뷰 탭 | **F1 첫 발동** |
| 3~6분 | 손님이 늘고, 과밀이 되고, 파란 말풍선 "자리 있어요!!" | 오렌 안내로 발판 확장 or 버섯 1마리 빼기 | **F3 첫 발동** — 고쳤더니 불만 색이 바뀐다 |
| 6~8분 | 느릿 영감 첫 등장. "…어디서 본 얼굴인데." | — | 궁금함 (복선) |
| 8~10분 | 머쉬맘 보스 출근 예약 소개. "이따 저녁 7시에 출근시켜 볼래요?" 오렌: "사장님 퇴근하셔도 사냥터는 돌아가요!!" | 예약 시각 선택 | **다음에 올 이유**가 생겼다 |

**첫 세션 종료 조건:** 헤네시스 들판 D → C등급. 이후 세션은 자유 퇴근.

### 3.2 온보딩 완료 — Day 1 나머지 ~ Day 2 첫 출근

**가장 중요한 순간은 Day 2의 첫 출근이다.** 여기서 F2(돌아오는 설렘)가 성립하지 않으면 이 게임은 끝난다.

첫 오프라인 정산에 **반드시** 들어가는 것:
1. 리뷰 더미 15건 이상. 적어도 하나는 **웃긴 이야기**가 있다 — 예: 쩔러 전사가 처음 등장해 난동, 다른 손님들의 연쇄 불만.
2. 어제 예약한 머쉬맘 출근 결과 — "손님 32명 동시 접속, 자리 불만 폭발, 수익 역대 최고."
3. 느릿 영감 한 줄 — "…어젯밤엔 오랜만에 시끄러웠지."
4. **고칠 거리 1개** — 별점이 올라 효율충 궁수가 오기 시작했고, 노란 불만이 생겼다.

### 3.3 1장 헤네시스 (Day 2~5) — "되살림을 배운다"

| 항목 | 내용 |
|---|---|
| 플레이어 목표 | 헤네시스 들판 C → A. 두 번째 사냥터(헤네시스 사냥터 II) 개업 |
| 배우는 것 | 3축 교환, 손님 성향 5종, 보스 예약, 시설(쉼터 의자, 포션 상점) |
| 새로 열리는 직원 | 달팽이, 주황버섯, 슬라임(분열), 리본돼지(드랍), 스텀프(맷집) |
| 절정 | **헬레나 사복 심사** — 하루 동안 손님으로 다녀가고 심사평 리뷰를 남긴다. 통과하면 챕터 컷: 느릿 영감이 당신의 첫 직업 초보자를 보며 "…자네, 그 초보였군." |
| 감정 | 흐뭇함 → 애착 |
| 이탈 위험 | Day 3~4 "매일 같은 걸 고친다" |
| 대응 | 별점 구간마다 손님 구성이 바뀐다(초보자 위주 → 효율충 유입 → 드랍충 유입). 고칠 거리가 매일 달라진다 |

### 3.4 2장 엘리니아 (Day 6~11) — "공간을 설계한다"

| 항목 | 내용 |
|---|---|
| 새 규칙 | **층.** 나무 위 발판이 여러 층이다. 마법사 손님은 텔레포트로 층을 오가지만 다른 직업은 밧줄·사다리가 있어야 한다. **자리 축에 수직 차원이 생긴다** — 층을 쓰면 자리가 넉넉해지지만 동선이 끊기면 위층이 비어 있다 |
| 새 결정 | 동선 시설을 어디에 놓을까 / 어느 층에 어떤 직원을 둘까 |
| 부하 관리 | 헤네시스 사냥터 2곳 + 엘리니아 = 동시 3곳. **A등급 사냥터 위탁 운영 해금** — 성장은 느려지지만 관리 목록에서 빠진다 |
| 절정 | 하인즈 심사. 챕터 컷: 마법사 손님들이 텔레포트로 층을 누비는 풍경 |
| 감정 | 발견 — "이런 것도 되네" |
| 이탈 위험 | 관리 대상 증가로 체크인이 길어진다 |
| 대응 | 위탁 운영. 동시 운영 상한 3곳을 코드 제약으로 박는다 |

### 3.5 3장 페리온 (Day 12~18) — "위험을 판다"

| 항목 | 내용 |
|---|---|
| 새 규칙 | **위험.** 바위산 몬스터는 손님을 되받아친다. 손님이 쓰러지면 마을로 귀환한다(자리가 비고 불만이 남는다). 대신 전사 손님은 **위험한 사냥터를 선호**한다. **경험치 축이 깊어진다** — 센 몬스터 = 경험치↑ = 귀환↑ |
| 새 결정 | 포션 상점과 쉼터로 위험을 관리할지, 위험을 그대로 팔아 전사 손님을 받을지 |
| 새 직원 | 와일드보어, 파이어보어, 다크 스텀프 등 (리소스 확인 후 확정) · 보스 스텀피 |
| 절정 | 주먹펴고일어서 심사. 전사 손님 리뷰 "여기 손맛 있네" |
| 감정 | 긴장 → 뿌듯함 |
| 이탈 위험 | 중반 권태 (Week 2~3). 가장 위험한 구간이다 |
| 대응 | 첫 **특화 사냥터** 칭호 해금("전사의 성지", "뉴비 천국" 등) — 3장부터 사냥터에 **정체성**이 생긴다. 직원 근속 이벤트 시작(10일 근속한 주황버섯의 특성 강화) |

### 3.6 4장 커닝시티 (Day 19~26) — "시장을 읽는다"

| 항목 | 내용 |
|---|---|
| 새 규칙 | **손님 시장.** 라이벌 레이스 사장의 사냥터가 같은 손님 풀을 나눠 갖는다. 라이벌은 과밀·고효율이라 효율충을 빨아들인다. **쩔 시간대 예약**이 생긴다 — 쩔러를 특정 시간에만 받으면 다른 시간은 쾌적하다 |
| 새 결정 | 라이벌과 같은 손님을 두고 싸울지, 라이벌이 놓친 손님(초보자, 자리 민감형)을 받을지 |
| 절정 | 다크로드 심사. 라이벌의 과밀 사냥터에서 지친 손님들이 넘어온다. 레이스 사장이 당신의 쉼터를 보고 조용히 따라 만든다 |
| 감정 | 경쟁심 → 화해 |
| 이탈 위험 | 경쟁 스트레스 |
| 대응 | 라이벌은 손님을 뺏어도 **당신을 망하게 할 수 없다.** 별점 하락 없음. 이기는 방법이 "차별화"뿐이라 싸움이 아니라 퍼즐이다 |

### 3.7 5장 슬리피우드 개미굴 + 엔딩 (Day 27~35) — "가장 깊은 곳까지"

| 항목 | 내용 |
|---|---|
| 새 규칙 | **깊이.** 개미굴은 5층 던전이다. 손님은 위층에서 시작해 만족하면 한 층 더 내려간다. 깊을수록 드랍이 좋지만 도달하는 손님이 줄어든다. **드랍 축이 깊어진다** — 층마다 중간 쉼터와 동선을 설계해 손님을 "내려가고 싶게" 만든다 |
| 새 결정 | 층별 난이도 곡선을 어떻게 그릴까 |
| 목표 | 손님이 5층 발록 앞까지 도달하게 한다 |
| 절정 | **5인 합동 심사** — 카이린이 노틸러스에서 배를 타고 온다. 베테랑 파티가 발록 층에 도달하고, 발록이 수년 만에 "퇴근"한다 |
| 엔딩 | 조합장 머쉬맘이 조합장 자리를 제안한다. 빅토리아 전역 인구 컷. 헤네시스 광장에 **"자리 있어요!!!"** 말풍선이 화면을 채운다 |
| 감정 | 아련함 → **카타르시스** |
| 이탈 위험 | 엔딩 직후 목적 상실 |
| 대응 | 엔딩 컷 직후 **완전 클리어 체크리스트**와 에필로그 떡밥(오르비스 지부 편지)을 바로 보여준다 |

### 3.8 완전 클리어 구간 (Day 36~49) — "다 채운다"

| 항목 | 내용 |
|---|---|
| 목표 | 사냥터 10곳 S등급, 직원 도감 30/30, 손님 도감 30/30(희귀 포함), 에필로그 |
| 플레이 | 위탁 운영 중이던 사냥터를 하나씩 다시 맡아 S로 올린다. 희귀 손님은 **현장 모드에서만** 단골이 된다 |
| 에필로그 | 오르비스 지부 — 지금까지의 규칙(층·위험·시장·깊이)이 한 맵에 섞인 최종 퍼즐 |
| 마지막 컷 | 느릿 영감의 은퇴식. 영감이 떠날지 "한 번만 더" 출근할지는 플레이어의 선택 |

### 3.9 완전 클리어 이후 (범위 밖, 라이브 가설)

- **계절 이벤트** — 원작 맵 재사용(해변, 눈 내리는 엘나스)으로 한정 사냥터. 치장 보상만 준다.
- **Phase 2: 진짜 손님** — 다른 플레이어가 자기 캐릭터를 내 사냥터에 맡겨둔다. [README](../README.md)의 장기 가설.
- **인기 사냥터 순위** — 구경거리. 보상은 걸지 않는다.
