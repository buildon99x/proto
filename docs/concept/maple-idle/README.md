## 왜 메이플인가 — 출발 명제

> **메이플은 원래 반쯤 방치하며 하던 게임이었다.** 플레이어가 이미 저관여로 하던 행동을 코어 동사로 삼으면, IP가 스킨이 아니라 문법이 된다.

| 원작에서 이미 있던 저관여 행동 | 이 폴더에서 쓰는 곳 |
|---|---|
| 의자에 앉아 잠수, VIP 사우나(공식 잠수 맵) | 창틀 사냥꾼 — 쉼터·의자 |
| 자리 잡고 같은 몬스터 반복 사냥, 펫 줍기 | 창틀 사냥꾼 — 자동 사냥 |
| 사냥터에서 모르는 사람과 나란히 사냥하던 기억 | 창틀 사냥꾼 — 동행(co-presence) |
| 리젠, 자리싸움("자리 있어요"), 사냥터 인기 | 사냥터 사장님 — 코어 시스템 전체 |
| 고용상인을 열어두고 로그아웃 | 사냥터 사장님 — 오프라인 정산 |
| "헤네시스 BGM 1시간" 틀어두고 공부 | 창틀 사냥꾼 — 소리 우선 설계 |

저관여에 강한 IP 자산 순서: **① 소리**(레벨업 징글·메소 줍는 소리·BGM — 안 봐도 전달된다) → **② 횡스크롤 2D**(가로로 긴 띠에 맞는다) → **③ 몬스터 캐릭터성** → **④ 커뮤니티 밈**.

## 시장 전제 — 가장 중요한 사실 하나

**메이플 IP 방치형 RPG 자리는 이미 찼다.**

- 넥슨·에이블게임즈의 **메이플 키우기**는 2025년 11월에 출시되어 국내 양대 마켓 매출 1위에 올랐다 `[집계-B, 모바일인덱스 · 연합뉴스 2025-11-15]`. 출시 45일 만에 누적 매출 1억 달러를 넘겨 2025년 신작 방치형 RPG 중 전 세계 매출 1위다 `[집계-B, Sensor Tower]`. 2026년 3월 월매출은 452억 원이다 `[집계-A, 넥슨 제공 · 네이트뉴스 2026-04-06]`.
- 2026년 7월에는 "이용자 불만 폭주에도 매출 순위 상승"이라는 보도가 있었다 `[해석:합의·T3, 인더스트리뉴스 2026-07-24]`. 수요는 크지만 Fair Progression 불만이 쌓이고 있다는 신호로 읽는다 `[해석:개인]`.
- MSW에서는 옛 메이플을 재구성한 **메이플랜드**(2023)가 노스탤지어 수요를 증명했다 `[공식·T1, MSW 월드 페이지]`.

**결론:** "자동 사냥으로 숫자를 키우는 메이플"을 또 만들면 레드플래그 R1(me-too)과 R5(포화)가 동시에 켜진다. 두 컨셉 모두 **메이플 키우기와 다른 동기**를 판다.

| | 메이플 키우기 | 창틀 사냥꾼 | 사냥터 사장님 |
|---|---|---|---|
| 판매 감정 | 키우는 재미 (Progression) | 켜두는 위안 (Solace) | 역할 반전 + 배치 최적화 (Fantasy · Optimization) |
| 성장 | 수직 — 전투력·스테이지 | 수평 — 여정·수집 | 사업 — 사냥터 등급·지역 |
| 과금 압력 | 성장 가속 | 치장만 | 치장만 (수익 모델은 후기 검토) |
| 관여도 | 중 (성장 관리·가챠) | 최저 (필수 입력 0) | 저 (하루 2~4회 체크인) |

## 플랫폼 전제 — MSW

| 항목 | 확인 결과 | 설계 영향 |
|---|---|---|
| 실행 방식 | **브라우저 안에서 플레이** (사용자 확인, 2026-09-24) | 탭이 뒤로 가면 브라우저가 렌더링·타이머를 멈춘다. 게임 결과를 클라이언트 틱에 맡기지 않는다 |
| 무입력 | **오래 입력이 없으면 접속이 끊긴다** (사용자 확인) | 끊김 방지 입력은 만들지 않는다. 사냥터 사장님은 끊김을 "사장님 퇴근"으로 연출한다 |
| 세션 유지 | 선호하지만 게임성에 맞는 쪽을 택한다 (사용자 확인) | 사냥터 사장님은 **세션 무관 설계**를 택했다 — 시뮬레이션은 서버 시간, 연출은 화면. 근거는 [core-fun-loop.md §3](./hunting-ground-boss/core-fun-loop.md#3-플랫폼-확정-사항과-설계-결정) |
| 치장 판매 | 가능. **후기 스펙에서 검토** (사용자 확인) | 컨셉 단계에는 BM이 없다. Fair Progression 가드레일만 유지한다 |
| 공식 리소스 | 사용 가능 (사용자 확인) | 스프라이트·맵·BGM을 그대로 쓴다. 자체 도트 비용 0 |
| 서버 저장 | 사용자별 서버 저장소 `[해석:개인, 크리에이터 문서 기준 — 확인 필요]` | Save System Integrity를 서버에서 보장한다 |
| 멀티플레이 | 월드 = 여러 유저가 함께 들어오는 공간 | 창틀 사냥꾼의 **동행**, 사냥터 사장님 Phase 2(진짜 손님)의 기반 |

**아직 확인 필요:** ① 브라우저 환경에서 서버 저장소와 서버 시각을 쓸 수 있는가. ② 무입력 끊김까지 몇 분인가. ③ 모바일도 브라우저인가, 앱인가.

## 추천

**사냥터 사장님을 먼저 진행한다.** 브레인스토밍 때는 창틀 사냥꾼을 1순위로 봤지만, 메이플 키우기의 시장 지배를 확인하고 순서를 바꿨다.

- 사냥터 사장님은 역관점이라는 **메커닉 차별**(I2)이 분명하고, 메이플 키우기와 겹치는 칸이 없다. 흥미로운 결정("한 마리 더 풀까")이 한 줄로 박힌다.
- 창틀 사냥꾼은 스코프가 가장 작고 IP 적합도가 가장 높다. 하지만 결정이 약하고(5번 항목 2점), 화면만 보면 "메이플 키우기의 가벼운 버전"으로 읽힐 위험이 있다. **동행(co-presence)이 실제로 위안을 만드는지**를 먼저 싸게 검증해야 한다.

**두 컨셉을 잇는 장기 가설** (지금은 스코프 밖): 창틀 사냥꾼의 캐릭터가 사냥터 사장님의 손님이 된다. 한쪽은 캐릭터를 맡겨두고, 다른 쪽은 사냥터를 운영한다. 둘 다 저관여인 비동기 양면 구조다.
