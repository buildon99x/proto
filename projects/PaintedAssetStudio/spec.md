# Specification
JSON jobs define preset, named pigment palette, seed, native replay width and height, output filename, max correction rounds, and engine timeout. Generate original Lua; invoke pinned upstream easel; save staged PNG observations and revision notes. Approval is an explicit CLI operation requiring the latest PNG hash and a review note; exports contain PNG, Lua and manifest with license, source/build hashes and dimensions. Same binary/settings/log/native resolution must reproduce identical decoded RGB pixels. Local presets only; no LLM dependency. Icon is explicitly RGB opaque. Preview resizing is distinct from native replay.
