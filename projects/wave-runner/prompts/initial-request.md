# Initial Request

"space wave + rogue like" 신규 프로젝트.

원버튼 지그재그 회피 게임의 강점과 문법을 계승하되, Mastery ★★★★인데 Optimization ☆라서 Mastery 축군이 성립하지 않는 약점과 단일 입력의 표현력 한계를 로그라이크 문법으로 극복해 업그레이드된 장르를 발굴한다.

확정된 방향 (대화 중 결정):

- 스크롤 축: **횡스크롤** (버튼이 중력축을 제어해야 조작이 설명을 요구하지 않는다)
- 빌드 대상: **부사 3축** — 동사는 하나로 고정하고 수행 계수만 바꾼다. 동사 슬롯 시스템은 암기를 요구해 폐기
- 선택 전달: **게이트 2택**, 선택 행위가 곧 회피 조작이라 게임이 멈추지 않는다
- 모드: **Endless + Stage**. Stage는 Endless에 시드와 종료선을 더한 것으로, 엔진을 100% 공유한다
- 착수: **1단계 수직 슬라이스** — 빌드도 게이트도 없이 기저 비행만. 중단 판정을 통과해야 2단계로 간다

설계 근거는 `docs/kb/mda-analysis/` 의 세 문서에 있다.
