# 벽 도료 — e2e 설계

> **범위:** [margin-space.md](./margin-space.md) 아이디어 5의 전체 설계. 여백 레이어의 세 번째 입주자(M3)다.
> 공통 불변 조건은 [margin-space-e2e.md](./margin-space-e2e.md), 질감은 [margin-texture.md](./margin-texture.md)에 있다.
> **작성:** 2026-09-16. 구현과 같은 변경에서 썼으므로 수치는 전부 실측이다.

## 0. 결론

**도료는 힘을 1도 주지 않는 첫 보상이고, 그래서 "보이는가"가 유일하게 어려운 문제다.**

원래 사양은 [margin-texture.md](./margin-texture.md) §3.5의 *"도료는 질감의 틴트 색상만 교체하고 패턴 구조·간격·방향·대비는 유형이 정한다"* 였다. 구현 전에 재보니 **그 사양으로는 도료가 화면에서 구분되지 않는다.** 질감 잉크는 벽의 12.5~14.6%만 덮으므로, 잉크 색을 아무리 바꿔도 벽의 평균색은 **ΔE 0.00~3.22**밖에 움직이지 않는다. 인접 패치의 식별 한계가 2.3이고 여기는 저대비 잔무늬가 흩어진 어두운 면이니, 사실상 **여러 쌍이 같은 색**이다.

그래서 사양을 넓힌다 — **도료는 질감 잉크와 벽 바탕색을 함께 옮긴다.** 대신 판독이 흔들리지 않도록 대비 바닥 네 개와 벽/배경 허용 구간을 못 박고 검증기가 매번 잰다. 그 결과 도료끼리 **ΔE 6.0~49.3**이 되고, "진행이 스크린샷 한 장에 드러난다"는 아이디어 5의 주장이 비로소 참이 된다.

바뀌지 않은 것이 더 중요하다. **구조는 여전히 유형이 정한다** — 간격·두께·방향·유형별 대비는 도료와 무관하다. 정보가 꾸미기에 덮이면 질감 레이어 전체가 무의미해진다.

---

## 1. 측정 — 왜 잉크만으로는 안 되는가

질감 잉크가 벽을 덮는 비율은 유형마다 12.5~14.6%다(협곡 12.5 · 회랑 13.3 · 산개 14.6 · 맥동 13.3). 나머지는 벽 바탕색 그대로다. 그러니 잉크 색을 바꿨을 때 **벽 평균색의 변화는 잉크 색 변화의 1/7 수준**으로 희석된다.

| 무엇을 바꾸는가 | 도료끼리의 벽 색차 ΔE |
|---|---|
| 잉크 틴트만 (원래 사양) | **0.00 ~ 3.22** |
| 잉크 + 벽 바탕색 (이 문서) | **6.0 ~ 49.3** |

잉크 색 자체는 ΔE 2.8~29.6으로 충분히 다르다. 문제는 그것이 화면에 도달하지 않는다는 것이다. 이 표가 이 설계의 전부다.

## 2. 무엇을 바꾸고 무엇을 안 바꾸는가

| | 도료가 바꾸는가 | 이유 |
|---|---|---|
| 벽 바탕색 | **예** | 화면의 41~75%를 차지하는 유일한 면. 여기가 아니면 보이지 않는다 |
| 질감 잉크의 색상·채도 | **예** | 벽과 같은 계열로 따라간다 |
| 질감의 간격·두께·방향 | 아니오 | 섹터 유형을 나르는 신호다 |
| 유형별 질감 대비 | 아니오 | 잉크 총량 균형이 깨진다. 벽이 바뀌면 **같은 대비가 되도록 다시 푼다** |
| 기록 이정표의 대비 | 아니오(값은 유지, 색은 재계산) | 각인은 언제나 질감보다 위여야 한다 |
| 통로 형상·엣지·장애물·아바타 | 아니오 | 판독의 언어다 |
| 물리·코스·솔버·난수 | 아니오 | 도료가 무엇이든 같은 시드는 같은 코스이고 같은 여유다 |

**기본 도료(현무암)는 0.6.0의 벽색 `#121a2e` 과 정확히 같다.** 도료를 고르지 않은 화면이 이전과 한 픽셀도 다르면 "도료는 꾸미기일 뿐"이라는 말이 거짓이 된다.

---

## 3. 대비 바닥

벽이 밝아져도 판독이 유지되는 것은 **통로를 읽는 것이 벽의 밝기가 아니라 엣지 선**이기 때문이다. 그래도 바닥을 명시하지 않으면 도료를 하나 더할 때마다 눈대중이 된다.

| 기준 | 바닥 | 기본 도료 | 가장 밝은 도료(비취) |
|---|---|---|---|
| 통로 엣지 `#3de1ff` | ≥ 9.0:1 | 11.06 | 9.51 |
| 장애물·셔터 `#ff5e7a` | ≥ 4.5:1 | 5.88 | 5.06 |
| 아바타 `#ffe66d` | ≥ 10.0:1 | 13.84 | 11.91 |
| 클리어선·사망 띠 `#7dffb0` | ≥ 10.0:1 | 13.85 | 11.92 |
| 벽 대 배경 `#070b14` | 1.10 ~ 1.35 | 1.137 | 1.321 |

벽/배경에 **상한**이 있는 것이 핵심이다. 벽이 너무 밝아지면 통로가 "빈 곳"이 아니라 **다른 물체**로 읽혀 도형-바탕 관계가 뒤집힌다. 그건 꾸미기가 아니라 게임을 바꾸는 일이다.

색상은 여백 팔레트와 같은 허용 대역(80~114°, 219~256°)만 쓴다. 벽도 예외가 아니다 — 기존 벽 `#121a2e`가 이미 223°라 규칙 안에 있었다.

## 4. 도료 6종

| 도료 | 벽색 | 색상 | 벽/배경 | 기본과 ΔE | 해금 |
|---|---|---|---|---|---|
| 현무암 | `#121a2e` | 223° | 1.137 | 0.0 | 기본 |
| 점판암 | `#1d202d` | 229° | 1.215 | 6.3 | 티어 1 전부 클리어 |
| 군청 | `#21214a` | 240° | 1.294 | 15.7 | 티어 2 전부 클리어 |
| 심연 | `#1c153f` | 250° | 1.151 | 17.3 | 티어 3 전부 클리어 |
| 이끼 | `#1a2315` | 99° | 1.214 | 25.4 | Endless 1500m |
| 비취 | `#182c15` | 112° | 1.321 | 32.7 | Endless 3000m |

가장 가까운 쌍은 군청–심연의 **ΔE 6.0**으로 식별 한계의 2.6배다. 검증기가 최소 ΔE 4.0을 강제하므로 도료를 더할 때 눈대중이 끼어들 수 없다.

허용 색상대가 두 구간뿐이라 **파랑 계열 넷과 초록 계열 둘**이 된다. 빨강·주황·자주를 쓸 수 없는 것은 그 색들이 장애물·속도·편향을 뜻하기 때문이고, 이 제약은 협상 대상이 아니다.

---

## 5. 해금 — 파생하고 저장하지 않는다

- **획득은 플레이로만.** 티어 전체 클리어 셋, Endless 거리 둘.
- **코어로 살 수 없고 코어를 주지도 않는다.** 두 경제를 붙이면 실력으로 얻어야 할 것과 취향으로 고르는 것이 한 저울에 올라간다. 아이디어 5가 리워드 광고의 출구로 도료를 지목한 것도 같은 이유이고, 광고 자체는 M5 사안이라 이 문서 범위 밖이다.
- **해금 목록을 저장하지 않는다.** `clearedStages` 와 `bestDistance` 에서 매번 파생한다. 어긋날 상태가 없고, 진행도를 내보내 옮기면 도료도 따라온다. 새 저장 항목은 **선택한 도료 id 하나뿐**이다.
- 진행도를 가져왔는데 그 도료가 아직 잠겨 있으면 기본으로 되돌린다.

## 6. UI

홈 화면의 "출발 형태"(프리셋) 줄 아래에 "벽 도료" 줄이 붙는다. 칩마다 **색 견본이 이름보다 먼저** 오고, 잠긴 칩은 해금 조건을 적는다("티어 2 전부 클리어", "Endless 3000m"). 풀린 칩에는 `꾸미기 전용`이라고 적는다 — 무엇을 주는 보상인지 오해할 자리를 남기지 않는다.

런 중에는 도료를 바꿀 수 없다. 화면이 런 도중에 바뀌면 불변 조건 4("`running` 중 새 정보 없음")를 깬다.

```ts
export interface Paint {
  id: string;
  name: string;
  /** 벽 바탕색 */
  wall: string;
  /** 질감 잉크의 색상·채도. 명도는 유형별 목표 대비가 정한다 */
  hue: number;
  sat: number;
  /** 진행도에서 파생한다 */

    | { kind: "default" }
    | { kind: "tier"; tier: number }
    | { kind: "distance"; meters: number };
}
```

메타에 붙는 것은 `paint: string` 하나다.

## 8. 검증

| 묻는 것 | 어떻게 |
|---|---|
| 기본 도료가 0.6.0과 같은가 | `DEFAULT_PAINT.wall === "#121a2e"` 를 상수로 고정 |
| 판독이 유지되는가 | 도료 6종 × 대비 바닥 4개 + 벽/배경 구간 + 허용 색상대 |
| **정말 구분되는가** | 벽 색차 ΔE 행렬, 최소 4.0 이상. 잉크만 바꿨을 때의 값도 같은 검증기가 계산해 근거를 붙들어 둔다 |
| 질감이 흔들리지 않는가 | 도료마다 유형별 대비가 목표 ±0.02, 잉크 총량 최대/최소 ≤ 1.10 |
| 각인이 질감 위에 남는가 | 도료마다 각인 상시 대비 > 질감 상한, 상시 ≤ 2.0, 섬광 ≤ 3.0 |
| 해금이 파생인가 | 합성 메타 5종으로 해금 목록 대조, 잠긴 도료 저장 시 기본 복귀, `paints` 배열 부재 |
| 코스에 닿지 않는가 | 도료 6종 해석 전후의 코스 지문 동일 |
| 통로를 침범하지 않는가 | 172장면에서 도료를 돌려 가며 픽셀 대조(질감·각인과 함께) |

**자동 검증이 증명하지 못하는 것.** 도료가 **좋아 보이는가**는 취향이고, 벽이 밝아진 것이 난이도 체감을 바꾸는지는 사람으로만 안다. 대비 바닥은 "읽을 수 있다"를 보장할 뿐 "똑같이 쉽다"를 보장하지 않는다. 질감 A/B에 가장 밝은 도료(비취) 조건을 하나 더 붙여 시도 수를 본다.

## 9. 지표와 판정

| 지표 | 정의 | 통과 |
|---|---|---|
| 채택 | 도료를 하나라도 해금한 사람 중 기본이 아닌 것을 고른 비율 | ≥ 40% |
| 무해 | 비취(가장 밝은 도료) 조건의 최초 클리어까지 시도 수 | 기본 도료 대비 ±10% |
| 성능 | 여백 렌더 p99 | 변화 없음(실측 ±0.0ms — 도료는 프레임당 비용이 0이다) |

채택률이 낮으면 **도료를 늘리지 말고 해금 조건을 앞당긴다.** 종류가 부족한 게 아니라 도달하지 못한 것이기 때문이다.

## 10. 리스크와 미결

| 리스크 | 징후 | 대응 |
|---|---|---|
| 밝은 벽이 난이도 체감을 바꾼다 | 비취 조건 A/B에서 시도 수 증가 | 벽/배경 상한을 1.35 → 1.25로 내린다. 도료를 빼지 않아도 된다 |
| 색상대가 좁아 다양성이 부족하다 | "다 비슷하다" 응답 | 명도와 채도를 더 쓰는 수밖에 없다. 색상 규칙은 판독의 언어라 건드리지 않는다 |
| 타일 캐시 교체 | 도료를 자주 바꿀 때 `ready` 프레임 스파이크 | 캐시 12장에서 가장 오래된 것부터 버린다. 런 중에는 도료가 고정이라 4장만 쓴다 |
| 색각 이상에서 파랑 넷이 뭉친다 | — | 명도 차(ΔE의 L 성분)가 주된 구분 축이라 원리적으로는 남는다. M3 A/B에서 함께 묻는다 |

**미결 ①** 광고 관람으로 도료를 주는 경로는 아직 없다. 광고 파이프라인 자체가 M5 사안이고, 그 전에 붙이면 검증할 수 없는 약속이 된다.

**미결 ②** 도료가 결과 화면·홈 화면의 색까지 바꿔야 하는가. 지금은 런 화면의 벽만 바꾼다. 셸까지 물들이면 더 "내 것" 같아지지만 UI 대비 규칙을 새로 세워야 하므로 별도 사안으로 둔다.
