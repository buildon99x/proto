# 회랑 9종 — 드리프트와 난이도를 떼어내다

## 결론

**수제 섹터 풀이 12개에서 18개가 됐고, 큐레이션이 18개를 전부 쓴다.** 회랑이 유형 하나로
축 셋을 서로 다른 방향으로 묻는 유일한 자리인데, 그 셋이 난이도 번호에 묶여 있어
**티어마다 한 질문씩만** 물어지고 있었다.

## 무엇이 묶여 있었나

0.5.4 까지 `corridor(1,"up") · corridor(2,"down") · corridor(3,"flat")` 이었다.
난이도가 곧 드리프트였으므로:

- 티어 1 의 회랑은 **상승만** — 편향 + 만 물었다
- 티어 2~3 의 회랑은 **하강만** — 편향 − 만 물었다
- **평탄은 티어 4 에서만** — 각도 − 는 마지막 티어에서 한 번

사양은 "평탄은 각도 −, 상승은 편향 +, 하강은 편향 −" 라고 세 질문을 적어 놨는데,
플레이어는 티어마다 그중 하나만 만났다. 축을 가르는 자리가 난이도에 묶여 낭비된 것이다.

## 9칸을 어떻게 채웠나

난이도는 **폭과 오르내리는 높이**로 가른다. 둘을 함께 움직이는 이유는 월드 크기다 —
중앙선이 `50 ± rise/2` 를 오가므로 `rise + width` 가 94 를 넘으면 통로가 월드 밖으로
나간다. 쉬운 칸은 넓고 짧게, 어려운 칸은 좁고 길게.

| | 폭 | 높이 | 최소 여유 | 축 선호 |
|---|---|---|---|---|
| corridor-up-1 / 2 / 3 | 34 / 32 / 30 | 44 / 54 / 64 | 126 / 98 / 69ms | 편향 + 139 / 148 / 158 |
| corridor-down-1 / 2 / 3 | 30 / 28 / 30 | 54 / 54 / 64 | 115 / 87 / 62ms | 편향 − 58 / 63 / 81 |
| corridor-flat-1 / 2 / 3 | 22 / 18 / 14 | — | 107 / 84 / 61ms | 각도 − 166 / 131 / 95 |

9칸 전부 도달 가능한 빌드를 하나도 막지 않고, 드리프트마다 난이도가 단조로 내려가며,
**축 선호가 난이도와 함께 강해진다** — 어려운 회랑일수록 더 강하게 묻는다.

`sector-probe` 의 편향 행이 이제 `+ + + − − − = = =` 로 읽힌다. 상승 셋, 하강 셋,
평탄 셋이 블록으로 갈린다.

## 두 번 되돌렸다

**① 티어 3 에 지속형이 들어왔다.** 첫 재큐레이션에서 티어 3 이 "성격까지 완화" 로
떨어지며 370단위짜리 코스를 집었다. 0.5.2 에서 티어 4 에만 부여한 "더 오래 좁다" 라는
정체성이 흐려진다. **완화 순서를 성격 → 지속으로 바꿨다** — 유형 구성이 지속보다 무른
선호다. 바꾸니 티어 3 의 최난 구간이 370 → 41단위가 됐다.

**② ±3 에서 티어 2 와 3 이 동률이 됐다**(둘 다 158ms). 티어 1·2 가 −28ms 짜리 해금
드리프트를 가진 후보를 집었기 때문이다. 제한을 30 → 20ms 로 조여 해결했다. 섹터가 전부
공정해진 뒤로 후보가 900/900 남아 조일 여유가 있었다.

## 대가

**±2 에서 티어 1 과 2 의 간격이 4ms 로 눌렸다**(185 대 181). 드리프트를 조이면서 티어 1 이
목표 200ms 에 닿지 못하게 된 탓이다. ±3 단조를 되찾는 쪽을 택했다 — 처음 만나는 조건이
±2 이지만, **해금 뒤에 곡선이 무너지는 것이 더 나쁘다**고 봤다. 되돌리려면 티어 1 의
목표를 190 근처로 낮추거나 드리프트를 25 로 두고 ±3 을 다시 봐야 한다.
