# R14a5 — 입력 관측 정확성과 스킬 FX 대비

## 계측 정의 정정
이전 R14a3/a4의 first-render-dispatch는 renderer.render 반환 후였다. 새 관측은 같은 cast의 renderer 진입과 반환을 따로 기록한다. UI도 '첫 렌더 진입 / 첫 렌더 반환'으로 표시하며 브라우저 합성·화면 표시·스피커 소리는 측정하지 않는다. 최초 입력은 다음 rAF 대기를 포함하고 홀드 반복은 같은 rAF 안에서 시작하여 두 수치를 직접 비교하지 않는다. 수집 위치의 정정이며 성능 향상으로 보고하지 않는다.

입력을 받을 때 슬롯의 실제 skillId를 고정하고 actionStarted의 ID와 맞는 경우에만 연결한다. 방패처럼 actionStarted가 없는 입력이나 다른 행동은 다음 홀드 공격에 붙이지 않는다. 이동 명령도 roll/sprint와 실제 reason을 대조한다. 매칭되지 않은 입력은 '관측 연결 종료'로 기록하며 게임 성공/실패 판정으로 해석하지 않는다. 첫 렌더 관측의 presentationObserved 필드는 전투 객체에서 제거하여 관측 데이터가 게임 상태를 수정하지 않도록 했다.

소리는 인접한 일치 actionStarted 뒤의 시작 sound 또는 roll sequence만 연결한다. 다른 타격/적/환경 sound는 미연결로 남긴다. audio.play 반환 true/false/기타를 수락/미수락/미확인으로 구분한다. 이 시각은 오디오 함수 결과이며 실제 발음 시작이 아니다.

## 표현 대비
v58 실제 사진에서 진격 pulse의 연결은 확인됐지만 얇은 선이 타일 바닥에 묻혔다. 같은 경로의 어두운 외곽선과 밝은 중심선을 사용하고, 기술별 무채색 실루엣을 구분한다: 철퇴 원호, 망치 열린 궤도+망치, 돌진 방패, 회복 꽃잎, 단죄 불꽃, 깃발, 진격 겹갈매기/창. 닫힌 확장 원은 신규 피해 범위처럼 읽히지 않도록 열린 모티프로 대체한다. 기존 게임의 실제 판정 경계는 바꾸지 않는다.

실제 actionContact/channelPulse, 0.42초 수명, 최대12효과·각8작은입자 제한 유지. flash0은 동일 경로/선폭과 높은 중심 대비를 유지하며 입자0. 적 예고·캐릭터·드롭보다 아래층. 최대12잔향+준비+이동+목적지를 동시에 구성해 계수한 상한은210 stroke/96 tiny fillRect이며, 보통 진격pulse1개는12 stroke/8 spark이다. drawcall 상한은 프레임 시간 실측을 대체하지 않는다.

## 검증과 한계
관측 집중191개와 FX 집중60개는 전체 검사에 중복되므로 합산하지 않는다. 신규 고유 검사는 관측24개+FX13개. 관측 새 검사를 원본에 적용 시23실패/1통과(단정실패16, 새 API 부재 등7), 수정후 통과.

이번 파일의 전체 회귀/빌드 결과는 첨부 full-unique.txt, lint.txt에서 확인한다. 실제 R14a5 후보 UI/입력/FX 검증은 아직 진행 전이다. v58-normal-input-observations.md는 이전 R14a4의 실제 QA다. 모든 스킬·적 위험이 공존하는 난전·청취·전과정 품질은 추가 확인이 필요하다.

전투 수치·준비/접촉/회수 시간·충돌/자원/피해/저장 내구성은 변경하지 않았다. 공개 root R11b6.1·다른 후보와 기존 정상획득 원본 유지. R13 성장·밸런스 보류.
