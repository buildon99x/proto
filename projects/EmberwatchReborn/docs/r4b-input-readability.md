# R4b: 실제 던전 QA에서 발견한 입력/시인성 개선

새 재구현 후보, 2026-10-09 UTC. R4a 정상입력 근거는 `r4a-normal-input-qa.md` 및 Library `libfile_4d5cca192f948191b0fc4b56defc78b7`에 보존했다. 변경은 전부 Emberwatch 자체 조정이며 원작의 미확인 조작 수치로 주장하지 않는다.

## 변경 계약

- 단발 망치/돌진: 현재 action/회수 잠금만 남고 학습·자원·CD는 준비된 요청을 최대0.55초의 활성 프레임 시간으로1개 보관. 기존 행동을 취소하지 않고 회수 끝에 홀드 철퇴보다 먼저 실행한다. 새 단발 요청이 교체하고 자원/CD는 실제 실행 때1회 재검증·차감한다. 장시간CD나 부족한 자원의 회복을 기다려 자동발동하지 않는다. 입력 시의 조준각(이동방향 돌진 선택이면 해당각)을 고정한다. 이 시간은 현재 철퇴1회에 맞춘 입력 허용치이며 기술 쿨다운/딜레이를 줄이지 않는다.
- 큐는 battle에만 존재하며 저장하지 않는다. 생성/사망/지역 재생성에 비어 있고 메뉴·blur·숨김·리바인딩·실패차단·pointercancel의 clearInput에서도 지운다. 메뉴닫힘 뒤 새 입력이 필요하다. OSrepeat/홀드의 단발 발동 정책은 기존 입력 라우터 그대로다.
- 커서가 살아 있고 활성화된 적의 화면상 몸/발 타원 안에 있고 벽 LOS가 통과하면 그 적의 지상 좌표를 조준한다. 선택된 발 위치에 금빛 작은 원/십자를 그린다. 빈 바닥은 기존 자유 조준 그대로다. 자동 공격/사거리/피해/판정/회피는 추가하지 않는다. 몸 보정은 현재 마우스 커서 해석이며 플레이어 이동 조작과 독립이다.
- 전방 적이 플레이어를 가릴 때 기존 적 투명도는 유지하면서 플레이어를 해당 겹침 위에 한 번 더 명확히 그린다. 위험 예고는 숨기지 않는다.
- 주변 보행 바닥 영역을 벽의 부분 투명도 보호영역에 추가하고 실제 walkable 타일 경계만 얇게 표시한다. 먼 벽/지형은 유지하며 이동 가능한 공간/충돌/지도 파일은 바꾸지 않는다.
- 치유사 rest 성공 때만 저장된 전체 recovery와 live action/CD/지연/무적/물약CD/버퍼를 동기화한다. 일반 체크포인트/아이템/보상 정산은 action이나 기술CD를 리셋하지 않는다. 저장 실패 시 sync 함수를 호출하지 않는다.
- 선택 창고까지 회수한 완료 HUD는 전체 탐험 완료라고 표시한다. 미구현 숙련/상위 기술 안내는 유지한다.
- 후보 UI에 복사 원본 QA 이름과 별도 대상 QA 이름을 표시해 기존 완료 후보를 덮어쓰지 않고 같은 보존된 L4 원본으로 반복 QA를 시작할 수 있다. 일반 main 저장 복사 금지와 별도 namespace는 유지한다.

## 검증

전체313/313검사, 문법/정적빌드 성공(마지막 UI 문구 변경 후 동일 검사 재실행). R4a276개 모두 유지하고 버퍼17,휴식동기화8,커서타깃8,보행시인성3,완료안내1을 추가했다. 버퍼와 휴식 검사는 실제 전투/reducer/저장 어댑터를 쓰지만 화면 입력 검증을 대체하지 않는다. 키/UI lifecycle 연결은 후보 정상 입력으로 따로 확인한다.

출시 범위는 첫 잿길/장비/첫 수문소/위임장까지다. 숙련16노드·실제 승급·상위캠페인은 아직 미구현이다. R4b 후보가 실제 검증되기 전 루트 R3b를 덮지 않는다.

## 조사 적용의 경계

부모가 확인한 공식 PoE2 패치: 0.3.0 https://www.pathofexile.com/forum/view-thread/3826682 (WASD Cursor Targeting,회피홀드 질주),0.4.0 https://www.pathofexile.com/forum/view-thread/3883495 (Cursor Tracking),0.5.0 https://www.pathofexile.com/forum/view-thread/3932540 (회피전용 미할당키). 현재 전체기본키/회피방향을 복제했다고 주장하지 않는다. 이번 버퍼/몸 조준은 자체 대응 설계이며 PoE2의 정확한 내부 구현을 확인한 것이 아니다. 기존 E/1/Z 및 레거시·추천 배치를 보존하고 Space는 공격형 방패돌진이다. 자유회피/질주는 만들지 않았다.
