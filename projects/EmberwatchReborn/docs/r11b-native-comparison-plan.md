# B calibration normal-input comparison

This is a plan, not a completed test. Public root stays R7a4. Candidate R11b
must pass the final aggregate and exact source/build preservation before use.

## Comparable baseline

R11a1/v37 ordinary-input evidence uses an explicit copy of the normally earned
R10 channel profile: L16, +1 mace/+1 shield, STR18/DEX5/INT12 allocations,
Hammer4/Mace4/Sundering1/Towering1, existing E/T. Trial by Fire was NOT purchased;
E costs30MP. Then Expert promotion and Banner1/Protection1/Onslaught1/Lance1
cost120G and12SP through normal buttons. Other unspent SP/attributes stay unused.
The menu-interrupted short samples are not continuous-play or DPS benchmarks.

For R11b use native title copy from untouched `qa-r10-channel-20261010` in qa-r10
to a fresh named qa-r11 profile. Never overwrite/reset a completed B profile,
inject XP/HP/targets/flags or import an edited save. Record promotion/ranks,
actual bindings and pools again. If healer rest is used before the first fight,
record it: differing initial HP prevents attributing survival changes solely to
this patch. The same offensive build still supports a target-choice comparison.

## What to observe

1. Verify old completed R11a1 profile first: level/gold/XP/gear/resources/keys,
   localized beacon label, no reopened rewards or enemy resurrection.
2. New copy, ordinary promotion, same four Expert purchases and same2/3 keys.
   Verify the trainer names the four-pulse Lance maximum; screen-label visibility
   is a separate gate from renderer fixtures.
3. First approach west, preserving the same order. Record cleave victims and
   target switches, any real need to leave Banner, cover use and a surviving
   caster/lancer's bounded side step. No deliberate waiting to force behavior is
   included in ordinary combat pressure observations.
4. East: the two lancers now start on different flanks. Does their position or
   step change target/aim/guard choice? Are weak frontliners still gratifying to
   clear? A longer walk or fewer incoming attacks alone is not improvement.
5. Short and committed Onslaught: compare actual payment, release contact and
   threat avoided. One active second/full four pulses also reaches the existing
   second payment while held. Menus are safety cancellation, not combat release.
6. Boss: keep200HP. During deliberate offense, observe whether a committed
   tell/recovery or vulnerable reposition creates an actual choice. If E+Q still
   kills it with no meaningful pressure, leave boss-depth gate open. Do not force
   survival or require every phase in an overpowering build.
7. Normal beacon/report/reload and duplicate guards remain mandatory.

Fire-area escape, opposite device order and Zeal are distinct trials. They need
separate legal profiles/purchases and cannot be inferred from this baseline.
All15 Expert nodes, higher difficulties, Master, live expedition reset/history,
advanced gear, audio listening/mobile and full campaign remain open.
