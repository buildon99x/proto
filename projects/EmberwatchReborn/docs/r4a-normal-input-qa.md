## 정상 입력으로 확인한 경로

1. 촌장 의뢰 수락/열쇠 → 치유사 무료회복 → 이미 처치된 잿길 통과 → 상층 입구. 의뢰/이동이 기존 적을 다시 만들지 않았다.
2. 진입 안내 대기 → 손잡이(+60XP) → 기록 읽기 → 경비3 처치(+30XP/10G). 벽을 넘는 직선 이동은 차단되고 열린 복도로 이동했다.
3. 물결1회→같은 판 오답으로0/3→물결/톱니/불씨 재입력 성공(+60XP/8G). 오답에서 HP/G/재료 차감 없음, 완료 후 재보상 버튼 없음.
4. 제어실3 처치(+40XP/13G),급수 차단/배수 개방/창고 방향 선택(+70XP/12G/철1)에서 **L5 XP52/300**. 방향 직통↔창고 재선택으로 XP/G 증가 없음.
5. 하층 승강기 연결→마을 왕복→하층 재진입. 체력/자원/적/퍼즐 유지, 회복/XP 무료지급 없음.
6. 전실2와 선택창고3 실제 처치. L5에서 각 입문 처치XP 감쇠 적용(총33.5XP/22G). 창고 회수 +30XP/18G/철1목재1실2물약1.
7. 봉인종→보스문. 쓸기/직선 경고와 바닥 울림 순환을 관찰. 첫 시도는 HP39에서 시작, 물약을 쓰지 않고 근접 조준을 점검하다 사망. 207G→197G(5% floor10), XP/퀘스트/장비 보존. 새로고침해 사망 상태를 다시 보고 마을 재시도.
8. 열린 승강기로 귀환, 일반 경비36처치 기록 유지. 보스HP는 새 시도에 초기화됐다. 두 번째 시도는 HP80 시작, 돌진·기본공격과 물약1회로 처치. +50XP(원시100×하위티어0.5),26G. 보스 처치 시 누적865.5XP.
9. 핵 회수 +70XP/20G,귀환→보고 +90XP/60G. **누적1025.5로 L6**, 자동검사 전체/선택 경로 수지와 일치. 위임장까지만 지급되며 실제 승급은 아직 미구현이라는 문구 확인.
10. 대장장이 보급 철2/목재1/잿불1 → 방패+2에22G/철2/잿불1. 방어7.2→8.2,장착으로HP가 회복되지 않음. 집중 목걸이 제작은 잿불 부족으로 비활성. 보급 재수령은 이미 받음으로 비활성.

## 시간/난이도 근거의 한계

약24분의 벽시계는 도구 관찰/문서화와 반복 일시정지가 대부분이다. 정상 연속24분 콘텐츠라는 뜻이 아니다. 첫 시도 마지막 사망 전 메뉴에서 플레이161초/교전42초/이동33초/메뉴718초/진입대기83초, 다음 재접속 최종 메뉴에서 플레이57초/교전9초/이동15초/메뉴279초가 관측됐다. 그 사이 사망까지 약5초와 일부 시작/로드 구간은 합계에 포함하지 않았다. 관측 합계 하한은 플레이218초/교전51초/이동48초/메뉴997초이며 교전·이동은 중첩된다. 플레이 카운터에는 서 있는 시간이 포함된다. 장시간 CPU/포커스 정지 프레임은 제외될 수 있다.

이번 실제 난이도는 Normal 하나다. Easy/Hard/Serious의 수지와 피해 배율은276자동검사 및 계산표 근거이지 실제 각 난이도 완주가 아니다. 두 번째 보스는 근접 조준을 알면 비교적 빨리 처치됐지만 메뉴로 여러 번 정지해 준비 시간을 읽었으므로 연속플레이의 난도/재미 합격으로 쓰지 않는다. L15/마스터/전체캠페인 시간은 미검증·미완이다.

## 발견 문제와 다음 우선순위

- P1: 기본 공격 홀드의 회수 중 누른 주력/돌진이 소리/자원 소비 없이 유실될 수 있다. 기본 공격보다 우선하는 짧은 단발 버퍼를 다음 후보에서 검사한다. 쿨다운을 단축해서 숨기지 않는다.
- P1: 보스의 큰 몸과 실제 지상 위치 차이 때문에 보이는 몸 쪽 조준이 빗나가고, 겹친 몸이 플레이어를 덮는다. 적의 몸을 커서로 가리킬 때 지상 타깃을 표시/선택하고 근접 반응을 실제 재확인한다. 현재0.64투명도와 작은 발 원만으로 충분하지 않았다.
- P1: 좁은 통로의 높은 벽이 출입구/보행 가능 바닥을 읽기 어렵게 한다. 특히 보스 귀환 시 모서리에서 여러 번 우회했다. 충돌을 제거하지 않고 근거리 바닥·문 경계를 더 드러낸다.
- P1: 별도 실제 runtime fixture에서 휴식 저장은 기술회복을0으로 만들지만 live battle에는 남는 불일치 재현. rest 성공 때만 두 상태를 일치시키고 회귀한다.
- P2: 완료 HUD가 선택 창고까지 회수했는데도 '선택 창고'를 계속 안내함. 모든 완료 상태에서는 다음 미구현 단계와 장비 정비를 구분한다.
- P2: NPC가 동상이고 마을/던전의 재사용 돌바닥이 반복적이다. 목표 품질에 부족하다. 첫 경비12명과 퍼즐은 짧은 기능 슬라이스이며 중기 성장 선택이 아직 충분하지 않다.
- 청취: 앱 사운드 이벤트/볼륨 동작은 존재하지만 이번 도구는 실제 청취 근거를 제공하지 않았다. 판타지 음향의 최종 동기화/음색/믹싱 합격으로 처리하지 않는다.
