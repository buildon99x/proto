# R14 입력 stage1: 미게시 소스 중간 체크포인트

기준 R12a6에서 별도 복사한 R14 작업면. R13 장비/성장 확장과 무관. 전체 자동검사·빌드·브라우저 QA·배포 아직 미완료다. 현재 코드 타이틀 R12a6은 복사 당시 값이며 릴리스 ID로 사용할 수 없다.

- 기준 생산 router: 한 프레임 안 LMB down/up은 attack=false로 유실. 기본 철퇴 contact0.182초/duration0.52초. baseline-results.json은 모델 관찰이며 브라우저·음향 지연 실측이 아니다.
- captureAttackTap opt-in은 눌렀다 놓은 기본공격을1회 보존한다. OS repeat는 새 edge가 아니며 실제 held 반복은 유지한다. 새 기술 edge가 이전 미전달 기술을 대체하고 기본공격 홀드보다 먼저 평가된다.
- acceptBattleInput은 세계시간·타격을 전진시키지 않고 같은 이벤트 턴에서 기존 생산 startAction을 실행한다. 자원/쿨다운은 실제 시작1회만 소비, 기존 접촉시간 유지. main 키/마우스/터치 경로 연결.
- 저장 busy 중 단발은150ms 한도. 완료 시 microtask에서 즉시 전달, 만료·메뉴·focus·사망 안전취소. 내구성 commit 중 세계정지는 기존처럼 유지되어 아직 지연 제약이다. 기다리는 입력은 자원 미소모; 시작된 행동은 commit 실패 시 게임 게이트를 닫는다.
- 저장 중 채널 release는 안전취소, Lance 없음. 입력 즉시 시작으로 프레임 이전 채널 tap도 시작비용9를1회 내고 contact/pulse 전에 중단한다. 기존 '아직 미전달인 채널 탭은 무소모' 조건은 저장대기에서 유지. 이 의도된 의미 변경을 실제 main 테스트에 반영했고 케이스 수를 줄이지 않았다.
- hotbar 실선/점선 테두리로 입력수락/저장대기를 표시한다. 모션·SFX dispatch·contact·first-render dispatch는 별도 메모리 기록. 실제 화면/오디오 출력 지연은 아직 미검증.
- controls4는 명시적인 프리셋 선택 함수에만 존재. 원래 v1~v3 키 설정은 자동변환하지 않으며 controls4에 priorControls 정확 사본. 원작두조준모드/추적과 이동/모빌리티 순수모듈은 아직 주게임 통합 전.

실행 검사: input-focused.tap의236/236 통과(기존+신규 실제 main-handler 포함). 전체2958개 기반 회귀를 돌린 결과는 아니며 236을 전체 완료로 쓰지 않는다. 변경없는 과거 검사결과를 현재 통과로 승계하지 않는다. 고수준 브라우저 테스트/CPU 프레임 측정/전체 캠페인/AAA 품질 미완료.
