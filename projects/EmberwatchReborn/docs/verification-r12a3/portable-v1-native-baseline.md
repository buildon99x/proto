## 확인된 작은 UI 후속 항목
- 현재 ‘파일 SHA-256’이라는 라벨은 canonical metadata+payload digest를 뜻하므로, 전체 파일 바이트 hash로 오해하지 않도록 ‘체크포인트 내용 SHA-256’ 설명으로 정밀화할 필요가 있습니다. 무결성 계산 자체의 오류는 발견하지 않았습니다.

- 두 UI 후속 항목은 아직 수정·게시하지 않았습니다. 이번 성공 범위를 확대하지 않습니다.
