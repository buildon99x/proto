### 이전 승인된 후반 캠페인 기능 흐름의 복원 목표

아래는 기획서에 없던 후속 Emberwatch 제작 범위다. 유실된 맵·코드의 완전한 원문 복구를 뜻하지 않는다. 각 단계의 실제 이름·좌표·보상은 새 콘텐츠 명세와 재검증이 필요하다.

- [ ] **미검증** — 주/보조 장비 변경은 파생 수치뿐 아니라 실제 공격·방어·모션에 반영된다.

- [ ] **미검증** — 비율 원시값 0.15는 +15%, 비율 차이 0.15는 +15%p, 이미 퍼센트 단위인 저항 차이는 다시 100배 하지 않는다. 초당 재생·초·정수와 단위를 구분한다. `null`을 0으로 표시하지 않는다.
- [ ] **미검증** — cave_ring ↔ focus_charm 비교의 주문 증폭 누락을 회귀 검수한다. 구체 수치는 새 아이템 정의와 대조하며 UI를 고치려고 효과를 바꾸지 않는다.
- [ ] **미검증** — 상점 구매 잠금 이유가 forge_restored / expert_commission / master_commission 등 실제 조건과 일치한다. 버튼 비활성뿐 아니라 실제 구매 명령도 원자적으로 거부한다.

## 7. 저장·죽음·격리 QA

- [ ] **미검증** — 구 원정 세이브·새 캠페인·격리 QA 저장소를 분리한다. 조용한 자동 전환·초기화·기존 플레이어 자산 삭제가 없다.
- [ ] **미검증** — 새 세이브는 캐릭터/랭크/배타 분기/티어/포인트·인벤토리·장비 인스턴스·퀘스트·NPC·시간/날씨·문/열쇠/상자/지름길·지역 위치·보상 영수증을 지속한다.
- [ ] **미검증** — 거래·보상·제작·스킬 투자·승급은 커밋 실패 시 부분 적용되지 않는다. head/slot 등 저장 구조의 실패·손상·복구·충돌 처리와 구버전 거부/명시적 이행을 검사한다.
- [ ] **미검증** — 저장 중 투사체·장판·버프·채널·소환/행동의 소유 ID와 타격/틱 영수증을 검사한다. 같은 action의 유효한 상태 별칭과 복제된 별도 피해 소스를 구별한다.
- [ ] **미검증** — Pulsing/Heaven 장판 복제, 같은 source를 Pillar 양 성분으로 사용, 음수 틱 시간, 남은 횟수/실행 횟수 불일치, 만료 효과가 있는 손상 저장은 안전하게 거부한다.
- [ ] **미검증** — 지역 왕복·저장/재개·죽음/부활 뒤 적 HP·죽음·보스 보상·열린 문·퍼즐·위임장·완료 플래그가 규칙대로 유지된다.
- [ ] **미검증** — 죽음은 명시된 골드/시간 비용·체크포인트 이동이며 전체 레벨/장비/퀘스트 초기화가 아니다. Guardian 처리 뒤 실제 죽음과 재생/버프 초기화 정책을 확인한다.
- [ ] **미검증** — QA 프로필은 안전한 단일 ID만 허용하고 캠페인 키만 고유 접두사에 매핑한다. malformed/중복/빈 qa는 fail-closed이며 정상 저장으로 fallback하지 않는다.
- [ ] **미검증** — QA wrapper 생성 시 기존 정상·legacy 데이터를 읽거나 복사하지 않는다. 두 QA 프로필·정상·legacy sentinel 독립성을 spy storage로 증명한다.
- [ ] **미검증** — storage 이벤트는 해당 프로필의 정확한 head만 처리한다. 다른 QA/정상/null 이벤트로 잘못 멈추거나 실제 자신의 충돌을 놓치지 않는다.
- [ ] **미검증** — QA에서는 파일 import를 차단한다. 미결인 원래 테스트 세이브 import를 읽거나 재시도·취소·우회하지 않는다. 신선한 새 게임 QA의 별도 허용 범위만 사용한다.

## 8. 실제 플레이·속도·깊이의 완료 조건

### 8.1 검사의 층과 증거

- [ ] **미검증** — 정적 검사: 정확한 53노드·출처/미확정·배타 관계·맵 연결·보상 표·한국어 표시를 대조한다.
- [ ] **미검증** — 합성 상태 단위 검사: 경계값·불충족·반복·손상 입력을 빠르게 검증하며 실제 진행으로 표기하지 않는다.
- [ ] **미검증** — 메모리 런타임 경로: 실제 command/interaction/kill/reward/promotion/save handler를 사용하고 XP/레벨·무료 랭크·핵심 플래그를 주입하지 않는다. 좌표 스크립팅·정지 적·AI 비활성 여부를 명시한다.
- [ ] **미검증** — 일반 입력 새 게임: 이동·조준·회피·방패·기술·NPC·퀘스트·제작·훈련을 화면에서 조작한다. 지도 이동 텔레포트·개발 XP·적 HP 조작·임의 저장 편집으로 통과하지 않는다.
- [ ] **미검증** — Easy/Normal/Hard/Serious를 경로 예산과 전투 정책에서 검사한다. 최소 Normal/Hard 실제 플레이를 기획서 수직 슬라이스 기준으로 검증하며, 미플레이 난이도를 플레이 완료로 표시하지 않는다.
- [ ] **미검증** — 중요한 입력은 실제 교전에서 검수한다. 적을 정지시킨 측정만으로 밸런스·재미·조준·생존 검증을 주장하지 않는다.
- [ ] **미검증** — 동일 버전으로 첫 게임→L5→L15→L30→Master 이후 결말을 기록한다. 중간 변경 뒤 영향 구간을 다시 확인하고 서로 다른 버전의 성공을 한 번의 완주로 합치지 않는다.
- [ ] **미검증** — 수동 브라우저·화면 검사는 명시된 공유 환경 시간과 권한에만 수행한다. 본 문서 작성 시에는 실행하지 않았다.

### 8.2 플레이 시간은 목표 관찰창이며 강제 지연 수단이 아니다

| 관찰창 | 통과 조건 | 실패 신호 |
|---|---|---|
| 첫 5분 | 전사의 돌진·철퇴·방패·망치와 자원 차이를 실제로 파악 | 한 버튼/한 방 데모, 입력을 모름 |
| 첫 15–30분 | 싸움 외 NPC·장비·기술·탐험 목표, 여러 적 대응과 보상 선택 | 몬스터 청소와 숫자 상승만 반복 |
| 첫 60–90분 | 단서→도구→재방문→다층 던전→보스로 끊기지 않는 흐름 | 막힌 조건 안내 없음, 긴 왕복만 존재 |
| 첫 90분 | 최소 3회 의미 있는 선택, 스킬/장비/경로 중 최소 2종, 재방문 동기 1회 이상 | 선택이 외형뿐이거나 정답 하나만 존재 |
| 2–4시간 관찰 | 새 티어·주요 기술·장비·지역이 행동을 바꿈 | HP·거리만 늘고 하는 일은 동일 |
| 같은 직업 2개 새 세이브 | 다른 분기·장비 선택의 실제 차이 | 빌드가 명목상만 다름 |
| 후반과 결말 | Master 이전 성장 동력과 Master 이후 사용 기회·빠른 귀환 | L30 달성 즉시 종료, 반복 파밍 강제 |

- [ ] **미검증** — 실제 경과 시간을 측정해 보고한다. 위 관찰창을 맞추려고 적 HP·걷는 거리·대기 시간을 늘리지 않는다.
- [ ] **미검증** — 10분당 의미 있는 빌드/탐험 선택, 다음 목표를 모르는 시간, 반복 전투·왕복 시간, 이탈 이유를 기록한다.
- [ ] **미검증** — “다음 행동을 모르겠다”는 안내 문제와 “알지만 재미없다”는 콘텐츠/깊이 문제를 따로 기록·수정한다.
