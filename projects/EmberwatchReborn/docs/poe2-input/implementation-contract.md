# R14 POE2 입력 수직단면 계약

2026-10-10. 원본 R12a6과 공개 루트는 보존하고 별도 작업면에서 개발한다. R13 신규 장비/후반 확장을 포함하지 않는다. 공개 근거는 movement-targeting-ko.md와 combat-inputs.md의 O/A 등급이며, 원작 실행/프레임 실측은 아직 없다.

## 구현 순서와 보존
1. 실제 R12a6 생산 router/전투 핸들러로 입력 탭·시작·접촉·회수·저장대기 기준을 기록한다.
2. Controls v1~3은 자동 키 변경 없이 기존 방식으로 읽는다. 명시적 POE형 프리셋 선택만 v4가 되며 원래 조작 설정을 되돌리기용 snapshot으로 보존한다. 기존 진행/경제/지역/스킬 수치는 변경하지 않는다.
3. 독립 /qa-r14/ 후보 이름공간에서만 쓰기. 기존 /qa-r12/ 정상 획득 원본과 공개 release는 읽기 원본 보존. 새로운 후보 시작/복사는 명시 UI로만 한다. v4 설정이 들어간 프로필은 구 R12 reader에 그대로 읽힌다고 주장하지 않는다.
4. WASD와 클릭 목적지 이동을 분리한다. 초기 클릭 프리셋 LMB는 명시적인 Move Only이며, 문맥 LMB 공격/상호작용·namelock은 아직 미확정/미구현이다.
5. Aiming Mode(cursor/ground)와 Cursor Tracking(release 이후 추적)을 독립 저장. 원작 기본 조합은 WASD cursor/on, 클릭 ground/off. 지면지정 기술은 공통 지면점을 쓴다.
6. 실제 사용자 QA 전에는 배포/완성/원작 완전동일을 주장하지 않는다.

## 즉시성
- keydown/keyup 사이 탭도 누름 edge를 1회 남긴다. OS repeat는 새 edge가 아니다.
- 입력 수락 시각, 액션 시작 시각, 첫 프레임/소리, 접촉을 구분한다. Node 시간은 핸들러 실행/모델 값이며 디스플레이/오디오 latency가 아니다.
- 유휴 상태의 허용된 액션 시작은 keydown handler에서 실행 가능해야 한다. 실제 접촉/투사체/회복은 기존 준비시간을 유지한다.
- 저장이 진행중이면 입력 수락 피드백은 즉시 보이되 자원 소비·접촉은 한 번만 실행한다. 기존 확정 저장 계약은 약화하지 않으며 긴 저장 stall에서는 명시적으로 만료 안내한다. 저장 pending 때 플레이 세계를 진행시키지 않는 현재 내구성 제약은 별도 측정/개선 대상으로 남긴다.
- 메뉴/포커스/사망/장면 전환/리바인딩은 누름/예약/이동 목적지를 취소한다. 새 입력이 필요하다.

## 스킬별 정책
POE2는 스킬별 이동·내장 이동·취소·방향 갱신 구간이 다르다. Emberwatch 스킬을 원작의 다른 스킬과 동일하다고 대응시키지 않는다. 현재 damage/contact/duration/CD는 보존하고, 보행·회전·회피 취소 허용만 명시 데이터에서 다룬다. 전사 철퇴 회수 보행은 이전 Emberwatch 규칙이며 POE2 공통 규칙으로 인용하지 않는다. 기존 Space 방패 돌진은 공격 기술로 유지하고 새로운 회피/질주 입력은 별개 액션이다.

## 미공개 자체 값
큐/버퍼 ms, 커서 목표 반경/렌더 높이, 클릭 도달 오차·장애물 경로, 동시입력 우선순위, 회피 방향·속도/시간/회피창은 원작 공개값으로 주장하지 않는다. 구현마다 값·이유·동작 QA를 별도 기재한다. 모든 타격 준비시간을0으로 만들거나 HP/피해/쿨다운을 편의상 바꾸지 않는다.

## 통과 전 필수
짧은 탭/홀드공격주기, W+A/W+D+방패/주력/물약, 새 스킬 우선, 사망/메뉴/blur held 정리, 리바인딩→전투→재로드, 원래 키 복원, 클릭 이동과 다른방향 조준, 벽/코너/목적지사망 취소, cursor/ground/Tracking 조합, 구르기+질주/구르기만 구분, 저장중 단발/채널 release, 입력→시작/접촉 분리 증거. 자동검사와 실제 화면·청취 관찰은 서로 대체하지 않는다.

최신 방향: 신규 선택 화면에서 POE2식 통합 회피+홀드 질주를 권장, 문서의 Shift 별도 달리기를 별도 선택으로 제공한다. 기존 저장에는 어느 쪽도 자동 적용하지 않는다. 문서 PC/Godot 가정은 현재 웹 런타임의 입력/상태/타임라인 아키텍처로 대응하며 엔진을 임의 교체하지 않는다. 거너 예시는 목표 체감의 예시이며 현재 진행하던 전사 구현을 먼저 연결한다.

새 프리셋 draft는 LMB기본(클릭모드는J), RMB망치 주력, Q돌진/E단죄/R치유/F전문1/G전문2, 물약1, V상호작용, C메뉴, Esc일시정지다. 방패 MMB/B 대체키. 통합형은 Space통합회피·Shift제자리; 분리형은 Space회피만·Shift달리기·H제자리. 이 키표는 전체 최신 POE2 순정 키표라는 주장이 아니다. 미구현 마나물약2/지도Tab을 작동하는 기능처럼 표시하지 않는다. 슬롯별 액션 배치는 기존 두 전문가 슬롯 외 확장이 남아 있다.

Stage1 현재 상태: 입력즉시 시작·짧은탭·저장대기 처리만 실제 main 핸들러에 연결했다. controls4/조준/이동/회피 모듈은 통합 중이며 공개 UI에서 선택할 수 있는 완성 기능이 아니다. /qa-r14/ 저장·빌드 격리와 공개 배포도 아직 하지 않았다.

FX 합격: 스킬별 준비/발사 또는 접촉/잔향의 시각·음향 이벤트, 판정시점과 일치, 몰살 반응, 적 예고/플레이어/드롭 시인성, flash0·shake0, 동시 음성 제한과 프레임 비용, 정상 입력 실제 화면/가능한 청취 근거. 일반 hotbar 입력 테두리는 즉시성 보조이며 화려한 스킬 FX 완성을 대신하지 않는다.

## Stage2 통합 상태 (2026-10-10 20:54 UTC)

위 Stage1은 해당 보존 시점의 기록이다. 현재 별도 작업면에서는 controls4 선택 UI, 새 게임의 4가지 명시 프리셋, v3 계속하기/원래 설정 복원, 독립 조준 설정, 실제 전투의 회피·질주·재조준, /qa-r14/ 전용 저장/엔트리/빌드가 연결됐다. 기존 legacy와 이미 획득한 성장/비용/공개 root는 보존한다. 실제 main 이벤트/저장 핸들러 66검사, core/namespace49검사, 빌드격리11검사가 통과했다. 전체 최종 suite와 실제 일반입력 화면 QA는 아직 완료 전이다. 이는 원작 내부 수치 동일 또는 전 과정 완성 선언이 아니다.

접촉 FX는 일반 기술의 실제 actionContact와 불굴의 진격의 실제 channelPulse에서 생기며 castId·pulse index 중복을 막는다. 채널의 fired 값은 준비 종료를 나타내지 않으므로 실제 contact 경과 시점에서 준비선을 끝낸다. 준비·접촉 모티프를 7개 기술에 연결하고 기존 24포즈 motion과 판타지 sound bank를 재사용했다. 최대12효과/각8잔입자 제한, flash0에서 입자는 없애되 경계/모티프를 유지한다. FX는 적 예고/캐릭터보다 아래 floor layer에 그린다. 구르기는 기존 dodge24포즈, 질주 보행은 실제 이동거리 walkPhase와 발소리 접촉을 공유한다. 이 구조검사는 화려함·실제 음향·난전 가독성의 합격을 대신하지 않는다.

남은 차이: 문맥 LMB 접근/상호작용, 작은 적 밀기/큰 적 몸 차단, 전체 스킬 슬롯 자유배치, 최신 원작의 비공개 namelock 내부 규칙, 실제 이동/표적/회피/FX/음향 비교는 미완이다. 클릭 프리셋은 현재 Move Only라고 UI에서 명시한다. R13/밸런스 확장은 계속 보류한다.
