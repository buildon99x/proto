# R14a2 조작 통합 및 검증 경계

2026-10-10. 사용자의 최신 지시로 밸런스·R13 성장 확장은 보류한다. R14a1 공개 후보의 정상 신규 플레이에서 NPC 문맥 클릭 누락과 적 몸 겹침을 확인했고, 별도 R14a2 작업면에서 수정했다. 전체 고유 자동검사3,763/3,763 및 문법/정적 빌드가 통과했다. 실제 새 후보 화면 합격은 아직 아니다.

## 사용자 지정 문서 대조
- WASD/마우스 이동 선택과 독립 조준: controls4/5. Aiming Mode와 Cursor Tracking 독립. 기존 사용자는 자동 변경하지 않음.
- 회피 후 유지 공격 복귀/회피 홀드→질주: 권장 통합 프리셋. Shift 별도 달리기는 별도 선택. 원작 미공개 시간·속도·회피 방향은 내부 가설로 명시.
- LMB/RMB/MMB 및 Q/E/R/F: 8개 기존 전투 바인딩을 명시 controls5 선택 후 기술 슬롯으로 전환. 기존 G 추가 슬롯 유지. 클릭모드는 LMB 문맥 이동, 공격 슬롯 기본 J. 원래 물리 키와 정확한 이전 controls1~4 snapshot 보존.
- 어떤 배운 행동 기술도 어느 슬롯에 지정 가능. 패시브·미학습·중복 기술 배치 금지. 방패/반복/단발/채널은 슬롯 이름이 아니라 지정 기술의 의미를 따른다.
- 물약1 작동. 마나물약2/지도Tab은 미구현이므로 작동하는 기능처럼 표시하지 않는다. 기존 레거시 초기화는 명시 조작이며 controls5 기술 배치는 유지, WASD 모드로 전환한다.
- 클릭 문맥 대상은 현재 보이는 실제 그림/라벨에서 선택하고 같은 identity로 접근·재검증 후 기존 권위 핸들러를 한 번 호출. 빈 바닥/적 클릭은 Move Only. 신규클릭/명시행동/메뉴/포커스/죽음/전환/설정변경은 옛 문맥 예약 취소. 도달 실패는 만료 안내.
- 벽 반경11을 보존하면서 살아있는 적 몸의 보행/질주 충돌과 작은 적 제한적 구르기 밀기. 구르기 축소 몸이 모든 적을 통과하는 것은 아니다. 적 분류·반경·밀기·시간은 Emberwatch 작성값. 공격형 돌진/진격의 기존 특수 이동 계약 유지.
- 타일 모서리에서 클릭 경로가 대각으로 꺾여 멈추던 결함: 다음 경유점까지 반경11 통과가 안 되면 현 타일 중심을 먼저 경유.

## 즉시성과 안전
- DOM 입력 handler에서 허용 액션 시작. 기존 접촉/비용/CD/회수시간은 유지.
- 저장 대기 입력은 기존150ms 단일 최신 계약, 성공 commit 직후 microtask에서도 전달. 단발/토글/홀드채널의 keyup 동작을 분리. 원본 스킬/슬롯/생명/저장 소유자/시각을 캡처한다.
- 같은 슬롯에 키 별칭을 둬도 중복 발동/채널 소유 이전 금지. 빈 슬롯은 옛 고정 행동을 실행하지 않는다. UI/포커스/사망/설정 변경은 새 입력 필요.
- 메뉴의 '입력 응답 기록'은 handler→start/render-dispatch/audio-dispatch/contact를 구분한다. 물리 디스플레이/청음 지연이나 POE 실측으로 주장하지 않는다.
- 기존 save/schema·후보 공간 경계와 검사 강도는 유지. controls5를 구 R14a1 모듈로 읽는다고 주장하지 않음. 전환전 스냅샷 복원은 현재 코드 안의 명시 UI 선택이며 구버전 코드 자체로 자동 롤백되는 기능은 아니다.

## FX 및 실제 QA 게이트
기존 자산·24포즈와 7기술별 바닥 준비/접촉/잔향 FX 재사용. 위험 예고 전에 그려 flash0에서도 경계가 남도록 설계. 이 구조적 계약만으로 화려함·타격감·가독성·청음·프레임비용 합격 처리하지 않는다.
실제 후보 검증: 기존R14a1 L1 save 유지, controls5 명시선택·기술옮김·새로고침, NPC/출구 문맥 접근과 취소, 적 몸막힘/구르기, 짧은 탭·독립조준·회피후홀드공격, 메뉴/blur/사망 유령입력, flash0/FX/위험예고, 정상획득Expert복사본의 채널 소유/자원/CD.

과거 R14a1 전체3,271 통과와 각 작업자 집중 검사 수는 중복되므로 합산하지 않는다. R14a2 전체 고유 결과를 검증 뒤 별도 로그로 기록한다.
