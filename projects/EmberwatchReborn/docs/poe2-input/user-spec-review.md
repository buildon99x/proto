## 핵심 구현 요구
1. 세부 DPS 밸런스 작업보다 전투·조작 P0 우선. 이동+조준 독립과 공격 중 포지셔닝.
2. Locomotion과 Action 상태 분리. 입력 pressed/released/held를 물리프레임에 수집, OS 반복 금지. 명령 타임스탬프/만료/우선순위 관리.
3. 즉각 행동 시작과 실제 적중 이벤트 구별. startup/active_windows/recovery 타임라인. 최종 retarget_windows와 dodge_cancel_windows는 시간 구간 데이터.
4. 좌클릭 홀드 연사, 우클릭 주력, 휠클릭 보조, Q/E/R/F 스킬, Space 회피, Shift 별도 달리기, 1/2 회복, Tab 지도, C 캐릭터는 문서의 Emberwatch 권장안. 원작 키 복제라고 주장하지 않음.
5. 클릭이동 프리셋은 좌클릭 이동/상호작용, 공격 재매핑. UI/World/Inventory 문맥 충돌 방지, 대각 정규화, 벽 슬라이딩, 경로탐색.
6. 커서/지면 조준 구분, 카메라/줌 좌표 보정, 지면 AoE 사거리/벽/시야 정책. 직접 조준 우선, 선택적 제한 보정. 근접은 강제 흡착 대신 공격 호/범위.
7. 유효 회피 취소창에 즉시 회피. 입력 방향 우선, 무입력 fallback 명시. 피해유형별 회피 규칙. 단일 완전무적 플래그 금지. 회피 후 홀드 공격 자동 재개.
8. 거너 후퇴/측면 사격·정밀사격, 전사 경베기/강타, 마법사 투사체/지면 주문으로 클래스별 루프 검증.

## FX 요구
본문 자체는 CombatFeedback(VFX/SFX/hit stop/camera), 클래스별 명중/피격 식별, 최소 1종 적의 명료한 공격 예고를 요구한다. 구체적 색·입자 수·쇼크웨이브 디자인은 정하지 않는다.
최신 사용자 추가 요구인 “스킬 화려한 FX 필수”를 함께 적용해야 한다. 화려함으로 지면 예고/회피 판단을 가리지 않도록 하며, 발동 준비·실제 적중·잔류 효과가 타임라인과 맞아야 한다. 이는 요구 적용 해석이며 원문이 특정 FX 모양을 지시한 것처럼 전달하지 않는다.

## 수치의 정체
- 버퍼 80–120ms는 초기 제안값.
- 이동 배율 거너 .75/.35, 전사 .50/0, 마법사 .65/0–.25도 임시 튜닝값.
- POE2 실측/공식 내부 파라미터가 아니다. 사용자 목표가 원작 충실 이식이므로 반드시 데이터화하고 확정 표현 금지.

## 기존 공식 조사와 대조
근거: 같은 폴더 movement-targeting-ko.md와 combat-inputs.md의 2026-10-10 조사. 이번 문서 검토 작업에서 웹을 새로 전수 조사한 것은 아니다.
1. 가장 큰 차이: 초안은 Shift 별도 달리기를 권장하고 회피 홀드 질주를 선택형으로만 고려한다. 기존 공식 0.3.0 조사에서는 일반 dodge 홀드→구르기 후 질주가 확인되며 0.5.0에는 질주하지 않는 별도 dodge-only 바인딩(기본 미할당)이 추가됨. “가능하면 원작 그대로”가 우선이면 POE2 프리셋은 통합 홀드 회피/질주 + 별도 dodge-only 액션을 제공해야 한다. Shift 별도 질주는 Emberwatch 선택 프리셋으로 설명.
2. 초안은 Cursor Tracking 옵션을 생략한다. 0.4.0 공개 계약에 따라 키 release 뒤 조준 추적을 Aiming Mode와 분리. 기본 WASD ON, 클릭이동 OFF.
3. Aiming Mode 기본 WASD Cursor / 클릭이동 Ground, 지면 지정 스킬은 양 모드 동일 지면점. 초안의 단순 발사벡터 설명을 2D 화면 높이/지면점 구별로 정교화.
4. Attack in place stops movement와 Always Attack Without Moving을 분리. 전자는 WASD 이동가능 스킬을 멈추게 하면 0.1.1 계약과 충돌. 초안에는 상세 없음.
5. 새 스킬 큐의 조준 갱신, 채널링→채널링 전환, 사망 시 예약이동 취소가 기존 최신 조사에서 확인됨. 초안 기본 구조에 포함할 회귀검사.
6. 스킬별 이동 감속·내장 이동·재조준/취소창은 다름. 클래스 단위 감속이나 전사 회수구간 이동을 원작 보편규칙으로 고정하지 않음.
7. 기존 조사 최신 목록 확인은 0.5.5e(2026-10-05), 초안 참고 공식 링크는 0.3.0. 초안이 최신 버전을 확정한 문서는 아님.
8. 최신 순정 키맵 전체, 정확한 프레임·큐시간·조준 선택 알고리즘은 미확정. 실기 동일성 보증 금지.

## 필수 검증
- input_to_action_start_frames: 로컬 다음 처리프레임 이내.
- input_buffer_expired_count 및 이유, invalid_target_snap_count, dodge_cancel_success_rate, stuck_action_count=0.
- aim_error_degrees, repeated_attack_interval_variance.
- 60FPS 목표; 30/60/120FPS 일관성.
- 전진/후퇴/측면 공격, 벽 구르기, UI 위 클릭, 동시 스킬 입력, 급격한 에임 변경, 적 소멸 직후, 장기 홀드 공격, 경직 중 회피, 해상도·줌 변경.
- 취소 전 아직 발생하지 않은 타격은 제거, 이미 발생한 적중 중복 생성 금지.
- 공격 홀드→새 스킬/회피→홀드 복귀, 통합 dodge 홀드→질주, dodge-only 홀드→질주 없음, release→추가 회피 없음.
- 키 재매핑/조작도움말/핫바가 실제 바인딩과 동일.
