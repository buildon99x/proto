# R3a 장비/제작 연결

R2f 실제 QA 뒤 새로 구현한 범위. 원본0.4.7과 원작 사실/UNKNOWN은 보존한다. 숫자·아이템·레시피·상인 현금은 `equipment-r3-design.md`에 적힌 Emberwatch 자체 조정값이다.

## 연결

- 마을 대장장이/작업대와 인벤토리 UI. 일곱 슬롯, 동일 기본 장비의 별도 인스턴스, 슬롯 대비 보너스, 영구 능력치 요구, 구매/판매 확인, 제작/강화.
- 기본 무장 환산값 위에 장비 보너스가 한 번만 합산된다. 철퇴·강철 충돌·자원 최대치·실제 피해·마나 재생·이동·스킬 미리보기에서 같은 파생식을 사용한다. 장비 요구는 기본+영구 배분 능력치이며 자기 보너스로 요구를 충족하지 않는다.
- 마을에서만 교체하고 상점/작업대는 실제 근접 가드가 있다. 장착으로 자원을 채워주지 않고, 제거 시 낮아진 최대치까지만 clamp한다. 쿨다운·회복 잠금은 바뀌지 않는다.
- 성공 명령의 전체 상태·고유 인스턴스·금화/재료·영수증을 기존 저장 컨트롤러로 함께 커밋한다. 같은 명령은 소비와 이벤트를 다시 만들지 않는다. 일회성 보급은 다른 명령 ID로도 다시 받을 수 없다. 저장 실패의 memory publish 차단을 검사한다.
- 새 schema version2에는 equipmentProgress가 필수. 이 재구현의 빈 장비 R2 v1 저장만 검증하여 읽을 수 있고 첫 정상 명령에서 v2로 이행한다. 누락 옵션의 기존 키는 legacy로 유지. 부분 장비/영수증을 임의 수리하지 않는다. 기존 원작0.4.7이나 소실된 Reborn import를 사용하지 않는다.

## 작은 획득 예산

정상 난이도 첫6명(유효 처치 ID를 보고한 모델 fixture) + 순찰 보고 =39G,철1,레벨2. 대장장이 일회 보급 =철1/목재2/실1/도구. 방패 제작15G+철1/목재2 뒤24G·철1, +1 강화12G+철1 뒤12G·철0. 제작 대신32G 철퇴를 구매하고 힘2점을 배분하여 장착할 수도 있다. 두 경로 모두 실물/지출/남은 보너스를 검사했다. 보고 fixture는 실제 처치 조작이 아니며 이 경로의 실제 UI 검증은 아직이다.

기존 실제 QA 프로필은13처치·69G·레벨2이므로 정상 귀환 후 해당 선택을 확인할 수 있다. 이 수치가 모든 유저의 플레이시간/난이도 합격을 의미하지 않는다.

## 추가 조작 정리

R2f 화면에서 확인한 긴 방패 키 목록은 전투 HUD에 대표 키 하나만 표시하고 전체 매핑/비용은 tooltip·접근성 라벨·도움말에 남긴다. 마우스의 화면 좌표를 매 프레임 현재 카메라 기준 월드 방향으로 재계산하며 프로필 전환 시 이전 조준과 토스트를 지운다.

## 검증 범위

R2f143검사를 유지한다. 장비 순수31개와 runtime 통합·세이브 재진입·실제 전투 파생값·사망재시도·장비 중복/지출 방지·구버전 전환을 추가한다. 합성 자원 무단 주입 대신 유효 처치 정산 핸들러를 사용한 예산 검사도 실제 정상 플레이와 구분한다. 브라우저 장비/제작·강화/판매/실전 체감은 배포 후 확인해야 한다.

미완: 첫 던전 이후를 요구하는 집중 목걸이 제작/+2 강화는 잠금 상태. 접사/품질 생성·고유품·부적·형상·상점 시간 재입고·되사기·던전·승급·상위44노드는 아직 완료하지 않았다. 회수 원본 장비 데이터 계약을 구현했다는 사실이 원작 실측 숫자나 AAA 품질을 증명하지 않는다.
