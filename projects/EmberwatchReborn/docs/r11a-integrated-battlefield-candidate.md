## Integrated behavior

- `state` registers B commands/validator, and rejects B activity in v1–v3 saves.
- Actual campaign travel selects B gates and invalidates B's objective token on
  any region transition. Region transition itself never refills pools or skips
  cooldown; ordinary elapsed walking still permits normal regeneration/CD.
- Eda's captured B command and every device use the displayed B revision plus
  modal epoch. Store revision is separate. They cannot silently refresh an old
  button's token. Quest acceptance, west/east device, beacon and report commit
  once through controller/store. Closed/replaced panels do not reopen on commit.
- The second device refreshes only the map/path cache, retaining enemies, live
  tells, projectiles, current pools, recovery and accepted action snapshots.
- Real enemy families, explicit undead/status tags and guarded low-wall/role
  rendering come from the separate retained B components. They are authored
  Emberwatch values; no unconfirmed original-game number was substituted.
- Genuine Expert guidance takes precedence over completed Tomb guidance.
  Earlier completed quest text now points to implemented continuation. A
  promoted Expert is not sent back for Adept/Expert promotion again.
- `/qa-r11/` accepts only an explicit forward QA-profile copy. Root/main and
  original Emberwatch saves are never imported. Existing target profiles cannot
  be overwritten. R10 profile/control/recovery bytes remain unchanged.
- App/package/project version is `0.11.0-reimplementation.1`, display labelR11a.
  Compact hotbars allow nine actions without a one-line horizontal overflow;
  very narrow screens use three rows. Pixel/touch-device review is still due.
