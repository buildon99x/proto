# R4c 실제 제작 리뷰 후속 수정

공개 R4c 정상 플레이에서 목걸이를 제작한 뒤에야 지능12 부족을 알 수 있었다. 다음 개발 묶음에 완성품 효과, 장착용 영구 요구/현재 능력치, 부족량과 '제작해도 지금은 장착 불가' 경고를 제작 전에 표시한다. 제작 자체는 가능하게 유지하여 자원/조건과 착용 여부를 구분한다.

previewRecipe는 기존 eligibility와 같은 판정을 재사용하고 상태·재료·아이템을 변경하지 않는다. 도구/금화가 없어도 완성품 요구를 볼 수 있다. 5개 새 자동검사 포함 전체339/339와 문법 검사가 통과했다. 이 수정은 아직 공개 v11에 포함되지 않았고 실제 화면 검수는 다음 후보에서 해야 한다. 현재 공개 앱 구현은 e1158e4 그대로다.
