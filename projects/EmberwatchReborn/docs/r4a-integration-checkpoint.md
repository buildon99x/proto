## 난이도와 계산 기준

현재 전투 배율은 기존값 그대로다. 기본 피해16의 새 보스 첫 cone을 방어4의 L1 시험 영웅이 막지 않고 맞는 고립 기준이다. 피해 = 기본피해 × 난이도피해배율 ×100/(100+방어). 실제 L4 장비/블록/이동은 이 표보다 달라지므로 이론 표를 실플레이 결과로 사용하지 않는다.

| 난이도 | 적 HP배율 / 보스HP | 피해배율 / 첫 cone 실제피해 | HP55에서 생존 접촉 횟수(사망 접촉) |
|---|---|---|---|
| 여유롭게 | 0.66 /145.2 |0.66 /10.154 |5회 생존,6번째 사망 |
| 보통 |1 /220 |1 /15.385 |3회 생존,4번째 사망 |
| 어려움 |1.25 /275 |1.25 /19.231 |2회 생존,3번째 사망 |
| 험난함 |1.5 /330 |2 /30.769 |1회 생존,2번째 사망 |

보스 방어8은 난도간 동일해 같은 공격/장비를 전부 맞히는 이상적 처치시간은 적HP배율에 비례한다(히트 반올림과 초기접촉 제외). 준비시간1/1.1/1.25초는 난도로 줄이지 않는다. 물약은 기존 최대HP55% 회복/CD5초, 자동HP회복0, MP4/초와 기력10/초의 지연 회복은 난도간 동일하다. 그래서 난도가 높아질수록 물약1병이 상쇄하는 피격 수는 줄지만 읽을 시간은 보존된다. 실제 TTK, 블록 기력 경제, 피격/회복 체감은 후보 QA에서 측정한다.

최소 경로 누적 XP는 보통791, 어려움709.5로 L5(누적700)를 보고까지 보장한다. 전 잿길→필수 던전은 보통972.5. 목표350XP와 순차 레벨 감쇠된 처치XP가 분리되어 있으며 보고에 L5 선행조건을 두지 않는다. 자세한 수지/기본 골드/선택 창고 순서는 r4-dungeon-module.md 참고.

## 공개 후보와 저장 격리

현재 루트 공개 v8/R3b는 유지하고 `/qa-r4/`에만 후보 파일을 넣는다. 후보도 전체 공개다. 후보 UI에 공개 테스트임을 표시한다.

- release 키는 기존 `emberwatch-reborn.reimplementation.v1.<profile>` 그대로.
- candidate 키는 `emberwatch-reborn.candidate.r4.v1.<qa-profile>`; 별도 슬롯/head/WebLock.
- 후보에는 일반 프로필을 생성/복사하지 않는다. 사용자가 명시적으로 누르는 버튼만 기존 재구현 QA프로필을 공유 읽기 잠금으로 읽어 빈 후보공간에1회복사한다. 체크섬 일치 후 후보 이어하기. 원본 슬롯에는 쓰지 않는다.
- 이는 과거 승인 대기인 원본 게임 테스트 파일 import와 다른 재구현 자체 QA 복사이며 파일을 읽거나 가져오지 않는다. 디버그 XP/장비/레벨 주입도 없다.
- 이미 존재하는 후보를 덮어쓰지 않는다. 후보 진전은 루트 저장으로 자동승격하지 않는다. 예전L4/E·1·Z 설정/장비/사망/퀘스트를 UI 복사로 다시 검증한다.
- 현 환경에는 지원되는 사용자-facing local preview가 확인되지 않아 임의 localhost/포워딩을 만들지 않는다. 부모가 승인한 공개 후보를 게시해 정상 입력 QA를 수행한다. 게시 전 자동검사와 게시 후 실제 QA를 구분한다.

## 다음 실제 QA 기준

1. 기존L4 QA 복사→장비/E·1·Z 유지→새로고침 후보복원→원본 미변경.
2. 촌장 의뢰/입구→경비/벽/문→오답·정답/수로→승강기/정비.
3. 세 보스 준비/접촉, 플레이어/드롭 가독성, 죽음 재도전, 핵/보고 중복 없음.
4. +2와 목걸이 재료 경쟁/첫 미구현 승급의 명확한 안내.
5. 시간은 실제입력·교전·이동·메뉴를 나누고 도구 대기/관찰정지를 포함한 총시간을 캠페인 길이로 주장하지 않는다.
