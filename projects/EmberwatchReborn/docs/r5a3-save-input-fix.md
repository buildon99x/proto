# R5a3 저장 중 단발 입력 유실 수정

R5a2 실제 F/물약 입력 유실에서 출발한다. 새 `immediate-input.js`는 busy 동안 상호작용/물약 중 최신 명시 입력 하나만 최대150ms(벽시계) 유지한다. 저장 완료 후 첫 프레임에 한 번만 실행하며 실행 전에 슬롯을 비운다. 자원/아이템은 기존 실제 reducer/저장 성공 경로에서만 소비한다.

메뉴, 사망, life/지역 전환, 저장 차단, blur/hidden, 다른 새 행동, 키 설정, 타이틀/로드, 긴 저장 지연에서 취소한다. 150ms를 넘으면 취소 사유를 표시하고 새 입력을 요구한다. 기존 스킬 회수0.18초 버퍼와 별개이며 쿨다운/자원 부족을 기다려 자동 발동하지 않는다. 유지된 키/OS repeat는 단발 pulse를 다시 만들지 않는다. 마우스 지정과 터치 물약/상호작용도 같은 실행 경로를 쓴다.

14개 새 자동 검사: 저장 중 기다림/한번 실행, 각 취소 조건, 역행·긴 시계/지연, 최신 의도/명시 취소, 키 반복, 실제 비동기 controller checkpoint 완료 뒤 물약1개 소비/재로드 CD 유지/두번째 소모 거부, 실제 portal travel 단1회. 실제 공개 후보 재회귀는 이 체크포인트 시점 아직 대기다.
