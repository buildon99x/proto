# R2c 공개본 실제 일반 입력 QA

2026-10-09, dot 클라우드 Chrome, 별도 `qa-r2-live-20261009`, 보통 난이도. 저장 import·debug 평가·자원/레벨 주입 없이 화면 버튼과 정상 WASD/마우스/Q/J/E/Esc만 사용했다.

- R2a에서 안내 확인 중 도착 지점 적에게 사망. 입력 도구 왕복 시간도 포함되므로 이를 순수 난이도 실패로 단정하지 않았다. 안전 진입 대기 필요성을 확인해 R2b를 수정했다.
- R2b에서 이동/공격 전 20초 이상 도착 안내를 읽어도 HP/마나/기력/적 위치가 보존됐다. 이어 5처치 후 8처치까지 정상 공격. 누적XP98·32G, HP37/55, 마나12/40, 물약2, 사망1.
- R2b 메뉴 재개 후 실제 Invalid step 오류 발생. rAF timestamp보다 늦은 resume performance.now가 음수 dt를 만든 것이 원인. R2c에서 0..0.05초 범위로 보호하고 5회귀 추가. 도착 대기 시간도 플레이 시간과 분리했다.
- R2c 새로고침·이어하기: 8처치/98XP/32G/HP37/마나12 유지. 메뉴 재개→귀환→촌장 보고 정상. 보상70XP/20G/철1, 레벨2·XP68/150·52G·기술3/능력5. 자동 레벨 주입이 아니다.
- 실제 훈련 UI에서 철퇴 1→2랭크 선택. 기술점수3→2, 피해 미리보기12→14.4, 다음16.8. 승인 보강 뒤 동일 클릭 재시도1회가 성공했으며 중복 소비 없음.
- 훈련 모달을 약2분 읽는 동안 HP37과 마나24가 그대로였다. 메뉴 반복 닫기·다시 열기 후 오류 재발 없음. 체크포인트 저장 뒤 새로고침·이어하기에서 레벨2/XP68/52G/철퇴2/남은점수2/처치8/사망1 유지.
- 메모리 공유 작업을 위해 13:51 UTC 안전한 훈련 모달에서 본 QA 탭만 정상 종료했다.

## 시간 해석

R2c 해당 접속 메뉴 표시: 플레이3초 / 교전0초 / 이동2초 / 메뉴153초 / 진입대기0초. 이 접속은 전투가 아닌 귀환·보고·훈련이며, 메뉴 시간은 도구 왕복·승인 대기를 포함한다. R2b 첫전투 접속은 플레이42초/교전5초/이동1초/메뉴45초였으나 당시 플레이 카운터에 도착 대기가 섞여 있어 그대로 합산할 수 없다. 교전과 이동은 중첩될 수 있다. 전체 인간 캠페인 시간·재미·AAA 품질을 입증하지 않는다.

## 미검증 / 후속

- 강화 후 처치 수/체감, 전체 감시자 전투, 물약 운영, 더 높은 난이도, 실제 창 blur/백그라운드 복귀, 모바일, 실제 청취.
- R2d 키 재설정 실제 입력/저장, 장비/제작 이후 성장, 승급·후반 완결.
- 훈련 NPC는 아직 원본 shrine 대용 표현, 기본 무기 원화와 철퇴 명칭 불일치. 시각적 완성 아님.
