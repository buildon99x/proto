# R4 첫 던전 → L5 숙련 승급 연결 제안

2026-10-09 UTC. **설계 제안만 작성했다. 아래 새 지역·적·명령·보상은 아직 구현/실플레이 검증되지 않았다.** 기존 코드·화면·세이브를 변경하지 않았고 게임 실행/전체 검사/빌드도 하지 않았다. 수지 표는 읽은 소스 값으로 한 산술 계산이다. 장기 spec의 마일스톤 명칭과 별도로, 여기의 R4는 이번 첫 던전 연결 작업명이다.

## 1. 권고와 현재 확인점

**권고:** 작은 수작업 2층 수문소, 열쇠+회수 도구, 순서 퍼즐, 수문 환경 퍼즐과 선택 창고, 독립 귀환 승강기, 패턴을 읽을 수 있는 보스 1개를 연결한다. 필수 신규 적은 일반8+보스1, 처치 기본 XP191, 분산 목표 XP350. 순찰의 최소6처치에 감시자가 포함되는 가장 짧은 Hard/Serious 경로도 누적709.5XP로 L5에 도달한다. 반복 처치나 선택 창고는 필수가 아니다.

첫 숙련 승급은 **L5 + `adept_commission` + 브란 대면 + 0G**를 추천한다. 0G는 첫 의뢰 후원이라는 명시적인 **Emberwatch 조정 제안**이다. 원작 미확인 수수료를 0으로 판정한 것이 아니다. 유한 보상을 장비/제작/죽음으로 소진한 플레이어도 메인 승급에서 영구적으로 막히지 않는다. 승급은 자동 실행하지 않고 NPC 선택으로 처리한다.

### 이미 관측된 끝점과 한계

잿길은 **일반24+감시자1 = 총25적**이다. 일반25+감시자1이 아니다. 실제 정상 입력 기록은 전부 처치, 순찰 보고, 상자2개로 누적XP492, L4 42/250을 확인했다. 실제 금화 수입183/지출59/잔액124, 철3/목재0/실3, 철퇴+0·방패+1·두건+0, 남은 능력점13이다.

기록된 교전29초는 이어하기 이후 **추가12처치(감시자 포함)** 구간이다. 전체 첫 게임 시간이나 모델 검사 시간이 아니다. 메뉴384초, 이동19초 등과 겹치는 계측이므로 이를 더해 목표 플레이시간을 충족했다고 하지 않는다. 현재의 빠른 전투를 그대로 길게 늘리려고 HP·거리·대기를 부풀리지 않는다. 새 구간의 목표는 단서 해석, 도구 사용, 공격 방향 대응, 자원/장비 선택, 귀환 이유를 실제 행동으로 만드는 것이다.

### 출처 구분

- **보존된 HWII 참조:** 기본4기술 첫 랭크 비용0, 레벨업 속성점5, L2–4 기술점3/L5–14 기술점4, 숙련 최소L5, Hard/Serious 처치 XP×0.75, L5부터 입문 적 XP×0.5. 원본 catalog의 비용/계수/배타 관계/UNKNOWN은 유지한다. 레벨과 훈련 티어는 별도다.
- **기존 Emberwatch 조정:** XP곡선, 기본 파생/재생, 능동 방패/돌진 공간·시간, 현재 잿길 적과 퀘스트, 장비·제작·강화 가격, 죽음 금화5%와 재도전 규칙.
- **이 문서의 신규 Emberwatch 제안:** 수문소/보스/퍼즐/도구/좌표/보상/승급 위임장과 첫 수수료0G. 원작 지도·적·퍼즐·경제를 복원했다는 주장이 아니다.

### 수락/재방문과 퍼즐의 의미

- 현재 R3 세이브는 이미 감시자 상자를 열었으므로 상자 재개봉을 열쇠 획득 조건으로 삼지 않는다. 촌장 수락이 기존 영수증을 확인하고 새 열쇠를 정확히1회 준다.
- 열쇠와 손잡이는 비소모 퀘스트 도구다. 아이템 stats/금화 구매/특정 능력치 배분이 필수가 아니다. 재접속 후에도 실제 소유와 열린 문이 일치해야 한다.
- 순서 퍼즐은 입구 기록과 같은 문양/한글 이름을 사용한다. 색만으로 구별하지 않는다. 정답을 이미 아는 플레이어에게 기록 읽기 클릭을 강제해 시간을 늘리지 않는다.
- 잘못된 순서는 진행0으로 돌아가는 정상 퍼즐 이벤트이며 XP/G/HP를 바꾸지 않는다. 먼 거리·없는 대상·잘못된 입력은 무변경 실패다. 재시작·오답 반복으로 추가 적/보상을 만들지 않는다.
- 환경 퍼즐은 순서판과 다른 행동이다. 급수/배수의 상태를 눈으로 보고 손잡이를 실제 사용한다. `급수 차단 + 배수 개방`이 되어야 주 통로가 열린다.
- 배수 방향1은 빠른 보스 접근, 방향2는 선택 창고의 위험/재료를 지금 감수하는 선택이다. 메인 계단은 양쪽 모두 열린다. 선택은 되돌릴 수 있고 이미 연 주 통로/창고는 다시 닫지 않아 플레이어를 벽에 가두지 않는다. 위험을 미루는 탐험 선택이며 배타 스킬 분기로 표현하지 않는다.
- 독립 승강기는 수문 퍼즐 완료만으로 자동 설치하지 않는다. 하층 입구에서 직접 체인을 연결해야 한다. 이것이 마을 정비→하층 복귀, 보스 실패 재도전, 선택 창고 재방문의 짧은 귀환 동기다.

## 3. 두 층의 수작업 공간 초안

월드 단위/32px 타일은 현 runtime 기준이다. 현재 두 지역의 크기·스폰·적 위치를 바꾸지 않는다. 아래 새 좌표와 바닥 마스크는 **배치 초안**이며 벽·문·몸 반경11·투사체·돌진 경로 검사와 실제 조작 확인 전까지 통행 보장이라고 하지 않는다. 새 아트 생성 없이 기존 바닥/벽/상자/횃불/귀환 표식 자원을 재사용하고 기능 표식을 더한다.

### 상층 `sluice_upper`, 28×22타일(896×704)

바닥 사각형 `(tileX,tileY,width,height)`의 합집합을 손으로 정의하고 나머지는 벽/접근 불가로 둔다. 현재 `createMap`의 전체 직사각형 바닥을 그대로 새 던전이라고 사용하지 않는다.

- 입구 `(1,14,7,7)` → 하단 연결 `(7,17,7,3)` → 경비실 `(12,13,8,8)`.
- 꺾인 통로 `(18,11,3,5)` → 순서판실 `(18,7,9,6)` → 중문 통로 `(12,8,8,3)`.
- 제어실 `(9,3,8,8)` → 수로 연결 `(5,5,7,3)` → 계단실 `(1,1,7,8)`.
- 스폰 `(112,576)`, 잿길 귀환 `(80,624)`, 기록 `(184,512)`, 손잡이 `(168,568)`.
- 경비실 적 `(432,528)` 척후, `(480,584)` 척후, `(548,520)` 추적자.
- 순서판 `(656,368)/(704,368)/(752,368)`, 중문 충돌 타일 `(17,8,1,3)`.
- 제어실 적 `(496,240)` 방패병, `(416,256)/(464,320)` 척후. 두 밸브 `(336,176)/(336,224)`.
- 수로 차단 타일 `(7,5,2,3)`은 정상 배수 후 통행. 하층 계단 `(112,112)`.

### 하층 `sluice_lower`, 24×20타일(768×640)

- 안전 진입실 `(1,13,8,6)` → 연결 `(7,12,7,3)` → 보스 전실 `(11,9,7,7)`.
- 전실 북쪽 통로 `(14,6,3,5)` → 보스실 `(10,1,13,7)`.
- 선택 창고 `(1,2,7,8)`와 연결 `(5,9,9,3)`, 배수 전 창고 문 `(8,9,3,3)`.
- 스폰 `(112,544)`, 상층 계단 `(80,576)`, 승강기 `(144,480)`.
- 전실 적 `(416,400)` 척후, `(512,352)` 추적자. 봉인종은 전실 북쪽에서 근접 조작하고, 두 전실 적을 모두 처치해야 한다.
- 보스 `(560,144)`, 수문핵 `(624,112)`. 좁은 세로축과 넓은 가로축에서 원형 경고를 옆으로 피할 수 있는지 특히 검수한다.
- 창고 적 `(128,192)/(224,160)` 추적자, `(192,272)` 방패병. 상자 `(96,96)`.

포털의 왕복 도착점은 고정된 안전 앵커를 사용한다. 잿길의 신규 던전 입구 후보 `(944,96)`은 감시자/상자 뒤에 놓고, 마을 승강기 출입구 후보 `(545,480)`은 작업대·대장장이·촌장에 짧게 연결한다. 스폰/귀환점 바로 옆에 적을 놓지 않고 적과 최소170월드단위 이상 간격을 검수한다. **현 AI는 거리300만으로 벽 너머에서도 활성화되므로, 간격만으로 안전하다고 판정할 수 없다.** 방/문/전투 개시 조건에 따른 활성화가 함께 필요하다.

빈 이동은 목표가 아니다. 독립 승강기 이후 치유/제작/보고→하층 복귀는 새 출입구 한 쌍으로 해결한다. 선택 창고를 위해 돌아올 때도 이미 끝낸 잿길 전역을 다시 걷게 하지 않는다.

## 4. 전투와 보스 수치

현재 scout/archer/bruiser의 HP/피해/방어/속도/XP/G는 그대로 재사용한다. 신규 적과 아래 공격 패턴은 모두 Emberwatch 조정이며 원작 동일 보스가 아니다. 던전의 신규9적은 **입문 tier**로 둔다. L5부터 적 XP 감쇠가 실제로 적용되는 예산이다.

|---|---|---:|---|
| 정면 쓸기 | 준비1.0초, 사거리96, 반각1.1rad, 조준 방향 고정 | 물리16 | 회수1.0초. 정면 방패/옆 회피 후 철퇴 |
| 수문 직선탄 | 준비1.1초, 폭20 경고선, 발사 방향 고정, 속도240·거리440 | 물리12 | 회수1.1초. 옆으로 이동하거나 방패, 공격 중 돌진 회수와 구분 |
| 바닥 울림 | 준비1.25초, 보스 중심 반경112의 채워지는 원 | 물리18 | 회수1.25초. 원 밖으로 이동하고 긴 회수에 반격 |

패턴 개시 거리는 쓸기96/직선탄280/울림112로 제안한다. 근접 패턴 차례에 거리가 멀면 보스가 접근하며, 접근을 위해 경고를 계속 취소/재시작하지 않는다. 패턴마다 새 피해 판정을 한 번만 실행한다. 원형/직선 경고와 실제 판정을 같은 모양 데이터에서 만들고, 경고 후 조준을 몰래 바꾸지 않는다. 기존 impact/slash/ring/line 및 enemyTell/enemyRelease 음원 기능을 재사용한다. 임시 placeholder 보스 외형은 완성 아트로 표시하지 않는다.

기절은 기존 전사 기능을 존중한다. 미리 준비한 기절/돌진으로 패턴을 끊는 것은 유효한 대응이다. 무적 구간·시간제 HP 잠금·정해진 횟수까지 피해 무효로 보스 시간을 강제하지 않는다. 강해진 전사가 빠르게 처치했다면 그 시간을 그대로 기록한다. 두 패턴을 볼 수 없을 만큼 무의미하게 끝났는지는 정상 장비/랭크를 함께 기록해 별도 판단하고, 먼저 위치/진입/적 역할/공격 가독성을 개선한다.

| 난이도 | 보스 HP | 쓸기/직선탄/울림 raw 피해(난이도 적용 후, 영웅 방어 전) | 처치 XP 기본 배율 |
|---|---:|---|---:|
| Easy | 145.2 | 10.56 / 7.92 / 11.88 | 1 |
| Normal | 220 | 16 / 12 / 18 | 1 |
| Hard | 275 | 20 / 15 / 22.5 | 0.75 |
| Serious | 330 | 32 / 24 / 36 | 0.75 |

위 피해는 난이도 배율 적용 후, 영웅 방어/방패/무적 판정 전 raw 값이다. 최종 실제 피해라고 표시하지 않는다. L5 이상이면 위 XP에 입문 감쇠0.5가 추가된다. 어려움에서 가능한 생존/자원/회피 창은 아직 실플레이 미검증이다.

## 5. XP 계산과 레벨5 보장 범위

현재 XP곡선은 L1→2 100, L2→3 150, L3→4 200, L4→5 250. 누적 L5 기준700, L6 기준1000이다. 곡선/레벨업 점수는 바꾸지 않는다.

### 출발 수지

- 전부 완료: 척후17×9 + 추적자4×12 + 방패병3×22 + 감시자90 = 처치357. 순찰70 + 남쪽 상자20 + 감시자 상자45 = 목표135. Normal/Easy492, Hard/Serious402.75.
- **엄격한 최소 진입:** 척후5×9 + 감시자90 = 처치135. 감시자도 순찰6처치에 포함되므로 척후6을 추가로 강제하지 않는다. 순찰70 + 감시자 상자45만 회수하면 목표115. Normal/Easy250, Hard/Serious216.25. 남쪽 상자와 나머지19적은 생략 가능해야 한다.

### 신규 필수 수지

- 적: 경비실30 + 제어실40 + 전실21 + 보스100 = **기본191XP**.
- 목표: 손잡이60 + 순서60 + 환경70 + 핵70 + 보고90 = **350XP**. 발견/퍼즐/핵/보고에 분산한다. 승강기나 같은 문/도구의 반복 클릭은 XP0.
- 선택: 추적자2+방패병 = 기본46, 창고 회수30. 필수 L5 계산에 넣지 않는다.
- 목표 XP는 `grantExperience`로 그대로 지급하고 난이도/하위티어 감쇠를 붙이지 않는다. 적은 `experienceMultiplier`로 **각 처치 시 현재 레벨**을 확인한다. 마지막 티어에서 전체 처치를 일괄 계산하지 않는다.

전25적 Normal은 환경 해결 보상으로 이미 L5라 전실21과 보스100이 각각 절반으로 지급된다. 따라서 단순 `492+191+350`과 결과가 다르다. 선택 창고의 위치/순서를 바꾸면 감쇠 시점과 최종 수치도 달라질 수 있으므로 실제 handler 경로로 재산출한다.

첫 초안의 환경XP60/목표합340은 엄격한 최소 Hard에서699.5로 **0.5 부족**했다. 감시자를 순찰에 포함하는 소스 규칙을 반영해 환경XP70으로 수정했다. 이 보정은 원작 값 변경이 아니라 신규 목표 보상의 설계다. 향후 적을 생략 가능으로 바꾸거나 목표 보상을 줄이면 이 최저 경로를 다시 확인해야 한다.

L5에서 누적 속성점20, 누적 기술점13을 획득하며 이미 쓴 점수는 뺀다. 레벨5 도달, 실제 숙련 승급, 새 기술 구입을 서로 구분한다. 보상 재시도나 승급이 포인트를 다시 주어서는 안 된다.

## 6. 재료·골드·능력치 선택

### 유한 골드

새 필수 처치 G56(10+13+7+26), 목표 G100(0+8+12+20+60) = **156G**. 선택 창고는 처치15+상자18 =33G. 기존 정책대로 난이도는 금화를 곱하지 않는다.

| 경로 | 기존 누적 수입 | 새 필수 수입 | 최종 누적 수입, 지출/죽음 전 |
|---|---:|---:|---:|
| 전체 잿길 | 183 | 156 | 339 |
| 최소6적 | 98 | 156 | 254 |
| 현재 실제 QA 잔액을 이어함 | 잔액124 | 156 | **잔액280**(새 지출/죽음 없을 때) |

임의 반복 적/무한 보급으로 금화를 보충하지 않는다. 초반 승급0G로 필수 진행을 보호하고 장비/제작/+1/+2에 실제 선택 지출을 둔다. 다른 승급비를 채택하려면 모든 유한 보상을 소비·매각한 경우와 반복 죽음 이후의 복구 경로를 먼저 명세해야 한다.

### 실제 이어하기의 재료

현재 QA의 철3/목재0/실3에서 환경 보상 철1, 기존 보급 `first_dungeon_salvage`의 철2/목재1/ember_shard1을 받으면 **철6/목재1/실3/불씨조각1**이다. 보급 정의나 기존 장비 수치를 변경할 필요가 없다.

- 현재 방패+1→+2: 22G/철2/불씨조각1. 방어 +1 추가. 다른 자원 회복은 없음.
- 집중 목걸이 제작: 18G/철1/불씨조각1. 최대마나+5, 마나재생+0.3/초. 영구 INT12가 필요하므로 기본 INT10에 추가2 배분을 실제 선택해야 한다.
- 척후 조끼 제작: 20G/실3/목재1. 방어/체력 외투 대신 최대기력/이동을 택할 수 있다. 현재는 가슴 슬롯이 비어 있어 첫 가슴 장비 선택이 된다.
- 불씨조각이1개이므로 **지금 +2와 지금 목걸이 제작은 동시에 할 수 없다.** 판매로 재료를 되돌려주거나 메뉴 재진입으로 복제하지 않는다. 첫 던전 이후 다음 공급처는 후속 설계 항목으로 안내한다.
- 기존 철을 모두 써도 던전 환경+보급에서 새 철3을 얻어 새 장비의 +1(철1)과 +2(철2)를 선택할 수 있다. 특정 장비/강화 소유를 던전 필수 조건으로 삼지 않는다.
- 선택 창고의 추가 철1/목재1/실2/물약1은 재방문 보상이며 L5/+2 해금의 필수 재료가 아니다. 불씨조각은 추가하지 않는다.

### 배분의 뜻을 수치로 설명

기본 STR18/DEX12/INT10은 참조를 유지한다. 아래 **추가5 배분 시** 변화는 현재 `warrior-balance.js`의 Emberwatch 환산이며 원작 일반 파생식이라고 하지 않는다.

| 추가 배분5 | 현재 파생 변화 | 이 구간에서 확인할 차이 |
|---|---|---|
| STR | 최대HP+10, 물리 공격+3, 방어+0.5 | 철퇴 피해·생존, 실제 장비 영구 요구. 기술 배율/적 방어 이후 피해는 별도 |
| DEX | 최대기력+5, 공격속도 배율+0.025, 치명확률+0.005, 기력재생+0.3/초 | 방패 자원/기본공격 운용. 치명확률은 +0.5%p이지 +5%가 아님 |
| INT | 최대마나+10, 시전속도 배율+0.025, 주문배율+0.05, 마나재생+0.2/초 | 망치/향후 치유 자원, 목걸이 요구. 공짜 자원 충전 없음 |

현재 실제 미사용13점은 자동 배분하지 않는다. STR2를 배분해 철퇴 요구를 충족했던 실제 경험을 이어, INT2/목걸이와 방패+2의 선택을 안내한다. 모든 빌드에 같은 답을 강요하지 않는다.

## 7. 실패·재시도·저장 계약

1. 입장: 순찰 보고/감시자 상자/수락/열쇠/거리/생존 중 빠진 조건을 정확히 표시한다. 부족하면 XP/G/도구/위치를 바꾸지 않는다.
2. 퍼즐: 진척과 영구 개방을 저장한다. 올바른 최종 조작+보상+영수증은 한 snapshot에서 처리한다. 오답은 명시한 퍼즐 초기화만 하며, 틀렸다는 이유로 반복 적/HP 벌칙/재료 소비를 만들지 않는다.
3. 처치: `world.defeated[region]`의 고유 ID로 기존처럼1회 정산. 지역 이동·죽음·재접속에서 이미 처치한 적은 되살리지 않는다. 새 보스를 기존 `road-warden` ID로 재사용하지 않는다.
4. 생존한 적: 현재 정책대로 이동/재시작 시 체력과 임시 전투 상태를 새로 만든다. 보스 실패 후 미처치 보스는 전체 HP로 재도전한다. 전투 중 새로고침으로 플레이어 자원을 공짜 회복하지 않고 저장된 자원/쿨다운/회수 잠금을 유지한다.
5. 죽음: 현재 `floor(gold*0.05)` 손실, 기록된 처치·XP·퀘스트·도구·퍼즐·장비는 보존. `retry`는 죽은 경우만, life 증가와 마을 귀환을1회 처리한다. 승강기를 열었다면 그곳으로 한 번에 돌아가 보스를 다시 시도한다. 긴 잿길/상층 반복 주행을 요구하지 않는다.
6. 보스와 영웅 동시 사망: 기존처럼 처치 XP/G를 먼저1회 정산하고 죽음 비용1회. 보스 receipt는 유지되지만 수문핵을 줍기 전에는 `first_dungeon_cleared`를 주지 않는다. 재도전 후 남아 있는 핵을 실제로 회수한다.
7. 보스 처치/핵 회수/촌장 보고/대장장이 보급/숙련 승급은 각각 다른 기록이다. 핵 회수는 기존 보급을 직접 두 번 주지 않고, 대장장이의 `equipmentChanged` receipt 경로를 통해 별도로 받는다.
8. 목표 영수증의 `r4:*` 키와 장비의 commandId를 같은 개념으로 혼용하지 않는다. 목표 완료 여부를 영수증/권위 flag로 확인하고 보상을 먼저 지급한 뒤 나중에 표시하지 않는다.
9. 저장은 기존 controller의 전체 커밋→성공 후 live state 적용 순서. 실패/불명확 커밋이면 진행 차단, 성공 reload 후 같은 ID 재시도. 실패를 피하려고 receipt를 삭제하지 않는다.
10. 이미 닫힌 문 안에 저장된 잘못된 좌표, core/commission만 있는 불일치 기록은 명시적으로 거절한다. 기존 R3 이행은 기존 기록을 보존하고 새 R4 상태를 미완으로 시작하며, 이미 연 감시자 상자는 수락 조건으로 인정한다.

### 숙련의 최소 실효 범위

G2는 tier 문자열 변경만으로 완료되지 않는다. 첫 숙련 승급에서 적어도 `lay_on_hands`(온기 나누기)와 `judgement`(단죄의 일격)를 실제 구입·사용하는 작업을 함께 계획한다. 첫 비용은 각각 참조2점이며 무료로 자동 지급하지 않는다. 참조 첫 랭크 치유60/마나30/CD13, 단죄 무기계수300%/마나30/CD4는 보존하고 공간·캐스트·접촉값은 따로 조정 기록한다.

이미 입문 기술에 점수를 썼으면 부족한 이유를 표시한다. L5의 신규4점을 남기면 두 기술 첫 랭크를 선택할 수 있지만 이를 강제로 유보하거나 포인트를 다시 주지 않는다. 선택 창고를 승급 후 남겨 두는 경로에서 새 기능 사용을 검수할 수 있다. 전부 이미 완료한 경로의 후속 숙련 전장은 별도 연결이 필요하다. 이 두 기술이나 후속 활용까지 구현하지 않은 R4 부분 체크포인트는 **던전/승급 기반 완료, G2 전체 미완**으로 명확히 표시한다. 나머지 숙련14개와 전문/달인 노드도 실행 검증 전에는 잠긴다.
