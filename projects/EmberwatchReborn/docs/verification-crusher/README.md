# First playable crusher loop candidate

Baseline: `ac9ec129b358660dc3a4bef8049fcf4c28899190` on `codex/emberwatch-rebuild`. This is the first functional crusher checkpoint, not a completed PoE2 port or a new release label. The earlier recovery-copy checkpoint is not this deliverable.

## Runtime contract

The candidate town menu selects a session-only crusher mode after starter mace training and learning Judgement. The effective mainhand must be the existing trained starter mace or an existing validated equipped mace. Existing equipment transactions remain unchanged. Selection neither changes controls nor saves a build field. Region/retry rebuilds carry the selected mode into fresh actors; explicit reload, profile load and app restart use the default mode.

Primary, positive-damage, living-enemy mace hits add one unit per cast per enemy. Two units create authoritative Primed readiness and an owned procedural diamond marker. Crits add one unit; secondary/proc packets do not build readiness. New values `1` and `2` are explicitly authored candidate hit counts, not confirmed PoE2 damage-scaled or rarity-dependent thresholds. There is no accumulation decay or automatic full-buildup heavy stun in this prototype.

The current learned Judgement key becomes a targeted crusher strike. At actual contact it checks the captured/tracked chosen actor, current life, weapon, range, sector and LOS. No nearest-target fallback exists. A valid positive hit on a Primed, nonimmune, not-already-heavy-stunned actor consumes readiness, applies a separate heavy-stun state and emits one shockwave centred on the real hit location. This is an actual hit transition, not consumption of an old stun timer or armour-break debuff. The primary is hit once and excluded from the wave. Each other live, target-visible actor within the existing Judgement radius receives at most one nonrecursive secondary hit. One cast cannot emit a second wave. A lethal direct conversion still emits its one wave and clears corpse state.

Missing, moved out of range, unprepared, dead, blocked-by-wall or immune targets do not produce a free wave. Already-heavy-stunned targets cannot convert again. Death and heavy-stun expiry reset the new enemy state; region replacement creates new enemy state. Existing short stun/armour break are not consumed or shortened. Immunity reads explicit actor/catalog flags; no new blanket boss immunity is invented.

Existing action quotes retain damage, costs, cooldown, contact, duration, range and arc. Heavy stun reuses `WARRIOR_BALANCE.charge.stunSeconds` (0.75 seconds); strike and wave reuse learned Judgement damage/radius. Learned Shackles still applies to the direct target; learned Trial by Fire retains its existing caster-sector area. This candidate changes selected-mode direct Judgement geometry from a sector sweep to a chosen primary plus conditional radial wave. It remains the existing learned spell/stat mapping, not a claim to implement PoE2's exact weapon skill formula. The classic mode retains its existing sector attack.

No save/state/recovery/equipment writer, JSON hook, serialization, migration, input queue, numeric balance module, binding or resource formula is modified. No a19 work is imported or recreated. Default-mode event/state equivalence is tested. Marker drawing is read-only; contact FX no longer fabricates a generic burst for crusher whiffs. Actual builder/strike actions reuse owned mace silhouette and existing cadence. No new sound, commercial art or image is added.

## Evidence and limits

See `summary.json`, test/build logs and `preservation.json` beside this file. Readable logs normalize terminal CR/trailing whitespace; `raw-command-logs.zip` preserves exact command output, with `raw-command-log-sha256.json` for byte checks. New tests execute production combat handlers, the real menu click handler, cursor resolver, J/E keyboard handlers, frames and checkpoint saves. They include deduplication, lethal conversion, target-centred geometry, LOS, immunity, death, expiry, actual legal equipment purchase/equip, resource/recovery constraints, classic-mode equivalence and no saved-field leakage. Stationary enemies/earned progression in automated fixtures are scripted test setup, not actual native play. Test debugging retained the initial invalid fixture with out-of-contract invulnerability; the final fixture uses ordinary hero state and the real save validator.

The official [0.3.0 patch notes](https://www.pathofexile.com/forum/view-thread/3826682) confirm a Primed-to-heavy-stun interaction for Seismic Cry. They do not establish this candidate's two-hit threshold, radius, formulas or a complete current Boneshatter tooltip. This is an authored adaptation of the requested loop; exact PoE2 numerical parity is unverified. Storm combo/Tempest Bell and magma shield remain separate unimplemented loops. No overall AAA, PoE2 parity, actual dot play, visual acceptance, listening or native accessibility acceptance is asserted.

## Normal-input QA

Extract the complete candidate package, serve its root using an existing HTTP server, and open `/qa-r14/` (or `/qa-r14/index.html`). Do not serve the `qa-r14` directory itself at `/`: the existing candidate route guard rejects that path. The prior README root-serving instructions were incorrect; this package corrects them without changing the guard.

Use a fresh candidate profile or your existing candidate profile through the ordinary game UI. Train the starter skills with Bran, complete the existing initial campaign and earn Adept promotion, then buy Judgement with earned skill points. Keep a trained starter mace or legally buy/equip the existing iron mace. At idle in town, open the menu's **전투 방식 · 파쇄철퇴** and select it. Choose PoE WASD controls explicitly if desired; the mode does not overwrite settings. Use the currently displayed bindings (default PoE WASD J for mace and E for Judgement).

Travel normally to a field and use a living target strong enough to survive two mace contacts. Aim at the target, land two real mace hits, observe its diamond, then aim at it and press the current Judgement key when action recovery permits. Confirm direct contact, one target-centred wave hitting nearby actors, diamond removal and eventual heavy-state reset. Repeat with a new enemy, an unprepared target, empty ground, a target leaving range, a wall and a target dying before contact; these must not create free waves. Repeating the strike during heavy stun must not emit another wave. Check that normal recovery/cost/cooldown rejections still operate and that switching back in town restores normal Judgement. Region travel keeps selection but reload resets it.

Verify supported-browser keyboard/menu focus, readable marker at zoom/occlusion, continuous J/E chains, impact sound and visibility in dense fights. The launcher root-entry metadata versus nested QA entry remains an existing release-routing issue; aggregate build success does not resolve it. Publication/deployment remains coordinator-owned.
