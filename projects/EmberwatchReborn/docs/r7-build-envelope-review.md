# R7 중기 전투 예산: 포인트를 실제로 쓴 세 빌드

2026-10-09. 수치 조정 전의 분석이며 정상 입력 전투 결과가 아니다. 앞선 실제 L8 QA 캐릭터는 능력치31점·기술13점을 사용하지 않았으므로 그 약한 장비/분배만으로 새 지역 난이도를 맞추면 안 된다.

`node app/scripts/adept-build-envelope.mjs`는 기존 퀘스트/승급/처치 보고/목표/구매/기술투자 reducer를 통해 full Normal 경로 L8(1865.5XP)을 만든다. 위치와 처치 보고는 scripted fixture이다. XP/레벨/완료플래그/무료 스킬을 주입하지 않는다. 실제 QA의1845.5XP와20XP 차이가 있는 별도 full route이다.

모든 빌드는 능력치35점과 기술25점을 정확히 소비한다. 철퇴+1/방패+1은 정상 구매·장착·강화 handler를 사용한다. 지능형도 철퇴 영구 요구를 충족하기 위해 힘2를 투자한다. 처음 분석에서는 지능형의 힘0 장착과 기반기술 이전 증강 구매가 실제 handler에서 거절됐고, 조건을 우회하지 않고 합법적 순서로 고쳤다.

|---|---|---|---|
| 힘 | 힘35 | 철퇴5, 망치3+균열1, 거력2, 빛나는 기사1, 온기1/단죄1 |153 /54 /20.5 /36|

이는 첫 접촉+후속 주기 산술이다. 치명타·방패·이동·회피·경직·다수 적·시전 MP·망치 번개/균열 추가효과를 제외했으며 실제 TTK나 생존 시간이라고 부르지 않는다. 모든 적/난이도 행은 JSON에 포함된다.

힘형 망치 피해99.4/MP31.25(완전MP 한 번), 지능형178.22/MP43.75(두 번, 번개 틱 별도), 혼합128.78/MP37.5(두 번). 소모MP의 자연복구 지연포함8.313/8.724/8.871초로, 주문 강도와 회복 주문의 공유 MP 선택은 유지된다. 13초 온기 쿨다운을 MP재생만으로 단축할 수 없다.

## 다음 정상 입력 검수

- 실제 남은 포인트를 투자한 캐릭터로 근접형/주문형 각각 고갯길의 원형→부채꼴 정예와 분산 사수를 검수한다. 기존 실제 QA 분기는 균열이므로 번개형은 별도 정상 성장 또는 구현된 재분배 경로가 있어야 한다. 현재 재분배는 미구현이다.
- 강해진 철퇴가 잡몹을 빠르게 정리하는 것은 성장 보상이다. 이를 없애려고 모든 HP를 일괄 늘리지 않는다. 장치 접근 순서, 엄폐/직선 예고, 군집/분산과 MP 회복 선택이 달라지는지 본다.
- 현재 난이도 차이는 보존된 배율이고 전투 패턴 자체는 난이도별 추가 변화가 없다. 고난도 패턴 완성을 주장하지 않는다.
- 보통 최소/고투자 빌드 모두 진행 가능하고, 어려움/험난에서도 숨은 수리비·필수 기술·파밍이 생기지 않는지 반복 확인한다. 조정이 필요하면 원작 참조를 바꾸지 않고 Emberwatch 기본 적/공간/연출 값만 별도 기록한다.
