## 시간과 질적 발견

후반 접속의 마지막 관찰은 플레이50초/교전28초/이동4초/메뉴240초/진입대기12초이며 교전·이동은 중첩 가능하다. 초기 접속은 마지막86초/교전3초/이동7초/메뉴89초/진입대기38초 뒤 계속 진행했다. 완결 세션 계측이 아니므로 총 캠페인 시간으로 합산하지 않는다. 메뉴 밖 도구 판독 중 약15초가 지나 추가 피해가 난 구간이 있다. 실제 연속 손플레이와 구분해야 한다.

- 사망 저장의 초기 재시도 창 지연은 수정 우선. `loadProfile`이 Web Audio 준비를 기다린 뒤 사망창을 여는 순서와 재구성 전투의 dead=false/arrival=true가 원인 후보였다. 실제 handler의 pending-audio 회귀로 재현했다.
- 큰 벽/문, 비슷한 적 실루엣, 이름/피해 숫자가 액션과 겹쳐 장갑병 분기 효과를 읽기 어렵다. 위험선은 보이지만 투석 선이 멀리 길어 화면을 가로지른다. 시각 품질 합격 아님.
- 퀘스트 목표를 달성한 뒤 과거 에다 대사에 숙련 승급을 다시 권하는 문구가 남는다. 내비게이션/완료 상태 표현 개선 필요.
- 오디오 재생 아이콘은 있었지만 실제 청취 품질 검증은 하지 않았다.

## R6a1 수정 검증

로드된 사망 상태의 retry UI를 선택적 audio 준비보다 먼저 표시한다. 죽은 전투 재구성은 진입대기를 끄고 이미 정산한 사망을 반복 정산하지 않는다. 살아 있는 진입 보호와 기존 소모/쿨다운은 유지한다.

새6회귀 중5개가 구코드에서 실패, 수정 후6개 통과. 전체488/488, lint/격리build 통과(하위 검수). 이6개는 실제 loader의 브라우저 경계 대체와 runtime/controller 검사이며 브라우저 시각 검사 아니다. 공개 후보 수정 배포 후 같은 저장의 죽음 재로드, 살아 있는 이어하기, 첫 진입을 추가 확인해야 한다. 자동 fixture의 XP와 정상입력 XP는 서로 대체하지 않는다.
