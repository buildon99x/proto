# Dubai miniature implementation plan

Goal: add a third living miniature faithful to the supplied portrait Dubai reference. The reference pixels were inspected locally; the image is not a public asset or texture.

Architecture: existing offline Three.js diorama-worlds kernel, gallery registry and shared accessible camera controls. Dubai owns its procedural geometry and absolute-time transport/fountain animation. No changes to harbor or Singapore worlds. Branch codex/dubai-diorama-gallery from remote Singapore 6bd76c0.

Builder choices: warm engraved atlas sheet, slim stepped central Burj Khalifa, sculpted sail hotel left, palm island rear-left, detailed glass cluster right, gold frame, scalloped mall and turquoise pool, elevated foreground metro, small vessels and people. Reuse existing procedural water algorithm without periodic sparkles. Camera is portrait-friendly and user-controlled. A flat image/video alternative would lose exploration; external models introduce assets/network/licensing unnecessarily. Existing procedural 3D is the chosen approach under the user's direction to proceed without optional questions.

Tasks:
1. Establish baseline, then fail tests for third registry entry, bounded deterministic Dubai geometry, transport motion and landmark silhouettes.
2. Implement Dubai-specific architecture helpers and world. Reuse established camera integration and static batching, mark dynamic roots.
3. Extend gallery and standalone build, metadata and docs. Test full suite, build/lint, registry and aggregate build.
4. Independent code review, fix findings, commit/push isolated branch and wait for Preview. Parent performs actual GPU screenshots/controls/animation QA and visual comparison. No visual or AAA claim before that evidence.

Review focus: slim silhouette not a broad cylinder, no disconnected rails/boats, readable map title, bounds over whole loop, scene allocation stable, full resource disposal, controls on both gallery and standalone, preserve Singapore speed and camera behavior. Acceptance requires actual browser images, not CPU tests alone. No production promotion.
