# Changelog

## 1.0.0 — 정식 첫 판 (규칙 v1.2)

컨셉 v1.1 플레이 프로토타입(입사~3장)을 정식 프로젝트로 옮기고, 엔딩과 완전 클리어까지 구현했다.

- **콘텐츠:** 5장 전부, 10계열 36단계(가칭 포함, notes/content.md), 부지 15곳, 주니어 발록 입사와 엔딩, 완전 클리어 체크리스트
- **선택 점검 (notes/choice-audit.md):** 봇 8성향 × 체크인 시각 흔들기 5로 v1.1을 굴려 선택 하나가 진행을 크게 가르는 곳을 찾았다
  - 빈틈 걷기: 빈틈의 모험가는 떠나지 않고 천천히 걷는다 → 멈춘 월드 0/40 (v1.1: 13/40)
  - 결재 ② 즐거운 시간(누적): 벽이 사라지고 달력이 목표(D28~35)에 맞았다 (v1.1: 표준 D12, 40번 중 18번 엔딩 불가)
  - 승진 발령, 키워서 잇기, 근속 이월, 진화 5초 되돌리기, 본사 전근, 꽉 찬 던전에 놓기(직원 자리 +1)
  - 챕터 수입 배율: 후반 스마일 약 180만 → 약 16만
- **화면 (notes/ux-review.md):** 입구 막힘 표시, 걷는 모험가, 촘촘 모드·군중 묶음, 채용 카드 가로 흐름, 토스트 위치, 오렌 누름 표시, 조사 규칙, Esc 순서, 테스트 도구 접기, 세로 화면 안내
- **도구:** TypeScript 규칙 모듈(화면과 분리), 페이싱·선택 점검 스크립트, 규칙 테스트 19개, CDP 스모크·장면 굽기
