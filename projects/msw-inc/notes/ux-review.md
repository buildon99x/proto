# 화면 점검 — 편의성 · 직관성 · 일관성 (v1.0)

> 컨셉 v1.1 프로토타입을 정식 프로젝트로 옮기면서 화면을 다시 만졌다. 그 과정에서 찾은 문제와 고친 것을 적는다.
> 점검 방법은 세 가지다. ① 시연 장면 16개를 구워 눈으로 봤다(`pnpm --filter msw-inc shots` → `assets/screenshots/`). ② 튜토리얼을 실제 클릭·드래그로 끝까지 밟았다(`pnpm --filter msw-inc smoke`, 13단계). ③ 봇 점검에서 막힌 자리를 화면 흐름으로 되짚었다([choice-audit.md](choice-audit.md)).
> 기준은 컨셉의 톤 규칙이다(01-tone-and-manner.md). 빨강은 지금 고칠 곳에만 쓴다. 경고음은 없다. 오렌은 느낌표 두 개로 한 줄만 말한다. 결과는 놓기 전에 보인다.

## 1. 한눈에

| 구분 | 건수 | 대표 |
|---|---|---|
| 막다른 길 (편의성) | 4 | 둘 곳 없는 신입, 채용 추천이 비는 길 끝, 되살릴 수 없는 월드, 대기실 가득 |
| 오해를 부르는 안내 (직관성) | 5 | "같은 던전에 신입을 두라"는 힌트, 거짓이 된 "보류해도 벌칙 없음", 요동치는 결재 인원 |
| 규칙이 화면마다 다름 (일관성) | 5 | 진화만 되돌릴 수 없음, 오렌 말풍선이 누를 수 있는지 안 보임, 조사 오류 |
| 규모 (후반 화면) | 3 | 발판 6층, 모험가 250명, 채용 카드 10장 |
| 톤 | 3 | 새 용어를 회사 말투로, 발록·엔딩 연출, 테스트 도구가 게임 UI처럼 보임 |

## 2. 막다른 길 — 누를 곳이 없는 순간

| # | 무엇이 막혔나 | 플레이어가 겪는 일 | 고친 것 |
|---|---|---|---|
| U1 | 직원 자리가 모두 찬 월드에서 빈틈 → 채용 | 신입이 대기실로 가지만 초록으로 빛나는 곳이 없다. 어디에도 놓을 수 없다 | 꽉 찬 던전에 끌어 놓으면 **직원 자리 +1을 같이 산다.** 결과 카드에 "직원 자리 +1 · 스마일 1,000"이 먼저 보인다. 추천 자리 계산도 이 구매를 포함한다 |
| U2 | 길 끝(예: 3장 Lv 42–45)은 채용할 수 있는 계열로 닿지 않는다 | v1.1 채용 시트는 추천 리본 없이 카드만 보여 줬다. 봇도 여기서 영영 멈췄다 | **키워서 잇기:** 보라 리본 "진화 1번이면 Lv 42–45!". 이미 그쪽으로 크는 직원이 있으면 제목 줄에 "와일드보어가 한 번 더 진화하면 이어져요 (근속 0/2,000)". 오렌도 같은 말을 한다 |
| U3 | 부지 9곳이 모두 자란 직원으로 차고 입구가 막힘 | 신입을 둘 부지가 없다. 대기실도 가득 찬다. v1.1 규칙에서는 월드가 0명으로 멈췄다 | 직원 말풍선에 **[본사 전근 +환급]**. 던전 하나를 비우고 새로 시작할 수 있다. 규칙 쪽에서는 빈틈 걷기로 월드가 멈추지 않는다 |
| U4 | 입구가 막힌 채 퇴근 | 밤새 새 손님이 들어오지 못한다(v1.1은 0명, v1.2는 느린 걸음) | [퇴근]을 누르면 오렌이 한 번 붙잡는다. "입구가 막혀 있어요!! 그래도 퇴근하려면 한 번 더 눌러요". 채용 시트가 그 구간으로 열린다. 막지는 않는다(P5) |

## 3. 오해를 부르는 안내

| # | 무엇이 어긋났나 | 고친 것 |
|---|---|---|
| U5 | 진화 시트 힌트 "💡 달팽이를 뽑아 들판에 두면 다시 이어져요" | 던전 레벨은 평균이다. 같은 던전에 섞을수록 모든 던전이 중간 레벨로 뭉개진다. 봇 점검에서 이 힌트대로 두면 3장에서 입구를 맡을 던전이 사라졌다. → 진화 시트가 **[▲ 승진 발령]**을 먼저 권한다(진화한 직원은 새 레벨에 맞는 곳으로, 빈자리엔 신입). 버튼에 손을 올리면 그 수의 결과가 월드 위 유령 발판으로 바뀐다 |
| U6 | "보류해도 벌칙은 없어요. 근속은 계속 쌓여요" | v1.1 규칙에서는 진화하면 근속이 0이 됐다. 보류한 만큼 버려졌으니 문구가 거짓이었다 → **근속 이월**로 문구를 참으로 만들었다("근속은 그대로 남아요") |
| U7 | 결재 ② "즐기는 모험가 20명 (동시)" | 인원이 시간마다 오르내려 막대가 줄기도 했다. 자리가 모자란 월드에서는 영영 닿지 않는 벽이 됐다(choice-audit §4) → **즐거운 시간(누적)**. 막대는 줄지 않는다. 결재함은 "지금 😊 N명이면 약 1.4일 뒤에 채워져요. 사람이 늘면 더 빨라요. 줄지는 않아요"라고 말한다 |
| U8 | 입구 막힘이 "빈틈 Lv 1–2"로만 보였다 | 가장 아픈 빈틈인데 다른 빈틈과 같은 말로 불렸다 → 땅 라벨 **"입구 막힘"**, 진화·드래그 결과 첫머리에 "입구가 막혀요", 리포트 명장면에 "😐 입구 막힘 3시간", 할 일 칩에 "입구 막힘" |
| U9 | 빈틈의 모험가가 제자리에 서 있기만 했다 | 걷기 규칙을 그대로 보이게 했다. 😐로 칸 안에서 아주 천천히 오른쪽으로 걷는다(흐린 걸음). "막혔지만 망하지 않는다"가 한눈에 보인다 |

## 4. 일관성

| # | 어긋남 | 고친 것 |
|---|---|---|
| U10 | 채용·배치·이벤트·자리는 5초 되돌리기인데 진화만 되돌릴 수 없었다 | 진화·승진 발령·본사 전근까지 **모든 결정이 5초 되돌리기.** 진화 시트는 미리보기 때문에 남는다. 도감 칸은 되돌려도 남긴다 |
| U11 | 오렌 말풍선을 누르면 되는지 안 되는지 알 수 없었다 | 누르면 갈 곳이 있을 때만 말풍선 테두리가 노랗게 되고 끝에 `›`가 붙는다 |
| U12 | "들판로", "쉼터으로" 같은 조사 | `ro()`: 받침이 없거나 ㄹ이면 "로". 을/를·이/가도 받침으로 고른다 |
| U13 | Esc가 화면마다 다르게 닫혔다 | 말풍선 → 시트 → 모달(도감·결재·체크리스트) → 현장 순으로 하나씩 닫는다 |
| U14 | 되돌리기 토스트가 시트 내용과 드래그 결과 카드를 가렸다 | 시트가 열리면 토스트는 시트 위로 올라간다. 끄는 동안에는 흐려진다. 결과 카드가 먼저다 |

## 5. 후반 규모 (4~5장, 던전 12~15곳 · 모험가 200명+)

| # | 문제 | 고친 것 |
|---|---|---|
| U15 | 발판이 6층까지 쌓여 하늘의 지역 이름과 겹치고, 도트가 윗층 발판을 가렸다 (컨셉 D3) | 층 간격을 400/층수로 줄인다. 5층부터 **촘촘 모드**: 도트 72%, 하늘 지역명 숨김(땅에 지역명이 있다), ▲ 배지 축소 |
| U16 | 모험가 250명을 한 명씩 그리면 발판 위가 뭉개진다 | 150명을 넘으면 **같은 발판·같은 레벨·같은 표정끼리 대표 한 명 + ×인원** |
| U17 | 채용 카드가 10장이 되어 화면을 넘친다 | 가로로 흐르는 카드. 추천(초록)·키워서 잇기(보라)가 맨 앞. 카드마다 "Lv 15 · 적정 10–20" |

## 6. 톤앤매너

| # | 점검 | 결과 |
|---|---|---|
| T1 | 새 용어를 회사 말투로 | **승진 발령**(진화 + 옮기기 + 채용), **본사 전근**(퇴사 환급), **즐거운 시간**(결재 ②), **입구 막힘**, **키워서 잇기**. 모두 회사 문구류와 같은 결이다. 농담의 대상은 회사와 몬스터다 |
| T2 | 엔딩과 발록 | 5장 결재 서류에 발록 입사 지원서 클립("…손님이 오면, 맞아 드리겠습니다."). 대기실에 보라 토큰으로 들어온다. 엔딩 컷은 파티 도착 → "…손님인가." → "…퇴근!" → 머쉬맘 마지막 결재 → THE END → 완전 클리어 체크리스트 |
| T3 | 테스트 도구가 게임 UI처럼 보였다 | 평소에는 흐리게 접힌다(마우스를 올리면 보인다). `?dev`로 펼친다 |
| T4 | 경고음 | 새로 넣은 것(입구 막힘, 퇴근 붙잡기, 못 하는 행동)도 소리 없이 빨간 토스트나 오렌 한 줄로만 알린다 |
| T5 | 빨강 규칙 | 끊긴 길(아무도 안 막힘)은 옅은 점선, 걷는 사람이 있을 때만 빨강. 발령 미리보기의 비는 구간만 빨간 예고 빗금 |

## 7. 남은 것

| # | 과제 | 이유 |
|---|---|---|
| R1 | 모바일 세로 화면(컨셉 D2) | 1280×720 무대를 창에 맞춰 줄일 뿐이다. 세로 폰에서는 "가로로 돌리면 더 크게 보여요" 안내만 한다. 세로축 = 레벨인 "밧줄 오르기" 화면은 다음 단계 |
| R2 | 도트·소리는 자리표시 | 메이플스토리 월드 공식 리소스로 바꾼다. 크기 규격(모험가 30×42, 직원 40×36)은 지켰다 |
| R3 | 진화 시트의 정보량 | 사원증 두 장 + 도감 줄 + 결과 + 발령 힌트 + 버튼 셋. 1280 폭에서는 읽히지만 세로 화면에서는 두 단계로 나눠야 한다 |
| R4 | 사람 플레이테스트 | 봇 점검은 "선택 하나"의 효과를 재는 데 쓴다. 발령을 사람이 이해하는지, 촘촘 모드가 읽히는지는 사람이 해 봐야 안다 |
