# Decisions

|---|---|---|---|
| 2026-09-25 | 화면은 React가 아니라 DOM 직접 조작(TypeScript 모듈)으로 | 프로토타입이 매 프레임 수백 개 요소의 위치·클래스를 바꾸는 구조로 이미 검증됐다. 그대로 옮기는 편이 위험이 작다 | React 재작성: 화면 코드 약 2,000줄을 새로 짜야 하고 프레임 루프와 상태 동기화가 늘어난다 |
| 2026-09-25 | 규칙 수치는 `rules.ts`에 V11·V12 둘 다 둔다 | 선택 점검이 같은 봇으로 옛 규칙과 새 규칙을 나란히 굴려야 개선을 수치로 증명할 수 있다 | V12만 두기: 개선의 근거를 다시 만들 수 없다 |
| 2026-09-25 | 빈틈 걷기 (떠남 대신) | P5. 입구가 막혀도 월드가 멈추지 않는다. 하나씩 빼 보면 이 변경이 가장 큰 차이를 막는다 | 입구 줄(떠나지 않고 기다림): 기다리는 동안 아무도 들어오지 않아 여전히 월드가 비었다 |
| 2026-09-25 | 결재 ② 누적 즐거움 | 벽 제거 + 달력 조절 손잡이. 목표 사다리의 같은 지표(😊)를 적분한 값이라 사다리가 끊기지 않는다 | 인원 목표만 낮추기: 벽은 그대로고 달력만 더 빨라진다 |
| 2026-09-25 | 근속 분배는 v1.1 그대로 (직원 수로 똑같이 나눔) | 점검에서 "한 던전에 몰기"와 "한 마리씩 펼치기"의 차이가 ±0.4일 안이었다(v1.2). 바꿀 근거가 없다 | 팀 분배(한 명 몫이 덜 줄어듦): 한때 넣었다가 점검 뒤 뺐다 |
| 2026-09-25 | 근속 이월은 넣는다 (효과는 작다) | 달력 차이는 ±1~2일로 작다. 하지만 "보류해도 벌칙 없음"이라는 화면 문구를 참으로 만든다 | 문구만 고치기: 보류가 실제로 손해인 채로 남는다 |
| 2026-09-25 | 3~5장 계열 이름은 가칭으로 먼저 | 챕터 4·5를 돌려야 점검이 된다. 공식 리소스 대조는 다음 단계 | 빈칸으로 두기: 엔딩까지 플레이가 안 된다 |
| 2026-09-25 | 규칙 v1.3은 V13으로 따로 둔다 (V12는 남긴다) | audit이 개선 전(v1.2)과 후(v1.3)를 같은 봇으로 나란히 굴려야 개선을 수치로 보인다 | V12를 고치기: 플레이 리뷰의 기준 측정을 다시 만들 수 없다 |
| 2026-09-25 | 엘리트·필드 보스는 새 규칙이 아니라 R5(이벤트) 확장 | P1 "규칙 다섯 줄"을 지킨다. 둘 다 "월드에 일어나는 일"이라 이벤트와 같은 자리다 | R6 추가: 규칙이 여섯 줄이 되고 직원·던전 레벨 규칙과 섞인다 |
| 2026-09-25 | 필드 보스는 손님 (던전 레벨 평균에 들지 않는다) | P2. 보스가 직원이면 방문하는 동안 길이 끊긴다 | 보스를 직원으로 배치: 길이 끊겨 플레이어가 보스를 피하게 된다 |
| 2026-09-25 | 새 보상(눈금·엘리트·보스)에 스마일은 없다 | 플레이 리뷰 F7(스마일을 쓸 곳이 없다)을 더 나쁘게 만들지 않는다 | 스마일 보상: 가장 쉽지만 쌓이는 숫자만 는다 |
| 2026-09-25 | 1장을 첫 세션 안에 끝낸다 (입사 버프가 ②에도) | 핵심 결정(승진 발령)과 진척 보상(결재 도장·새 지역)을 첫 10분 안에 겪게 한다 | 출근 리포트까지 빨리 감아 보여 주기: "떠나 있어도 돈다"를 말로만 가르친다 |
| 2026-09-25 | 튜토리얼 "가로 = 레벨" 배속 ×5 (계획은 ×3) | 실측에서 ×3은 누를 곳 없는 구간이 59초였다. ×5로 36초 | 모험가를 누르면 말풍선: 입력만 늘고 빈 구간은 줄지 않는다 |
| 2026-09-25 | 1장 Lv 14–15는 고참 달팽이 승진 발령 한 번에 잇는다 (1.1.1) | 1장 직원으로는 채용만으로 Lv 13까지. 던전 레벨은 평균이라 들판에서 진화만 하면 Lv 6이 되어 안 닿는다. 기다리던 둘째 달팽이는 대본 밖에서 최대 136분 걸렸다 | 1장에 Lv 12 안팎 채용 직원 추가: "높은 단계는 키워서만"이 첫 장부터 흐려진다. 둘째 달팽이 근속 시작값 올리기: 대본 밖 함정(그냥 진화 + 이벤트)은 그대로다 |
| 2026-09-25 | "② −N시간"은 자리 확장에만 보인다 (계획은 이벤트·직원 자리도) | 경험치 2배와 직원 자리 +1은 즐기는 인원을 늘리지 않아 ②를 당기지 않는다. 없는 효과를 숫자로 보이면 거짓이다 | 계획대로 셋 다: 이벤트 카드에 근거 없는 숫자가 뜬다 |
| 2026-09-25 | 첫 40분 밀도는 배속이 아니라 사람 수·가짓수로 (규칙 v1.4, 입사 버프 삭제) | 요청: "배속을 높이는 것이 아니라 경험의 빈도 자체를 늘린다". 버프는 20분 뒤 절벽(레벨업 10분에 200 → 7)을 만들었다 | 버프 45분으로 늘리기: 절벽이 뒤로 밀릴 뿐이고 요청과 반대다 |
| 2026-09-25 | 파티 도착을 20초 박자로 (무작위가 아니라) | 사건을 무작위로 두면 평균 10초여도 40분 최장 공백이 50~80초다. 최장 20초는 무언가 하나가 박자를 쳐야 지킨다 | 사람을 더 많이(분당 8명): 줄 선 사람이 100명을 넘고 떠나는 사람이 는다 |
| 2026-09-25 | 붐비는 시간은 월드 시각으로 센다 (플레이 시간이 아니라) | "화면이 켜져 있든 아니든 같은 step()" 원칙. 튜토리얼 뒤 바로 떠나면 약 250명이 자리를 못 찾고 돌아가지만 리포트에는 보이지 않는다 | 접속 중에만 붐비기: 오프라인 진행이 다른 함수가 되고 결정성이 깨진다 |
| 2026-09-25 | 구간 개방은 길이 이어져 있을 때만 | 끊긴 길 위에 새 구간을 얹으면 빨간 빈틈이 겹쳐 "지금 고칠 곳"이 흐려진다. 고치면 다음 땅이 열리는 순환이 된다 | 퇴근만으로 열기: 방치한 월드에 빈틈이 쌓인다 |
| 2026-09-25 | 첫 진화 근속 2,000 → 60 (2·3단계는 그대로) | 배속 없이 신입마다 40분 안에 진화·승진 발령을 겪게 한다. 2장 마지막 구간(키워서만 닿음)을 5분 안팎 기다림으로 | 새내기 근속 배율: 효과가 같고 규칙 한 줄이 는다 |
| 2026-09-25 | 3~5장 수입 배율을 ×0.57 | 자리·사냥터로 인원이 늘어 스마일 최고가 약 38만이 됐다. 약 16만(v1.2 결정)으로 되돌려도 달력은 같다 | 그대로 두기: 플레이 리뷰 F7(쓸 곳 없는 스마일)이 나빠진다 |
