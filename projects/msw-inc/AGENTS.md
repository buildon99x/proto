# MSW 주식회사 — 프로젝트 지침

Prototype Lab 개별 프로젝트. 레포 공통 규칙은 루트 `AGENTS.md`를 따르고, 아래는 이 프로젝트에만 해당한다.

## 기준 문서

- 설계의 원본은 `docs/concept/maple-idle/msw-inc/`(컨셉 v1.1)다. 규칙·수치·화면을 바꾸면 이 프로젝트의 `spec.md`와 함께 컨셉 문서와의 차이를 `notes/`에 남긴다.
- 컨셉 폴더의 `prototype/`은 v1.1 플레이 프로토타입(바닐라 JS)이다. 이 프로젝트로 옮길 때 참고 구현으로 쓰고, 원본은 기록용으로 그대로 둔다.
- 설계 판단은 컨셉의 다섯 원칙(P1~P5)으로 근거를 단다. 특히 P2 "몬스터 레벨 = 던전 레벨"과 P5 "떠나 있어도 망하지 않는다"는 협상 대상이 아니다.

## 작업 규칙

- 프로젝트 전용 코드·에셋·데이터·프롬프트·테스트·노트는 이 폴더 안에만 둔다.
- 도트는 자리표시다. 메이플스토리 공식 리소스를 레포에 넣지 않는다.
- 동작이 바뀌면 `brief.md`, `spec.md`, `eval.md`를 같이 맞추고 `pnpm sync:registry`를 돌린다.
