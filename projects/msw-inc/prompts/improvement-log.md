**도중에 바로잡은 것:** ① 진화 시트는 그냥 진화가 길을 비울 때만 발령 버튼을 보여서 고참 달팽이 시트에 발령이 없었다 → 발령이 더 이을 때도 권한다. ② 오렌 문장의 "(으)로"가 따옴표 뒤에서 틀렸다 → 조사를 이름으로 고른다. ③ 옛 세이브의 튜토리얼 단계 이름을 새 순서로 옮기는 표를 더했다. ④ `pnpm audit`은 pnpm 내장 보안 점검이 먼저 잡는다 → 문서의 명령을 `pnpm run audit`으로.
