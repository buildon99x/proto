# Improvement Log

## 2026-09-25 · 1장 Lv 14–15 정체 풀기 (1.1.1)

**요청:** 초반 Lv 10~15 구간의 사냥터 오픈이 정체 구간으로 보인다. 점검하고 개선안을 제안해 달라. 이어서 추천안으로 개선해 달라.

**한 것:** 원인을 규칙으로 좁혔다. 1장 직원은 채용만으로 Lv 13까지 닿고, 던전 레벨은 직원 평균이라 들판에서 진화해도 Lv 14–15에 안 닿는다. 튜토리얼은 그냥 진화 → 둘째 달팽이 기다림(대본 보장) → 승진 발령 순이라 빨간 빈틈을 61초 봤다. 대본 없이 그냥 진화 + 경험치 2배를 고르면 136분 막혔다(시뮬레이션). 추천안대로 고참 첫 진화를 승진 발령으로 바꾸고 이벤트를 길 이은 뒤로 옮겼다. 진화 시트가 "발령해야 더 이어질 때"도 발령을 권하게 했고, 오렌·채용 시트에 옮기기 안내(`moveFix`)를 더했다.

**결과:** changelog 1.1.1. 빨간 Lv 14–15 61초 → 21초, 1장 결재 도장 2:45 → 2:22, 첫 세션 입력 24 → 21번(playreview:ui). 규칙 수치는 그대로이고 audit 40판 모두 엔딩, 멈춘 월드 0.

**도중에 바로잡은 것:** ① 진화 시트는 그냥 진화가 길을 비울 때만 발령 버튼을 보여서 고참 달팽이 시트에 발령이 없었다 → 발령이 더 이을 때도 권한다. ② 오렌 문장의 "(으)로"가 따옴표 뒤에서 틀렸다 → 조사를 이름으로 고른다. ③ 옛 세이브의 튜토리얼 단계 이름을 새 순서로 옮기는 표를 더했다. ④ `pnpm audit`은 pnpm 내장 보안 점검이 먼저 잡는다 → 문서의 명령을 `pnpm run audit`으로.
