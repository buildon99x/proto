# DEAD FREIGHT / BLACK PINES

제한된 4색과 디더링으로 그린 숲 속 1인칭 슈터 개발 빌드입니다.

GPT Site: https://dead-freight-browser.buildon733500.chatgpt.site (소유자 전용)
현재 비주얼 및 실제 플레이 검증은 로그인 대기 중입니다. 배포 성공을 플레이 검증 완료로 간주하지 않습니다.

## 실행

- `pnpm --filter dead-freight build`
- app/dist 디렉터리를 정적 서버로 열거나, 모노레포에서 `pnpm build:project -- dead-freight` 후 런처로 실행
- 최신 데스크톱 브라우저의 WebGL, 키보드/마우스 필요

## 조작

WASD 이동 · Shift 달리기 · Space 회피
마우스 조준 · 좌클릭/F 발사 · 우클릭/Q 해머/펌프
R 장전 · 흰 타이밍 구간에서 R 재입력으로 강화 장전
1/2/3 무기 선택 · E 회수/탈출 · M 지도 · Esc 일시정지
마우스 잠금이 불가능하면 화살표 키로 조준할 수 있습니다.

## 전투

적의 사격 전 섬광을 읽고 이동하거나 회피하세요. 회피는 스태미나를 소비합니다. 정확한 타이밍 장전은 3초간 공격력을 높이고, 실패하면 장전이 늦어집니다. 헤드샷과 빠른 연속 처치는 스타일 점수를 높이며 피격되면 연속 보상이 끊깁니다.

안개 속 중계소의 표적을 처치하고 금빛 증표 가까이에서 E를 누르세요. 시작 지점의 착륙장으로 돌아와 E로 탈출합니다.

## 제작/검증

원작 코드·이미지·음원을 포함하지 않습니다. 직접 제작한 3D 기하, 절차적 재질, 효과음과 Three.js 0.160.1 (MIT)을 사용합니다. 최신 제공 이미지의 색/디더링/숲/무기 구도를 지향하지만 아직 실제 렌더 비교가 완료되지 않았습니다. 원작의 완전한 복제본이 아닙니다.

`pnpm --filter dead-freight test`로 22개 모델 검사를 실행합니다. 자세한 상태는 eval.md를 보세요.
