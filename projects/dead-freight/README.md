# DEAD FREIGHT / RIFLE FOUNDATION 0.7.2

R-4 라이플 한 종의 FPS 기반과, 340×340m 단일 연결 지역을 다루는 1인칭 Extraction 개발 체크포인트입니다. `proto/projects/dead-freight`에서 개발합니다. 완성된 상용 오픈월드 규모나 품질을 의미하지 않습니다.

GPT Site: https://dead-freight-browser.buildon733500.chatgpt.site (사용자 요청으로 전체 공개)

## 현재 라이플 체크포인트

R-4는 별도 탄창/약실, 연사/3점사, 입력 버퍼, 달리기 후 사격 복귀, 일반/빈 탄창 재장전, 거리별 피해와 방어구 반응을 구현했습니다. 기존 세 무기는 유지되지만 새 기준의 완성 검증은 아직 아닙니다. 라이플 한 종의 실제 플레이·청취가 다음 단계 진입 조건입니다. 두 도시 맵, 완성형 레이드/AI/창고/경제 및 다섯 무기 완성은 아직 구현되지 않았습니다.

## 플레이 루프

남쪽 착륙장에서 출발해 벌목 야영지, 화물 집하장, 폐채석장의 분기 경로를 선택하세요. 보급품과 선택 화물을 회수하고, 북쪽 중계소의 표적을 처치해 증표를 얻습니다. 남쪽 착륙장 또는 동쪽 긴급 회수장에서 E로 신호를 보내고 6초 동안 구역을 지키면 탈출합니다. 구역을 벗어나면 신호가 취소됩니다.

지역에는 17명의 국소 교전 적과 720그루의 충돌 가능한 나무, 점프 가능한 낮은 엄폐와 슬라이드 통로가 있습니다. M 지도와 목표 거리, 도로 표지로 이동할 수 있습니다. 발각되지 않은 원거리 적은 지도에 드러나지 않습니다.

기본 난이도는 HARDCORE이며 첫 진입에서는 관광객을 선택할 수 있습니다. 현재 시간 제한은 없고 다음 계약도 같은 지역을 초기화합니다. 메뉴의 무기·난이도 변경은 새 원정에 적용되며 일시정지 후 계속하기는 현재 설정을 유지합니다.

회수 가치는 탈출 성공 때만 브라우저의 로컬 저장소에 누적됩니다. 저장 실패는 미저장 가치와 재시도 버튼으로 표시하며 기존 기록은 지우지 않습니다. 보관 값은 현재 누적 기록용이며 아직 구매·제작에 사용하지 않습니다. 사망하면 현재 화물 가치를 잃습니다. 저장은 이 브라우저/사이트에 한정되며 클라우드 계정 동기화, 장비 보관함 또는 완성된 메타 경제는 없습니다.

## 조작

- WASD 이동 · Shift 달리기 · Space 점프
- Ctrl/C 슬라이드 · X 회피 (스태미나 사용)
- 마우스 조준 · 좌클릭/F 발사 · 우클릭 정밀 조준
- 펌프/슬라이드는 자동 작동하며 회복 시간은 건너뛸 수 없습니다
- R 재장전 · B 라이플 연사/3점사 전환
- 기존 세 무기는 흰 구간에서 R 재입력으로 타이밍 장전
- 4 라이플 · 1/2/3 기존 무기 · E 회수/탈출 · M 지도 · L 레이저 · Esc 일시정지
- 마우스 잠금이 안 되면 화살표 키로 조준

걷기는 초당 2, 달리기는 초당 10의 스태미나를 실제 이동량에 따라 소비합니다. 점프 10, 슬라이드 28, 회피 45를 사용하며, 지상에서 멈추면 초당 24를 회복합니다. 소진되어도 느리게 걸을 수 있습니다.

## 시각 방향

지표는 대기가 햇빛을 막는 영구적인 밤입니다. 상층부 사건의 원인은 밝히지 않습니다. 시설의 국소 작업등과 제한된 간접광으로 길과 적을 읽을 수 있게 합니다. 모든 무기의 크기와 위치를 낮춰 중앙 조준 영역을 비웠습니다. 화면 전체의 디더링/랜덤 그레인을 제거했습니다. 조준점은 정밀 조준 중에도 유지되고 명중 표시는 별도입니다. 차가운 색조와 붉은 총기 액센트를 유지하며 표면 풍화는 월드 재질에만 적용됩니다. 내부 렌더는 960×540입니다.

## 실행과 검사

- `pnpm --filter dead-freight build`
- `pnpm --filter dead-freight test`
- `pnpm --filter dead-freight lint`
- `app/dist`를 정적 서버로 열거나 `pnpm build:project -- dead-freight`로 런처에 복사
- 데스크톱 WebGL, 키보드/마우스 필요

원본 게임 코드·이미지·음원을 포함하지 않습니다. 직접 제작한 기하/절차 재질, 라이선스를 확인한 Pixabay 녹음을 게임 동작에 맞게 조합한 라이플 오디오, 기존 프로토타입 오디오와 로컬 Three.js 0.160.1 (MIT)을 사용합니다.

음원 출처와 게임 내 사용 범위는 `audio-provenance.md` 및 `assets/audio/rifle/manifest.json`을 보세요. 원본 녹음은 저장소에 배포하지 않습니다. 라이플 음원의 파형/타이밍 검사는 실제 청취를 대신하지 않습니다.

자동 검사는 물리·교전·맵 경로·뷰모델·오디오 신호·렌더러 없는 통합을 다룹니다. 공개 사이트의 메뉴까지 실제 클라우드 브라우저로 열었으나, 해당 브라우저의 그래픽 렌더러가 비활성화되어 WebGL 컨텍스트 생성이 실패했습니다. 따라서 실제 3D 영상, 일반 입력 플레이, 음질 및 프레임률 검증은 아직 완료하지 못했습니다. 0.7.1은 이 실패 때 잘못된 플레이 버튼과 HUD를 숨기고 명확한 오류·다시 불러오기 동작을 제공합니다. 배포 성공이나 오류 화면 검사를 실제 플레이 통과로 간주하지 않습니다. `eval.md`에 상세 상태가 있습니다.

`assets/diagnostics/region-layout-0.6.png`는 실제 맵 데이터로 만든 경로도이며 게임 화면 캡처가 아닙니다.

0.7.2는 메뉴 키보드 조작, 저장 실패 복구, 기존 저장의 다음 계약 번호 복원, 사망·일시정지 문구, 불필요한 구급/방탄 소모와 시작 무기에 따른 표적 방어구 차이를 고칩니다. 원정 시간은 일시정지를 제외한 실제 경과 시간이며 물리는 1/120초 고정 간격으로 따라잡되 한 프레임 최대 0.25초로 제한합니다. 긴 브라우저 정지 구간을 한 번에 시뮬레이션하지 않습니다.
