# DEAD FREIGHT — 브라우저 FPS 습작

## 실행

GPT Site: https://dead-freight-browser.buildon733500.chatgpt.site (owner-private). 이 모노레포에서는 `pnpm build:project -- dead-freight`로 정적 아티팩트를 생성합니다. WebGL 지원과 키보드/마우스가 필요합니다.

app 디렉터리로 실행하려면 `python3 -m http.server 4173` 후 `http://localhost:4173`을 엽니다. 현재 개발 환경의 클라우드 미리보기 연결은 실패했으며, 사용자 컴퓨터에서의 실행도 아직 확인하지 못했습니다.

## 목표

1. 운송 구역을 통과하여 저택의 붉은 갑옷 표적을 찾습니다
2. 표적을 처치한 뒤 금빛 증표에 다가가 E로 회수합니다
3. 처음 시작한 파란 착륙장으로 돌아와 E로 탈출합니다
4. 다음 계약은 적 체력이 높아지고 시작 방어력이 보강됩니다

## 조작

- WASD 이동, Shift 달리기
- 마우스 조준, 좌클릭 또는 F 발사
- 우클릭 또는 Q 해머 당기기/펌프 조작
- R 장전
- 1 리볼버, 2 산탄총, 3 쌍기관단총
- E 회수/탈출, M 지도, Esc 일시정지
- 화살표 키로 키보드 조준 가능
- 시작 화면에서 수동 조작, CRT 효과, 소리, 난이도 선택 가능

마우스 잠금은 시작 버튼의 사용자 클릭으로 요청합니다. 브라우저가 잠금을 허용하지 않으면 화살표 키로 조준할 수 있습니다. 창을 벗어나거나 다른 탭으로 이동하면 일시정지합니다.

## 구현 범위

직접 제작한 3D 도시/저택 레벨, 세 종류 무기, 탄약과 장전 상태, 수동 해머/펌프, 파괴 가능한 벽과 상자, 폭발 통, 적 추적/공격, 헤드샷, 방어력, 회복 및 탄약 아이템, 현상금 회수와 탈출, 성공/사망/재시작, 반복 계약, 효과음과 화면 효과.

## 참고와 차이

참고 작품: devpetrichor의 HEADCUTTER
https://store.steampowered.com/app/4603230/HEADCUTTER/

Steam의 공개 1920×1080 스크린샷 네 장을 직접 확인했습니다. 해당 작품은 확인 시점에 미출시 상태였으며 원작을 직접 플레이하거나 전체 기능을 검증한 것은 아닙니다.

참고한 시각 특성은 1인칭 카메라, 대형 전경 총기, 회녹색 산업 구역, 붉은색/금색 저택, 청색 테두리의 어두운 HUD, CRT 선과 낮은 렌더 해상도입니다. 이 빌드는 새로운 이름·지도·캐릭터·무기로 제작했습니다. 원작의 그림, 스프라이트, 얼굴, 담배 UI, 음원, 대사, 코드, 로고를 포함하지 않습니다.

비주얼은 동일하지 않습니다. 원작의 정교한 픽셀 아트 대신 기하학적 3D 모델과 절차적 재질을 사용했습니다. 적 애니메이션과 파괴 범위는 단순화되어 있으며, 선원 대화/우주선/상점/원작의 전체 캠페인은 구현하지 않았습니다.

## 검증 상태

- JavaScript 구문 검사: 통과
- 순수 게임 로직 테스트 14개: 통과
- 실시간 브라우저 실행/입력/오디오/프레임레이트: 미검증
- 렌더링 스크린샷과 원작의 시각 비교: 차단

클라우드 브라우저가 file URL을 허용하지 않았고 HTTP 개발 미리보기는 502 Connection refused를 반환했습니다. 이 제한을 우회하지 않았습니다. 따라서 현재 파일은 테스트 가능한 개발 빌드이며, 검증 완료된 최종 복제본으로 제시하지 않습니다.
