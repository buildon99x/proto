# 유물왕 — MDA 설계

> 시점: 2026-09-17 기준 / 모드: **B(순설계)** / 길이: 심화
> 프레임워크: MDA(Mechanics–Dynamics–Aesthetics) + Design Contract 4층

## 0. 설계 전제

| 항목 | 판정 |
| --- | --- |
| 게임 유형 | 패키지-완결(프로토타입). 수익화·가챠 없음 |
| 장르 | 방치형(Idle/Incremental) × 수집 × 비동기 자산 경쟁 |
| 플레이 관계 | **Solo** — 라이벌은 NPC 시뮬레이션 |
| 플레이 목적 | 소비형 + **비동기 경쟁형**(순위표) 혼합 |
| 세션 | **무한 세션** + 짧은 능동 개입(1~5분) |
| 플랫폼 | 웹(데스크톱 + 모바일 터치), 정적 산출물, 오프라인 동작 |
| Design pattern | **집중형** — FOMO·Completionism·Progression 3축이 ★★★★★ |

### 장르 가이드 공백 처리

분석 프레임워크의 장르 가이드에 **방치형/증분(Idle·Incremental) 항목이 없다**. 빈 화면에서
축을 재검토하지 않고 인접 3장르의 예상 프로필을 합성해 출발점으로 삼았다.

- **하드캐주얼 모바일 Puzzle**(#10)에서: Submission ★★★★★, Progression ★★★★★,
  Solace ★★★★, **Mastery ★★ (낮은 게 장르 본질, 결함 아님)**
- **자동화 시뮬레이션**(#8)에서: Optimization(Functional), Completionism, Save System Integrity 필수
- **가챠 오픈월드 RPG**(#9)에서: FOMO ★★★★★, Completionism, Fair Progression 민감도

합성 결과에 이 게임 고유의 **유일성(N=1) 공급 원장**을 얹은 것이 아래 프로필이다.

## 1. Mechanics — 규칙과 자원

### 1.1 자원

| 자원 | 역할 | 획득 | 소비 |
| --- | --- | --- | --- |
| 발굴력 `D` (진척/초) | 모든 진행의 속도 | 인부·장비·유적 해석 | — |
| 진척 `P` | 깊이와 드랍의 연료 | 발굴력 × 시간, 클릭 | 층 굴착, 드랍 임계 |
| 깊이 `L` (층) | 발굴지별 도달 지층 = **시대** | 굴착 | 상위 티어 접근 |
| 자금 `₩` | 설비 투자 | 유물 매각, 전시 수입 | 인부·장비·발굴지·감정비 |
| 소장 자산 | **점수** = 소장 유물 평가액 합 | 유물 보유 | 매각 시 감소 |

### 1.2 핵심 규칙 10개

> **(정정 — B6, `app/src/game/balance.ts`가 정본)** 아래 10개는 초판(v0.1
> 설계 단계) 그대로였고 실제 구현 상수와 최대 28배까지 어긋나 있었다. 값은
> 갱신하고, 근거인 *창발*(왜 이 수식인가)은 그대로 둔다.

1. **굴착** — 층 `L` 도달 비용 `C(L) = 300 × 2.45^(L-1) × 권역계수` 진척. 발굴지당 12층
   (기존 `120 × 2.6^(L-1)`은 초판 추정치였다).
2. **지층 = 연대** — 층이 깊을수록 오래된 시대. 층마다 고유 유물 풀.
3. **드랍** — 진척 고정값이 아니라 **그 층의 기대 평가액에 비례하는 임계**
   (`dropThreshold(L) = layerExpectedValue(L) / (1000 × (1+0.12×(L-1))) × 권역계수`)
   마다 유물 1점 롤(기존 `800 × 1.25^(L-1)` 고정 임계는 틀렸다 — 깊이가 수입을
   벌게 하는 폭주 경로를 열어 척추 2번을 위반했을 값이다. §7.5 참조).
4. **삽질(클릭)** — 1클릭 = `D × 0.06 × 콤보` 진척(기존 `D × 0.4`는 실측 대비
   과대추정이었다). 연타 3초 유지 시 최대 1.4배 콤보(기존 1.5배). 초당 클릭
   진척은 `D × 0.35`를 못 넘는다(클릭 노동 방지 상한, 초판에 없던 안전장치).
   방치만으로도 완주 가능하고, 클릭은 가속일 뿐이다.
5. **미감정** — 드랍 유물은 정체 불명. 감정(시간 + 추정가 2%)해야 도감에 오른다.
   미감정 즉시 매각은 기대값의 **70%** — 싸게 털고 가는 도박.
6. **현존 개체 수 = 공급량** — 유물마다 현실의 현존 수량을 그대로 게임 재고로 쓴다.
   `T0 흔함 ∞ / T1 희귀 2000 / T2 진귀 60 / T3 국보 6 / T4 유일 1`
7. **세계 원장(Ledger)** — 유물 잔여 수량을 세계가 관리한다. 0이면 풀에서 빠진다.
   플레이어와 라이벌이 **같은 원장**에서 뽑는다.
8. **라이벌 6인**(기존 "6~8인"은 초판 추정 범위였다 — 실제 `RIVAL_SEED`는
   6명 고정) — 각자 발굴력·선호 발굴지·선호 티어를 갖고 동일 규칙으로 발굴한다.
   오프라인 중에도 진행. 활동 로그가 공개된다.
9. **제보(Tip)** — 첫 제보 90초, 이후 평균 **3분**(`TIP_MEAN_INTERVAL=180초`,
   기존 "평균 25분"은 틀렸다) 간격. 유효 **60~150초**(기존 "3~8분"은 틀렸다).
   대상 유물이 드랍 롤마다 걸릴 확률은 **28%**(`TIP_PLAYER_HIT`, 기존 "가중
   ×80"은 배율이 아니라 확률이라는 점 자체가 틀렸다). 라이벌 일부도 같은
   제보를 받는다(롤당 10%, `TIP_RIVAL_HIT`).
10. **순위** — 총자산 실시간 순위. 유물을 팔면 자금은 늘고 **순위는 떨어진다**.

### 1.3 v0.3 이후 (거래)

11. **오퍼/역오퍼** — 라이벌이 가진 유물을 현금으로 사온다. 라이벌도 내 유물에 오퍼를 건다.
    **영구 상실의 유일한 회복 경로**이자, 자산 경쟁의 마지막 축.

## 2. Dynamics — 창발

### 2.1 수집 vs 자금 딜레마 (핵심 긴장)

방치형의 고질병은 "모든 숫자가 한 방향으로만 커진다"는 것이다. 여기서는 **점수(소장 자산)와
성장 동력(자금)이 같은 유물을 두고 경합한다**. 국보를 팔면 장비를 두 단계 올릴 수 있지만
순위는 내려간다. 매 드랍마다 같은 질문이 반복된다 — *지금 팔 것인가, 끝까지 쥘 것인가.*

### 2.2 선점 경쟁 — 방치를 깨는 유일한 장치

제보가 뜨면 방치 상태가 깨진다. 발굴력을 어느 발굴지에 몰아넣을지 60~150초 안에 결정해야 하고,
같은 제보를 받은 라이벌보다 먼저 도달해야 한다. **먼저 간 쪽이 영원히 가진다.**
웹툰 `도굴왕`의 동력이 "나만 어디에 뭐가 있는지 안다"는 정보 우위인데, 제보는 그 우위를
**시간제한 레이스**로 번역한 것이다.

### 2.3 복구 불가 상실

라이벌이 유일 유물을 가져가면 도감에 **영구 회색 칸**이 남는다 — 소유자 이름과 함께.
Steam `바나나`가 드랍 풀에서 빠진 바나나의 공급을 고정해 가격이 수백~수천 달러로 치솟은
구조와 같다. 다만 여기서는 화폐가 아니라 **도감의 구멍**이 그 희소성을 체감시킨다.

### 2.4 블라인드 매각의 후회 서사

미감정 유물을 무더기로 털어 장비를 샀는데, 며칠 뒤 라이벌의 소장 목록에서 그때 판 유물이
**유일 티어**로 감정되어 올라온다. 플레이어가 자기 손으로 만든 이야기다.

### 2.5 오프라인 역전

자고 일어나면 순위가 바뀌어 있다. 복귀 요약이 밤사이의 사건을 보고한다.
단 아래 §5.2의 상실 규칙 때문에 **유일 유물은 자는 동안 잃지 않는다.**

## 3. Aesthetics — 재미 정의

### 3.1 재미를 세 문장으로

1. **"세상에 하나뿐인 것을 내가 가졌다."** — 소유의 배타성. 다른 누구도 가질 수 없다.
2. **"조금만 늦었으면 놓쳤다."** — 선점의 스릴. 방치형에 긴장을 주입하는 단 하나의 장치.
3. **"이게 진짜 있는 물건이라고?"** — 실존의 무게. 수집이 지식적 발견을 동반한다.

### 3.2 축 매핑 (설계 목표치)

| 축 | 목표 | 근거 |
| --- | --- | --- |
| **FOMO/Urgency** | ★★★★★ | 유일 유물 선점 레이스, 영구 상실. **게임 정체성** |
| **Completionism** | ★★★★★ | 도감. 영원히 못 채우는 칸이 있는 도감 |
| **Progression satisfaction** | ★★★★★ | 자산 곡선, 깊이 갱신, 발굴지 해금 |
| Social status/Flex | ★★★★ | 순위표. "로제타 석 소장자: 나" |
| Reverence/Awe | ★★★★ | 실존 유물의 무게. 감정 연출 + 실제 내력 |
| Discovery | ★★★★ | 몰랐던 유물을 **실제로** 알게 된다 |
| Submission | ★★★★ | "한 층만 더" |
| **Optimization (Functional)** | **★★★★**(v0.2, ★★★에서 상향 — 근거·대가는 §10.1) | 발굴력 배분, 팔 것과 쥘 것의 계산 + 스텝 배치·시설 투자·시장 채널 선택 |
| Solace | ★★★ | 지층을 파내려가는 리듬, 도트의 정적인 질감 |
| Melancholy | ★★ | 회색 칸. 의도적으로 소량만 |
| Narrative | ★★ | 유물 내력이 서사를 대체 |
| **Mastery** | ★★ | **의도적으로 낮다.** 방치형 장르 본질 |
| Fellowship / Teamwork / Theory of Mind | ☆ | Solo |

**축군 판정**: Mastery 축군(Mastery+Catharsis+Optimization) **미형성 — 의도적**.
이 게임은 손기술을 요구하지 않는다. Theory of Mind 축군 해당 없음.

**Design pattern**: 집중형. 3축 ★★★★★ + 나머지 ★★~★★★★.

### 3.3 안티-펀 (명시적으로 피하는 것)

- **무의미한 숫자 팽창** — 자산 곡선이 커지되, 팔면 줄어드는 구조로 의미를 유지한다.
- **클릭 노동 강요** — 클릭은 언제나 선택. 미클릭 완주 경로를 보장한다.
- **출구 없는 좌절** — 영구 상실에 회복 경로(거래, v0.3)를 남긴다.
  거래 전 버전에서는 상실 빈도를 낮게 튜닝한다(§5.2).
- **라이벌이 반칙한다는 느낌** — 라이벌 발굴력과 추격 계수를 UI에 공개한다.

## 4. 역전 현상 (설계가 의도한 것)

| 패턴 | 내용 |
| --- | --- |
| **경제 역전** | 방치형은 자원 축적이 곧 점수인데, 여기선 **자원을 쓰면 점수가 준다**. 성장과 점수가 반대 방향 |
| **장르 정의 역전** | 방치형은 "안 봐도 되는 게임"인데, 제보는 **봐야만 하는 3분**을 만든다 |
| **철학 역전** | 수집 게임의 도감은 채우라고 있는데, 이 도감은 **영원히 못 채우는 칸**을 설계로 남긴다 |
| **디커플링** | 총 클릭 수와 최종 순위의 상관이 약하다. **타이밍이 클릭량을 지배**한다 |

## 5. Design Contract

| Contract | 강도 | 이행 방법 |
| --- | --- | --- |
| **Save System Integrity** | ★★★★★ 필수 | 방치형의 생명선. 세이브 버전 마이그레이션, 자동 백업 3슬롯, JSON export/import. 세이브 소실 = 게임 종료 |
| **Fair Progression** | ★★★★ 필수 | 유일 유물 확률·라이벌 발굴력·추격 계수를 **전부 공개**한다. 한국 유저 민감도 1순위 축 |
| **Performance Reliability** | ★★★ | 오프라인 진척 계산 오차가 곧 신뢰 붕괴. 틱 적분은 단조·결정론 |
| Content Delivery | ★★ | 프로토타입 단계. 유물 데이터셋 확장이 곧 콘텐츠 공급 |
| Competitive Integrity | N/A | NPC 상대. 단 **라이벌 활동 로그를 관전 가능**하게 해 "조작" 의심을 차단 |
| Community Standard | N/A | 멀티 요소 없음 |

### 5.1 Fair Progression 공개 항목 (게임 내 "규칙" 화면)

- 층별 티어 드랍 가중표
- 제보 발생 주기(평균 3분)와 명중 확률(`TIP_PLAYER_HIT=28%`, 정정 — 기존 "가중
  배율 ×80"은 실제 구현(확률 가중, 배율 아님)과 달랐다)
- 라이벌 각자의 발굴력, 추격 계수 공식
- 오프라인 효율(60%)과 누적 상한(12시간)

### 5.2 영구 상실의 설계 원칙 — **"플레이어가 그 자리에 있었을 때만"**

오프라인 중 라이벌은 T0~T2만 가져간다. **유일(T4)·국보(T3)는 오프라인에 소실되지 않는다.**
영구 상실은 플레이어가 접속해 제보 레이스에 참여했고, 거기서 졌을 때만 일어난다.
거래(v0.3)로 회복 경로가 열리기 전까지 이 원칙은 협상 대상이 아니다.

## 6. 시간 스케일 루프

```
초(1~5s)     클릭 삽질 → 진척바 → 지층 한 픽셀 더 내려감
분(1~5m)     유물 드랍 → 감정 → [소장 | 매각] 결정 → 장비 구매
세션(10~20m) 층 돌파 → 발굴지 해금 → 제보 대응 → 순위 확인
일(8~24h)    오프라인 진척 → 복귀 요약 → 라이벌 활동 로그
세계(20~40h) 도감 완주 → 자산 1위 → 시즌 순위 확정(프레스티지, v0.2 — `notes/decisions.md` G11.
             박물관 설립은 v0.2에서도 유지되지만 리셋형 프레스티지는 아니다 — 시즌 내 성장·명성 축이다)
```

**루프 교차점 — 설계 밀도를 가장 높게 둘 두 순간**

1. **감정 결과 공개** — 카드가 뒤집히는 순간. 티어별 연출 차등, T4는 전체 화면 연출.
2. **복귀 요약** — 아침에 돌아와 밤사이 로그를 읽는 순간. 손실을 숨기지 않는다.

**루프 실패 경보**: 분 스케일이 비면(드랍 간격 5분 초과) 방치형이 아니라 대기 화면이 된다.
초기 구간 드랍 간격은 40초를 넘기지 않는다.

> **(v0.6) 이 경보는 이제 규칙이다.** 지키는 장치가 없어서, 깊이를 압축하자마자
> 즉시 울렸다 — 발굴력이 따라오기 전에 10층에 서면 드랍 임계(층 기대 평가액
> 비례)가 커져 **100초에 한 번**이 된다. `DROP_INTERVAL_CEILING_SECONDS = 20`을
> 하한(16초)과 대칭으로 두어 코드가 이 경보를 강제한다. 천장이 걸린 구간에서는
> 드랍 **빈도**가 고정되고 **한 건의 값**이 깊이를 따라 오른다
> (`notes/decisions.md` G86.2, `eval.md` §27).
>
> **세션 스케일 줄도 v0.6에서 실제로 맞췄다.** 위 표는 "층 돌파"를 세션
> (10~20분) 루프로 적어 뒀는데, v0.5.1의 12층 도달 실측은 **4시간 39분**이었다
> — 게임이 자기 설계 문서와 14배 어긋나 있었다. 지금은 9분 2초다(G83).

## 7. 설계 리스크

### 7.1 문화재 약탈 서사 리스크 (가장 큰 것)

실존 유물을 "개인이 캐서 금고에 넣는" 구도는 반환 논쟁(엘긴 마블, 외규장각 의궤 등)과
정면으로 부딪친다. 웹툰 `도굴왕`의 흑화 서사를 그대로 가져오면 리스크가 커진다.

**완화 설계**
- 최종 목표를 개인 금고가 아니라 **박물관 설립·공개 전시**로 둔다. (정정 — v0.2는
  프레스티지를 박물관이 아니라 시즌이 전담한다, `notes/decisions.md` G11 — 이
  완화 설계는 여전히 유효하다: 시즌 종료 시 소장 유물 전량이 계정 영구 기록인
  "명예의 전당"에 **헌정(Dedication)**된다(`notes/decisions.md` G14/§13.4) —
  사적 소장이 결국 공개·영구 기록으로 귀결되는 구조가 프레스티지 대신 시즌 롤오버로
  옮겨 갔을 뿐, "개인 금고에서 끝나지 않는다"는 완화 의도는 오히려 더 강화됐다.)
- 유물 카드에 **실제 현 소장처를 사실대로 표기**한다. 반환 논쟁 유물은 논쟁 사실을 병기.
- 용어를 '도굴'이 아니라 '발굴·수집'으로 통일한다.

### 7.2 평가액의 사실성

실존 유물의 시장가는 대부분 비공개이거나 거래 자체가 불가능하다. 게임 내 평가액은
**가상 단위(₩)이며 실제 감정가가 아님**을 도감 하단에 상시 표기한다.

### 7.3 라이벌 고무줄의 양면

추격 계수는 독주를 막지만 "내가 뭘 해도 따라온다"는 무력감을 만들 수 있다.
계수 상한을 두고(최대 ×2.0), 수치를 UI에 노출해 납득 가능하게 만든다.

### 7.4 도트 에셋 생산량

유물 60~120점의 도트 스프라이트를 손으로 찍는 건 비현실적이다.
외부 이미지 파이프라인은 이 환경에서 **네트워크가 차단되어 불가**(박물관 오픈액세스 API 403 확인).
→ **절차적 도트 생성**으로 간다. 형태·팔레트·시드를 데이터로 주면 생성기가 32×32를 굽는다.
트레이드오프: 실물 재현도는 낮다. 실존성은 **이름·연대·소장처·내력 텍스트**가 담보한다.

## 8. 디자인 인사이트

1. **현실의 희소성을 게임의 희소성으로 그대로 쓴다.** 로제타 석은 1점, 데나리우스는 수만 점 —
   이 사실 자체가 티어 테이블이다. 밸런스를 위해 지어낸 등급이 아니라서 설득력이 공짜로 따라온다.
2. **깊이 = 연대.** 지층을 파내려간다는 도트 화면 하나가 진척 시각화와 시대 구분을 동시에 해결한다.
   방치형의 우상향을 숫자가 아니라 그림으로 보여주는 지점이다.
3. **방치형에 긴장을 넣는 유일한 방법은 "지금 아니면 안 되는 것"을 만드는 것**인데,
   유일 유물 레이스가 그 역할을 한다. 스태미나나 일일 퀘스트 같은 외부 압박이 필요 없다.
4. **점수와 자원을 같은 물건으로 만들면 방치형의 단조로움이 깨진다.** 팔면 빨라지고 순위는 내려간다.
5. **`바나나`에서 가져올 것은 클릭이 아니라 "드랍 풀에서 빠지면 공급이 고정된다"는 구조**다.
   클릭은 껍데기였고, 가격을 만든 건 discontinued 처리였다.
6. **`도굴왕`에서 가져올 것은 먼치킨 서사가 아니라 정보 우위**다. 제보 = 회귀자의 사전 지식.
7. **영구 상실은 플레이어가 그 자리에 있었을 때만 일어나야 한다.** 자는 동안 빼앗기는 설계는
   FOMO가 아니라 원한을 만든다.
8. **Mastery가 낮은 것은 이 장르에서 결함이 아니다.** 손기술 요구를 끼워 넣으려는 유혹을 거부한다.

### 10.1 Optimization 상향의 근거와 대가

**근거**: v0.1의 Optimization은 "팔 것과 쥘 것의 계산" 하나였다. v0.2는 여기에
발굴단 인원·장비·단장 스탯 배분, 스텝 3직군 고용·승급 관리, 시설(감정소·보관소·
박물관·경매장) 투자 순서, 시장 3채널(직접매각·경매장·암시장, 거래소는
`notes/decisions.md` G15/A4로 v0.2에서 제거됐다) 중 어디에
팔지의 선택이 더해진다 — `notes/decisions.md` G3가 정리한 "조직 관리 + 처분 경로"
7종 전부가 이 축에 무게를 싣는다. §0에서 이 게임을 "자동화 시뮬레이션(#8)"
프로필에서 가져온 이유가 Optimization·Completionism·Save System Integrity였는데,
v0.1은 그중 Optimization만 얕게 썼다. v0.2는 그 프로필을 더 온전히 채운다.

**대가**: Optimization을 올리면 Mastery축군(Mastery+Catharsis+Optimization)이
형성될 위험이 있다 — 이 게임이 명시적으로 피해 온 "손기술 요구"와는 다르지만,
"매 순간 최적해를 계산해야 한다"는 부담은 방치형의 "안 봐도 되는 게임" 정체성을
같은 방식으로 깎아 먹는다. 대가를 두 가지로 못 박아 지불한다.

1. **Mastery는 계속 ★★로 고정한다.** 스탯 최적화가 "결정을 더 잘 내리는 것"이지
   "더 자주 확인하는 것"이 되면 실패다. `notes/staff.md` §5의 급여가 **결정론적
   함수**(스탯이 높으면 급여도 결정론적으로 오른다, 확률 재굴림 없음)인 이유,
   `notes/staff.md` §6의 승급이 **무작위가 아니라 최저 스탯 보완**인 이유가 이
   대가를 지불하는 구체적 장치다 — 최적화는 "한 번 잘 배치하면 유지되는" 결정이지
   "계속 다시 굴려야 하는" 도박이 아니다.
2. **관여 예산(G3)이 Optimization의 하드 캡이다.** 하루
   `DAILY_ENGAGEMENT_MIN_COUNT~MAX_COUNT`(2~3회) × `DAILY_ENGAGEMENT_SESSION_SECONDS`
   (180초) 안에서 이 모든 최적화 결정을 내릴 수 있어야 한다 — 그 예산을 넘기는
   최적화 여지(예: 시세를 실시간으로 추적해 매초 채널을 바꾸는 플레이)는 설계
   목표가 아니라 초과 이득도 없다. **(정정 — B5)** 예전 근거였던
   `ARBITRAGE_MAX_SPREAD_RATIO = 1.40`은 G26/B3로 `2.33`(≈233%)으로 재조정돼
   더 이상 20~40% 밴드와 맞지 않는다 — 이 값은 "전역 12거점 중 최댓값/최솟값"
   이라 플레이어가 실제로 손대는 것과는 다른 수치였다. 실제로 플레이어가
   손댈 수 있는 상한은 `notes/world-map.md` §8.4의 **보유 base(최대 3곳) 중
   최고가를 자동 선택하는 이득**(`E[max of 3] = 1.20`, G26/B3·G48/B3)이다 —
   보유 base 3곳 안에서는 아무리 최적화해도 지역 차익이 대략 20%를 넘지
   못한다. 3,000km 이상 원거리의 정보 우위 보너스(`REMOTE_ARBITRAGE_*`,
   G19/B4)는 이동시간·미스헵을 이미 지불한 대가라 이 밴드 밖의 별도 "위험수당"
   으로 명시적으로 예외 처리된다(world-map.md §8.5).

### 10.2 신규 시스템의 재미 3문장 기여 판정

기준은 §3.1의 재미 정의 3문장이다: **①세상에 하나뿐인 것을 내가 가졌다
②조금만 늦었으면 놓쳤다 ③이게 진짜 있는 물건이라고?**. `notes/decisions.md` G3의
장르 문장("짧은 능동 개입으로 조직을 굴리고 처분 경로를 관리해 세 지표를 겨루는
저관여 경영형 수집 방치 게임")은 이 3문장과 다른 층위다 — 장르 문장은 시스템이
**왜 이 게임에 있어야 하는가**를, 3문장은 시스템이 **재미를 실제로 만드는가**를
묻는다. 아래 표는 3문장 기여를 우선 찾고, 없으면 v0.1부터 있던 상위 Dynamics
("수집 vs 자금 딜레마", §2.1)에 대한 기여로 대체 판정한다 — 둘 다 없는 시스템만
자른다.

| 시스템 | ① 배타적 소유 | ② 선점 스릴 | ③ 실존의 무게 | 판정 |
| --- | --- | --- | --- | --- |
| 거점·세계지도(12곳) | 거점당 T4 정확히 1종(`SPECIES_PER_SITE_BY_TIER[4]=1`) — 도감을 완주하려면 12곳 전부 배타적으로 소유해야 한다 | 미탐사 보너스·먼 거점 유일 최초 발굴이 더 넓은 지도 위의 레이스가 된다 | 12개 실제 역사 도시로 세계가 확장된다 | **유지** — ①③ 직접 기여 |
| 발굴단·단장(`notes/staff.md` §1) | 통솔력(`LEADERSHIP`)이 발굴력에 가산돼 "가졌다"는 확인(드랍→감정)까지의 시간을 줄인다(개정 — `notes/decisions.md` G50/C#5로 감식안 `APPRAISAL_EYE` 스탯 자체가 삭제됐다) | 항해술(`NAVIGATION`)이 원정 도착 시간을 줄여, 먼 거점의 유일 유물 최초 발굴 경쟁에서 실질적 우위를 만든다 — 선점 스릴의 **공간적 확장** | — | **유지** — ①②에 직접 기여 |
| 감정소·보관소(상태 축, G6) | 상태(`condition`)가 좋을수록 더 자랑스러운 소유가 된다 | — | 파손↔완품↔관급의 물리적 상태 차이가 "낡아가는 진품"이라는 실존감을 더한다 | **유지** — ①③에 직접 기여 |
| 박물관·관장 | 전시로 소유를 **증명**한다(사적 소유를 공개 전시로 확장 — §7.1 완화 설계와 직결) | — | — | **유지** — ①에 기여 + Design Contract상 문화재 윤리 완화의 유일한 실행 장치(§7.1) |
| 경매장 | — | — | — | 3문장 직접 기여 없음. **Dynamics 2.1(수집 vs 자금 딜레마)의 처분 경로**로 정당화 — 자르면 v0.1의 핵심 창발(팔 것인가 쥘 것인가)이 깊이만큼 커진 소장 규모를 처리할 경로를 잃는다 |
| 암시장 | — | — | 장물 매입은 "훔친 물건임을 알고 산다"는 낙인 서사를 만든다 — 약하게 ③에 기여 | **유지(약함)** — 매입 전용 채널로 처분 경로(경매장)와 겹치지 않고, 도난(G9)과 연결된 서사가 ③에 소액 기여 |

**이 표를 작성한 시점(G3 라운드)에는 자른 시스템이 없었다.** 거래소(유저간,
NPC 유동성)는 그때 3문장 직접 기여가 없었지만 "Dynamics 2.1 대체 판정"으로
구제됐다. **리뷰 1회차가 그 구제 판정 자체를 지적했다** — 3문장·Dynamics
기여와는 **다른 축**(산수)에서 거래소가 죽어 있었다: 실현 배율이 직접매각보다
항상 낮아(등록 최대가 1.128배 < 직접매각 1.26배) 밴드를 아무리 유리하게
써도 손해였다. `notes/decisions.md` G15/A4가 이 근거로 거래소를 잘라
v0.4로 이연했다 — 3문장/Dynamics 판정이 "왜 있어야 하는가"를 묻는 질문이고
산수 판정은 "실제로 작동하는가"를 묻는 별개의 질문이라, 전자를 통과했다고
후자를 안 물어도 되는 건 아니었다. 경매장·암시장은 두 축 모두를 통과해
유지한다.

### 10.4 리스크 갱신

v0.1 §7의 4개 리스크는 유지한다(문화재 서사·평가액 사실성·라이벌 고무줄·도트 생산량).
v0.2가 추가하는 리스크:

**7.5 관리 과부하 — Optimization 상향이 방치형 정체성을 깎아 먹을 위험**

§10.1에서 이미 대가로 인정한 리스크다. 완화: 관여 예산 하드캡(G3) + Mastery ★★ 고정
+ `notes/ux-v02.md`의 조작 단계 수 표(모든 주요 액션 3단계 이내)로 삼중 방어한다.

**7.6 (해소됨) NPC 시장조성자 유동성 고갈 — 거래소 제거로 이 리스크의 전제가 없어졌다**

이 리스크는 "라이벌이 거래소의 유동성 공급자"라는 전제(G1) 위에 있었다.
`notes/decisions.md` G15/A4가 거래소를 v0.2에서 제거했으므로(경제 리뷰어가
실현 배율을 재검산해 산수로 지배당한 죽은 채널로 판정했다), 라이벌이 거래소
매수자로서 자금을 소진할 경로 자체가 없다. v0.4에서 거래소를 다시 설계할 때
이 리스크를 재평가한다.

**7.7 급여 비율 근사 — 세 직군 급여의 합이 K3 목표(8%)와 정확히 일치하지 않는다**

`notes/staff.md` §5가 이미 인지한 리스크다: 단장 3% + 관장 최대 4.5% + 경매관장
소액을 더한 값은 `STAFF_TOTAL_SALARY_SHARE_TARGET = 0.08`에 "근접"할 뿐 정확히
일치하도록 강제되지 않는다. 완화: 시뮬 측정치가 크게 벗어나면 세 비율(
`FOREMAN_SALARY_INCOME_SHARE`·`CURATOR_SALARY_INCOME_SHARE`·
`AUCTIONEER_SALARY_FEE_SHARE`)을 조정한다 — 각 비율이 도메인 안에서 독립적으로
정의돼야 스탯의 의미가 유지되므로, 정확한 8% 일치보다 이 독립성을 우선한다.

**7.8 데이터 파이프라인 지연 — 480종 검증이 이 게임의 새 병목이 된다**

`notes/artifacts-dataset.md` G7이 이미 인지한 리스크다. 완화: 목표를 1,000~2,000종이
아니라 480종으로 낮췄고, 기존 60점을 시드로 재사용해 처음부터 다시 만들지 않는다.
검증 없이 커밋된 항목은 `sourceStatus: "pending"` 배지로 정직하게 노출한다 — 병목을
숨기지 않는 것 자체가 척추 5번의 연장이다.
