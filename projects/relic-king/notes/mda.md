# 유물왕 — MDA 설계

> 시점: 2026-09-17 기준 / 모드: **B(순설계)** / 길이: 심화
> 프레임워크: MDA(Mechanics–Dynamics–Aesthetics) + Design Contract 4층

## 0. 설계 전제

| 항목 | 판정 |
| --- | --- |
| 게임 유형 | 패키지-완결(프로토타입). 수익화·가챠 없음 |
| 장르 | 방치형(Idle/Incremental) × 수집 × 비동기 자산 경쟁 |
| 플레이 관계 | **Solo** — 라이벌은 NPC 시뮬레이션 |
| 플레이 목적 | 소비형 + **비동기 경쟁형**(순위표) 혼합 |
| 세션 | **무한 세션** + 짧은 능동 개입(1~5분) |
| 플랫폼 | 웹(데스크톱 + 모바일 터치), 정적 산출물, 오프라인 동작 |
| Design pattern | **집중형** — FOMO·Completionism·Progression 3축이 ★★★★★ |

### 장르 가이드 공백 처리

분석 프레임워크의 장르 가이드에 **방치형/증분(Idle·Incremental) 항목이 없다**. 빈 화면에서
축을 재검토하지 않고 인접 3장르의 예상 프로필을 합성해 출발점으로 삼았다.

- **하드캐주얼 모바일 Puzzle**(#10)에서: Submission ★★★★★, Progression ★★★★★,
  Solace ★★★★, **Mastery ★★ (낮은 게 장르 본질, 결함 아님)**
- **자동화 시뮬레이션**(#8)에서: Optimization(Functional), Completionism, Save System Integrity 필수
- **가챠 오픈월드 RPG**(#9)에서: FOMO ★★★★★, Completionism, Fair Progression 민감도

합성 결과에 이 게임 고유의 **유일성(N=1) 공급 원장**을 얹은 것이 아래 프로필이다.

## 1. Mechanics — 규칙과 자원

### 1.1 자원

| 자원 | 역할 | 획득 | 소비 |
| --- | --- | --- | --- |
| 발굴력 `D` (진척/초) | 모든 진행의 속도 | 인부·장비·유적 해석 | — |
| 진척 `P` | 깊이와 드랍의 연료 | 발굴력 × 시간, 클릭 | 층 굴착, 드랍 임계 |
| 깊이 `L` (층) | 발굴지별 도달 지층 = **시대** | 굴착 | 상위 티어 접근 |
| 자금 `₩` | 설비 투자 | 유물 매각, 전시 수입 | 인부·장비·발굴지·감정비 |
| 소장 자산 | **점수** = 소장 유물 평가액 합 | 유물 보유 | 매각 시 감소 |

### 1.2 핵심 규칙 10개

1. **굴착** — 층 `L` 도달 비용 `C(L) = 120 × 2.6^(L-1)` 진척. 발굴지당 12층.
2. **지층 = 연대** — 층이 깊을수록 오래된 시대. 층마다 고유 유물 풀.
3. **드랍** — 층에서 진척 `800 × 1.25^(L-1)` 누적마다 유물 1점 롤.
4. **삽질(클릭)** — 1클릭 = `D × 0.4`초분 진척. 연타 3초 유지 시 1.5배 콤보.
   방치만으로도 완주 가능하고, 클릭은 가속일 뿐이다.
5. **미감정** — 드랍 유물은 정체 불명. 감정(시간 + 추정가 2%)해야 도감에 오른다.
   미감정 즉시 매각은 기대값의 **70%** — 싸게 털고 가는 도박.
6. **현존 개체 수 = 공급량** — 유물마다 현실의 현존 수량을 그대로 게임 재고로 쓴다.
   `T0 흔함 ∞ / T1 희귀 2000 / T2 진귀 60 / T3 국보 6 / T4 유일 1`
7. **세계 원장(Ledger)** — 유물 잔여 수량을 세계가 관리한다. 0이면 풀에서 빠진다.
   플레이어와 라이벌이 **같은 원장**에서 뽑는다.
8. **라이벌 6~8인** — 각자 발굴력·선호 발굴지·선호 티어를 갖고 동일 규칙으로 발굴한다.
   오프라인 중에도 진행. 활동 로그가 공개된다.
9. **제보(Tip)** — 평균 25분마다 "○○ 발굴지 7층 부근 유일급 반응". 유효 3~8분.
   해당 층에 발굴력을 집중하면 대상 유물 드랍 가중 ×80. 라이벌 일부도 같은 제보를 받는다.
10. **순위** — 총자산 실시간 순위. 유물을 팔면 자금은 늘고 **순위는 떨어진다**.

### 1.3 v0.3 이후 (거래)

11. **오퍼/역오퍼** — 라이벌이 가진 유물을 현금으로 사온다. 라이벌도 내 유물에 오퍼를 건다.
    **영구 상실의 유일한 회복 경로**이자, 자산 경쟁의 마지막 축.

## 2. Dynamics — 창발

### 2.1 수집 vs 자금 딜레마 (핵심 긴장)

방치형의 고질병은 "모든 숫자가 한 방향으로만 커진다"는 것이다. 여기서는 **점수(소장 자산)와
성장 동력(자금)이 같은 유물을 두고 경합한다**. 국보를 팔면 장비를 두 단계 올릴 수 있지만
순위는 내려간다. 매 드랍마다 같은 질문이 반복된다 — *지금 팔 것인가, 끝까지 쥘 것인가.*

### 2.2 선점 경쟁 — 방치를 깨는 유일한 장치

제보가 뜨면 방치 상태가 깨진다. 발굴력을 어느 발굴지에 몰아넣을지 3~8분 안에 결정해야 하고,
같은 제보를 받은 라이벌보다 먼저 도달해야 한다. **먼저 간 쪽이 영원히 가진다.**
웹툰 `도굴왕`의 동력이 "나만 어디에 뭐가 있는지 안다"는 정보 우위인데, 제보는 그 우위를
**시간제한 레이스**로 번역한 것이다.

### 2.3 복구 불가 상실

라이벌이 유일 유물을 가져가면 도감에 **영구 회색 칸**이 남는다 — 소유자 이름과 함께.
Steam `바나나`가 드랍 풀에서 빠진 바나나의 공급을 고정해 가격이 수백~수천 달러로 치솟은
구조와 같다. 다만 여기서는 화폐가 아니라 **도감의 구멍**이 그 희소성을 체감시킨다.

### 2.4 블라인드 매각의 후회 서사

미감정 유물을 무더기로 털어 장비를 샀는데, 며칠 뒤 라이벌의 소장 목록에서 그때 판 유물이
**유일 티어**로 감정되어 올라온다. 플레이어가 자기 손으로 만든 이야기다.

### 2.5 오프라인 역전

자고 일어나면 순위가 바뀌어 있다. 복귀 요약이 밤사이의 사건을 보고한다.
단 아래 §5.2의 상실 규칙 때문에 **유일 유물은 자는 동안 잃지 않는다.**

## 3. Aesthetics — 재미 정의

### 3.1 재미를 세 문장으로

1. **"세상에 하나뿐인 것을 내가 가졌다."** — 소유의 배타성. 다른 누구도 가질 수 없다.
2. **"조금만 늦었으면 놓쳤다."** — 선점의 스릴. 방치형에 긴장을 주입하는 단 하나의 장치.
3. **"이게 진짜 있는 물건이라고?"** — 실존의 무게. 수집이 지식적 발견을 동반한다.

### 3.2 축 매핑 (설계 목표치)

| 축 | 목표 | 근거 |
| --- | --- | --- |
| **FOMO/Urgency** | ★★★★★ | 유일 유물 선점 레이스, 영구 상실. **게임 정체성** |
| **Completionism** | ★★★★★ | 도감. 영원히 못 채우는 칸이 있는 도감 |
| **Progression satisfaction** | ★★★★★ | 자산 곡선, 깊이 갱신, 발굴지 해금 |
| Social status/Flex | ★★★★ | 순위표. "로제타 석 소장자: 나" |
| Reverence/Awe | ★★★★ | 실존 유물의 무게. 감정 연출 + 실제 내력 |
| Discovery | ★★★★ | 몰랐던 유물을 **실제로** 알게 된다 |
| Submission | ★★★★ | "한 층만 더" |
| Optimization (Functional) | ★★★ | 발굴력 배분, 팔 것과 쥘 것의 계산 |
| Solace | ★★★ | 지층을 파내려가는 리듬, 도트의 정적인 질감 |
| Melancholy | ★★ | 회색 칸. 의도적으로 소량만 |
| Narrative | ★★ | 유물 내력이 서사를 대체 |
| **Mastery** | ★★ | **의도적으로 낮다.** 방치형 장르 본질 |
| Fellowship / Teamwork / Theory of Mind | ☆ | Solo |

**축군 판정**: Mastery 축군(Mastery+Catharsis+Optimization) **미형성 — 의도적**.
이 게임은 손기술을 요구하지 않는다. Theory of Mind 축군 해당 없음.

**Design pattern**: 집중형. 3축 ★★★★★ + 나머지 ★★~★★★★.

### 3.3 안티-펀 (명시적으로 피하는 것)

- **무의미한 숫자 팽창** — 자산 곡선이 커지되, 팔면 줄어드는 구조로 의미를 유지한다.
- **클릭 노동 강요** — 클릭은 언제나 선택. 미클릭 완주 경로를 보장한다.
- **출구 없는 좌절** — 영구 상실에 회복 경로(거래, v0.3)를 남긴다.
  거래 전 버전에서는 상실 빈도를 낮게 튜닝한다(§5.2).
- **라이벌이 반칙한다는 느낌** — 라이벌 발굴력과 추격 계수를 UI에 공개한다.

## 4. 역전 현상 (설계가 의도한 것)

| 패턴 | 내용 |
| --- | --- |
| **경제 역전** | 방치형은 자원 축적이 곧 점수인데, 여기선 **자원을 쓰면 점수가 준다**. 성장과 점수가 반대 방향 |
| **장르 정의 역전** | 방치형은 "안 봐도 되는 게임"인데, 제보는 **봐야만 하는 3분**을 만든다 |
| **철학 역전** | 수집 게임의 도감은 채우라고 있는데, 이 도감은 **영원히 못 채우는 칸**을 설계로 남긴다 |
| **디커플링** | 총 클릭 수와 최종 순위의 상관이 약하다. **타이밍이 클릭량을 지배**한다 |

## 5. Design Contract

| Contract | 강도 | 이행 방법 |
| --- | --- | --- |
| **Save System Integrity** | ★★★★★ 필수 | 방치형의 생명선. 세이브 버전 마이그레이션, 자동 백업 3슬롯, JSON export/import. 세이브 소실 = 게임 종료 |
| **Fair Progression** | ★★★★ 필수 | 유일 유물 확률·라이벌 발굴력·추격 계수를 **전부 공개**한다. 한국 유저 민감도 1순위 축 |
| **Performance Reliability** | ★★★ | 오프라인 진척 계산 오차가 곧 신뢰 붕괴. 틱 적분은 단조·결정론 |
| Content Delivery | ★★ | 프로토타입 단계. 유물 데이터셋 확장이 곧 콘텐츠 공급 |
| Competitive Integrity | N/A | NPC 상대. 단 **라이벌 활동 로그를 관전 가능**하게 해 "조작" 의심을 차단 |
| Community Standard | N/A | 멀티 요소 없음 |

### 5.1 Fair Progression 공개 항목 (게임 내 "규칙" 화면)

- 층별 티어 드랍 가중표
- 제보 발생 주기와 가중 배율(×80)
- 라이벌 각자의 발굴력, 추격 계수 공식
- 오프라인 효율(60%)과 누적 상한(12시간)

### 5.2 영구 상실의 설계 원칙 — **"플레이어가 그 자리에 있었을 때만"**

오프라인 중 라이벌은 T0~T2만 가져간다. **유일(T4)·국보(T3)는 오프라인에 소실되지 않는다.**
영구 상실은 플레이어가 접속해 제보 레이스에 참여했고, 거기서 졌을 때만 일어난다.
거래(v0.3)로 회복 경로가 열리기 전까지 이 원칙은 협상 대상이 아니다.

## 6. 시간 스케일 루프

```
초(1~5s)     클릭 삽질 → 진척바 → 지층 한 픽셀 더 내려감
분(1~5m)     유물 드랍 → 감정 → [소장 | 매각] 결정 → 장비 구매
세션(10~20m) 층 돌파 → 발굴지 해금 → 제보 대응 → 순위 확인
일(8~24h)    오프라인 진척 → 복귀 요약 → 라이벌 활동 로그
세계(20~40h) 도감 완주 → 자산 1위 → 박물관 설립(프레스티지, v0.2)
```

**루프 교차점 — 설계 밀도를 가장 높게 둘 두 순간**

1. **감정 결과 공개** — 카드가 뒤집히는 순간. 티어별 연출 차등, T4는 전체 화면 연출.
2. **복귀 요약** — 아침에 돌아와 밤사이 로그를 읽는 순간. 손실을 숨기지 않는다.

**루프 실패 경보**: 분 스케일이 비면(드랍 간격 5분 초과) 방치형이 아니라 대기 화면이 된다.
초기 구간 드랍 간격은 40초를 넘기지 않는다.

## 7. 설계 리스크

### 7.1 문화재 약탈 서사 리스크 (가장 큰 것)

실존 유물을 "개인이 캐서 금고에 넣는" 구도는 반환 논쟁(엘긴 마블, 외규장각 의궤 등)과
정면으로 부딪친다. 웹툰 `도굴왕`의 흑화 서사를 그대로 가져오면 리스크가 커진다.

**완화 설계**
- 최종 목표를 개인 금고가 아니라 **박물관 설립·공개 전시**로 둔다(프레스티지 = 헌정).
- 유물 카드에 **실제 현 소장처를 사실대로 표기**한다. 반환 논쟁 유물은 논쟁 사실을 병기.
- 용어를 '도굴'이 아니라 '발굴·수집'으로 통일한다.

### 7.2 평가액의 사실성

실존 유물의 시장가는 대부분 비공개이거나 거래 자체가 불가능하다. 게임 내 평가액은
**가상 단위(₩)이며 실제 감정가가 아님**을 도감 하단에 상시 표기한다.

### 7.3 라이벌 고무줄의 양면

추격 계수는 독주를 막지만 "내가 뭘 해도 따라온다"는 무력감을 만들 수 있다.
계수 상한을 두고(최대 ×2.0), 수치를 UI에 노출해 납득 가능하게 만든다.

### 7.4 도트 에셋 생산량

유물 60~120점의 도트 스프라이트를 손으로 찍는 건 비현실적이다.
외부 이미지 파이프라인은 이 환경에서 **네트워크가 차단되어 불가**(박물관 오픈액세스 API 403 확인).
→ **절차적 도트 생성**으로 간다. 형태·팔레트·시드를 데이터로 주면 생성기가 32×32를 굽는다.
트레이드오프: 실물 재현도는 낮다. 실존성은 **이름·연대·소장처·내력 텍스트**가 담보한다.

## 8. 디자인 인사이트

1. **현실의 희소성을 게임의 희소성으로 그대로 쓴다.** 로제타 석은 1점, 데나리우스는 수만 점 —
   이 사실 자체가 티어 테이블이다. 밸런스를 위해 지어낸 등급이 아니라서 설득력이 공짜로 따라온다.
2. **깊이 = 연대.** 지층을 파내려간다는 도트 화면 하나가 진척 시각화와 시대 구분을 동시에 해결한다.
   방치형의 우상향을 숫자가 아니라 그림으로 보여주는 지점이다.
3. **방치형에 긴장을 넣는 유일한 방법은 "지금 아니면 안 되는 것"을 만드는 것**인데,
   유일 유물 레이스가 그 역할을 한다. 스태미나나 일일 퀘스트 같은 외부 압박이 필요 없다.
4. **점수와 자원을 같은 물건으로 만들면 방치형의 단조로움이 깨진다.** 팔면 빨라지고 순위는 내려간다.
5. **`바나나`에서 가져올 것은 클릭이 아니라 "드랍 풀에서 빠지면 공급이 고정된다"는 구조**다.
   클릭은 껍데기였고, 가격을 만든 건 discontinued 처리였다.
6. **`도굴왕`에서 가져올 것은 먼치킨 서사가 아니라 정보 우위**다. 제보 = 회귀자의 사전 지식.
7. **영구 상실은 플레이어가 그 자리에 있었을 때만 일어나야 한다.** 자는 동안 빼앗기는 설계는
   FOMO가 아니라 원한을 만든다.
8. **Mastery가 낮은 것은 이 장르에서 결함이 아니다.** 손기술 요구를 끼워 넣으려는 유혹을 거부한다.
