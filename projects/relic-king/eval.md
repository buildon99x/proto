# Evaluation — 유물왕

> v0.1 구현이 "된다"를 증명하는 체크 목록. 설계 단계인 현재는 **미실행 상태**이며,
> 구현과 함께 자동 검증부터 채운다.

## 1. 자동 검증

- [ ] `pnpm --filter relic-king build` — 타입체크 + Vite 빌드 무오류.
- [ ] `pnpm playtest --project relic-king` — 헤드리스로 첫 실행 → 첫 드랍 → 감정 →
      매각 → 업그레이드까지 자동 진행. page/console 에러 0.
- [ ] **오프라인 적분 일치**: 12시간을 1초 틱으로 돌린 결과와 오프라인 적분 결과의
      자산 차이가 1% 이내 (효율 60% 적용 후).
- [ ] **세계 원장 보존**: 임의 시뮬 10,000틱 후 모든 유물의
      `획득 수량 합(플레이어+라이벌) + 잔여 == 총량`. T4는 어떤 경우에도 2개가 존재하지 않는다.
- [ ] **세이브 왕복**: export → 초기화 → import 후 상태 완전 일치.
- [ ] **마이그레이션**: v1 세이브가 이후 스키마에서 손실 없이 열린다.

## 2. 밸런스 검증 (헤드리스 시뮬)

클릭 0회, 방치만으로 돌린 기준선.

- [ ] 첫 유물 드랍까지 **40초 이내**.
- [ ] 초기 20분 구간 평균 드랍 간격 **5분 이하** (루프 실패 경보선).
- [ ] 2번째 권역(이집트) 해금까지 **90분 이내**.
- [ ] 도감 80% + 자산 1위까지 **20~40시간** 범위.
- [ ] 클릭 최대 활용 시 진행이 방치 대비 **1.6배를 넘지 않는다** (클릭 노동 방지).
- [ ] 추격 계수 상한 ×2.0에서 라이벌이 플레이어를 **영구 추월하지 못한다**.

## 3. 상실 규칙 검증 (설계 원칙의 방어선)

- [ ] 오프라인 24시간 시뮬 100회에서 **T3·T4 상실 0건**.
- [ ] 제보 레이스에서 플레이어가 대응했을 때 승률이 **대응하지 않았을 때보다 유의하게 높다**.
- [ ] 제보를 전부 무시해도 도감 T0~T2는 완주 가능하다 (제보는 보너스이지 진행 조건이 아니다).

## 4. 데이터 검증 (실존성)

전제가 "실존 유물"이므로 이 항목이 틀리면 게임의 근거가 무너진다.
[notes/artifacts-dataset.md](notes/artifacts-dataset.md)의 초안을 1차 자료로 확인한다.

- [ ] 모든 유물의 `holder`(현 소장처)를 소장 기관 공식 자료로 확인.
- [ ] **T4 8점 전부**가 실제로 단일 개체인지 확인. 의심되면 하위 티어로 내린다.
      (알려진 쟁점: 훈민정음 해례본 — 상주본 존재)
- [ ] 반환 논쟁이 있는 유물에 `disputed` 표기.
- [ ] 연대와 권역·층 구성이 어긋나는 항목 0건.
- [ ] 도감 하단에 "평가액은 가상 단위" 문구 상시 노출.

## 5. 수동 체크리스트

- [ ] 방치만으로 진행되고, 클릭은 가속으로만 작동한다.
- [ ] 지층 단면이 진척에 따라 내려가고 층 경계에 연대가 표시된다.
- [ ] 감정 카드 뒤집기 연출이 티어별로 다르고, T4는 전체 화면 연출이 나온다.
- [ ] 유물을 팔면 자금이 오르고 **순위가 내려간다**.
- [ ] 제보 배너가 카운트다운과 함께 뜨고, 이동 버튼이 해당 권역·층으로 보낸다.
- [ ] 레이스에서 지면 도감에 회색 칸 + 소유자 이름이 남는다.
- [ ] 복귀 요약이 라이벌 활동을 포함해 손실을 숨기지 않고 보고한다.
- [ ] 규칙 화면에서 확률표·라이벌 발굴력·추격 계수 공식을 볼 수 있다.
- [ ] 모바일 4탭에서 전 기능에 도달하고, 지층 화면이 세로에서 깨지지 않는다.
- [ ] 티어를 색만으로 구분하지 않는다(테두리 두께·배지 병행).

## 6. 재미 가설 검증 (플레이테스트)

설계가 목표한 세 문장이 실제로 발생하는지 본다.

- [ ] **"하나뿐인 걸 가졌다"** — T4 획득 직후 소장고·도감을 다시 여는 행동이 관찰되는가.
- [ ] **"조금만 늦었으면"** — 제보 배너가 뜨면 방치 상태를 깨고 개입하는가.
      개입률이 30% 미만이면 제보 설계가 실패한 것이다.
- [ ] **"진짜 있는 물건이라고?"** — 유물 내력 텍스트를 끝까지 읽는가.
      즉시 닫는 비율이 높으면 내력을 감정 연출에 더 묶어야 한다.
- [ ] **매각 딜레마가 작동하는가** — 팔지 말지 망설이는 순간이 세션당 1회 이상 나오는가.
      항상 즉시 판다면 자산 점수의 무게가 부족한 것이다.

## 7. 알려진 한계

- 라이벌은 NPC 시뮬이다. 실제 비동기 경쟁이 아니므로 "사람과 겨룬다"는 감각은 약하다.
- v0.3(거래) 이전까지 영구 상실은 회복 경로가 없다. 그래서 상실 빈도를 보수적으로 잡았다.
- 도트 스프라이트는 절차 생성이라 실물 재현도가 낮다. 실존성은 텍스트가 담보한다.
