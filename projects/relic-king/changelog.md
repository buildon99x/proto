# Changelog

## 0.2.0

v0.1 이후 최대 개편 — 세계지도·발굴단·시설·시장을 갖춘 3축 순위 방치형으로 확장했다.
5단계에 걸친 구현(`prompts/v0.2-deepening.md`)과 마무리 패스, 이번 결함 수정
패스를 하나로 묶는다. 자세한 판단 근거는 `notes/decisions.md` G51~G57.

- **엔진 코어**: 드랍 간격 하한 + 티어 재역산, 자동매각 개정(T2+ 예외·종당 1점
  보존), 3축 순위(자산·도감·명성) 공식, 세이브 v2, 시즌 롤오버.
- **세계지도·거점·원정**: 12거점(한반도·이집트·로마·그리스·튀르키예·이스라엘·
  인도·중국·이라크·일본·멕시코·페루) 실제 위경도 지도, 거리·이동시간 기반 원정
  회차제(파견→이동→현지작업→귀환, 미스헵·후불 원정비), 발굴단 다중화(최대
  4팀)·자동 재파견 루틴, 스텝 3직군(단장·관장·경매관장), 거점별 시세.
- **유물 데이터·제보·라이벌**: 280종(검증 182종) 12거점 전부에 유일(T4) 확보,
  제보 배너-레이스 분리 재설계([집중 굴착]·[급파]), 라이벌도 원정비·급여
  원천징수 + 오프라인 고티어 차단.
- **시설과 시장**: 감정소 3축(감정량·속도·해금 티어) 배선, 보관소(습도·복원·
  보안), 박물관(전시·관람수입 30% 캡), 경매장, 암시장(미감정 매입·장물),
  도난(72시간 회수기간, 온라인 경과시간 기준).
- **UI 전면 재편**: 5탭(발굴/소장고/시설/시장/도감) + 헤더 상시 아이콘 2개
  (⚙ 설정·세이브, 📋 규칙), 온보딩("본거지를 정하자"), 세계지도 React 배선,
  알림 3계층, 복귀 요약, 모바일 375px 레이아웃.
- **마무리 패스**: `checkEnding()`을 v0.2 정의(RANK_SCORE 종합 1위 + 도감
  75% 1시간 연속 유지)로 교체, 명성 축 박물관 관람객 카운터, 시즌 롤오버
  실제 발동, `CODEX_SCORE` 분모 버그(480→검증 종수)·원정비 과청구 버그
  수정 — 클릭 0회로 **226시간 32분**에 실제 엔딩 도달을 확인했다.
- **결함 수정 패스(사람 스크린샷 육안 검수)**:
  - **[치명] 기본 상태 방치 교착 수정** — 자동매각 기본값 켬(희귀 이하),
    미감정 큐 오버플로 자동 처분(`pendingCap` 초과분만, T0·T1 한정),
    인부·장비·감정소 자동 재투자 신설. 감정비를 못 내 감정이 막히고
    자금이 안 돌아 인부도 못 사던 완전 교착을 닫았다 — 8시간 방치 후
    발굴력이 1.0/s에서 208.4/s로, 미감정 큐가 무한정 쌓이던 것에서
    `pendingCap` 언저리로 안정됐다(실측, `eval.md` §16.1). 클릭 0회
    엔딩은 239시간 8분으로 재확인(이전 226시간 32분과 같은 자릿수).
  - 스모크 테스트가 온보딩 모달을 못 닫아 시설·시장·도감 스크린샷이
    전부 오버레이만 찍히던 문제를 고치고, 모바일 375px 스크린샷 3장을
    새로 추가했다.
  - 세계지도 거점 라벨 충돌 회피(그리디 배치 + 리더선 + 줌 단계별
    우선순위)와 대륙 실루엣 도트(외부 리소스 없이, 기존 40색 팔레트
    안에서만)를 추가해 유럽·중동 밀집 구간의 라벨 겹침을 없앴다.

## 0.1.1

- 소장고 화면을 좌우 두 열로 나눈다. 미감정 항목이 생기고 사라질 때마다 아래 소장고가
  밀려서 버튼을 겨냥할 수 없던 문제. 미감정 목록에도 고정 높이를 줬다.
- 소장고를 유물 종류로 묶고 수량 배지를 단다. 낱개 최신순 격자는 새 유물이 들어올 때마다
  칸이 한 자리씩 밀려 같은 문제가 격자 안에서 다시 생겼다. 매각은 1점/전부로 나눴다.
- 한글 조사를 받침에 맞춰 고른다. "L. 로시이(가) '신라 금관'을(를)" → "L. 로시가 '신라 금관'을".
- 스모크에 회귀 검사 두 개 추가: 8시간 오프라인 후 소장고 칸이 움직이지 않는지,
  화면에 조사 병기가 남아 있지 않은지. 오프라인 되감기는 페이지를 떠난 뒤에 해야 한다 —
  `beforeunload` 세이브가 덮어쓴다(리로드로 오프라인 시간을 위조하지 못하게 하는 정상 동작).

## 0.1.0

플레이 가능한 첫 빌드.

- 설계 문서: MDA 설계, 코어 루프, 재미 정의, UX 정의, 유물 데이터셋 규격.
- 엔진: 굴착·드랍·세계 원장·감정·매각·라이벌 6인·제보 레이스·오프라인 진척·세이브.
- 유물 60점(유일 8, 국보 6, 진귀 12, 희귀 15, 흔함 19). 현존 개체 수를 티어로 쓴다.
- 도트 렌더: 절차적 32×32 유물 스프라이트, 지층 단면 캔버스(240×360).
- UI: 발굴·소장고·세계·도감 4탭, 제보 배너, 감정 공개 연출, 복귀 요약, 규칙 공개 화면.
- 검증: 헤드리스 밸런스 시뮬(`sim`)과 CDP 기반 실시간 스모크(`smoke`).
  방치만으로 엔딩까지 약 1시간, 원장 보존·오프라인 적분·클릭 상한 모두 통과.

밸런스 조정 과정에서 드러난 것들
- 깊이와 발굴력이 둘 다 수입을 곱하면 20분 만에 발굴력이 194만/s로 폭주했다.
  드랍 임계를 층 기대 평가액에 묶어 **깊이가 돈을 벌어 주지 않게** 바꿨다.
- 감정을 순차 처리로 두자 감정소가 드랍 속도의 병목이 되어 소장고가 텅 빈 채
  전량 자동 처분됐다. 병렬 처리로 바꿨다.
- 시작 자금이 0이라 첫 유물의 감정비(추정가 2%)를 못 내 첫 1분이 죽어 있었다. 3만 ₩을 쥐여 준다.
