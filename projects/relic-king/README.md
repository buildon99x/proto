# 유물왕 (relic-king)

Prototype Lab 신규 프로젝트. **작업 대기 상태**로, 현재는 템플릿 스캐폴드만 있다.

- 슬러그: `relic-king` (레지스트리 id는 kebab-case ASCII만 허용해 한글 이름과 별도로 둔다)
- 상태: `idea` — 기획 확정 전이라 구현물이 없다.
- 실행: `pnpm --filter relic-king dev`
- 빌드: `pnpm --filter relic-king build`

## 다음 단계

레포 규칙상 구현 전에 `brief.md`, `spec.md`, `eval.md`를 먼저 채워야 한다.
기획이 정해지면 이 세 문서를 갱신하고, 그다음 `app/`에 손을 댄다.
