## 해석

프로젝트 자리(스캐폴드와 레지스트리 등록)만 먼저 만들고, 게임·앱 내용 구현은
후속 지시를 기다린다. 컨셉·장르·메커닉에 대한 지시가 없었으므로 문서에 임의로
설정을 채우지 않았다.

## 이 커밋에서 한 일

- `pnpm create:project -- --name "Relic King"`로 Vite React 템플릿 복사
- 표시 이름을 `유물왕`으로, 상태를 `idea`로 조정 (id는 ASCII 제약 때문에 `relic-king`)
- `brief.md` / `spec.md` / `eval.md`는 대기 표식만 남기고 비워 둠
- `pnpm sync:registry`로 런처 레지스트리 반영

## 대기 중인 입력

1. 장르와 코어 루프 — "유물왕"이라는 이름 외에 정해진 것이 없다.
2. 대상 플랫폼/입력(데스크톱 마우스, 모바일 터치 등).
3. 레퍼런스 게임이나 참고 자료.
