## 설계에서 내린 주요 결정

1. **현실의 현존 개체 수 = 게임 공급량.** 등급을 지어내지 않는다. 신라 금관 6점, 로제타 석 1점.
2. **깊이 = 연대.** 지층 단면을 파내려가는 화면 하나로 진척 시각화와 시대 구분을 동시에 한다.
3. **점수(소장 자산)와 자원(자금)을 같은 물건으로 묶는다.** 팔면 빨라지고 순위는 내려간다.
4. **영구 상실은 플레이어가 그 자리에 있었을 때만.** 오프라인 중 T3·T4는 소실되지 않는다.
5. **거래(v0.3)는 영구 상실의 유일한 회복 경로**다. 후순위지만 없으면 상실이 출구 없는 좌절이 된다.
6. **도트는 절차 생성.** 외부 네트워크 차단 확인(박물관 오픈액세스 API 403) → 이미지 파이프라인 불가.
