# v0.6.6 작업 지시 — 결정 트리 패스 (첫 10분·첫 1시간)

- 일자: 2026-09-24 · 대상: v0.6.5
- 근거: `notes/decision-tree-10h.md`(§0 결론, §5 실측, §6 개선안). 먼저 읽는다.
- 성격: **결정의 질을 고친다.** 무거운 결정은 보이게, 지배 전략은 자동으로, 시간은 고르게.
  새 시스템은 만들지 않는다. 척추 5개와 환경 제약(`AGENTS.md`)은 그대로다.

## 반영 항목

1. **버그 2건.** ① [집중 굴착]·[급파] 원정비 배수가 누를 때마다 곱해진다(`engine.ts` `focusDig`·
   `emergencyDispatch`의 `costMult *=`). 원정당 한 번, 최대 ×2·×3으로 묶는다. ② 원정비 정산에
   하한이 없어 자금이 음수로 무너진다. 정산액은 보유 자금을 넘지 않는다.
2. **첫 유일 제보를 놓칠 수 없게.** 유일 제보는 화면 전체 알림 + Web Audio 합성음(외부 리소스 0,
   `settings.muted` 존중). 같이 모바일(390px) 제보 배너 붕괴를 고친다.
3. **결정 계측을 버튼 기준으로.** `density` B축은 화면에 버튼이 실제로 뜨는 제보만 결정으로 센다.
   지배 전략·잡무는 결정 수에서 뺀다. 새 지표: 첫 10분·1시간 결정 수, 결정 간 최장 간격.
   `playlog`의 제보 창 통계(승 0/패 0/만료 N으로 찍히는 것)를 고친다.
4. **첫 10분 재배치.** 36초 본거지 모달을 없애고, 첫 거점 해금이 가능해지는 순간(약 3분)에
   카드 세 장으로 합친다. 카드에는 종 수·유일·홈 라이벌 수·거리·비용을 숫자로 적는다.
   제보가 결판나기 전에는 띄우지 않는다. 첫 진귀 입고 때 임시 전시대 안내를 한 번 띄운다.
5. **첫 1시간 재배치.** 발굴단 증강을 자동 재투자에 넣는다(G80.1). 박물관(첫 국보 무렵, 목표 15~25분)과
   경매장(첫 중복 배치 무렵, 목표 35~45분)이 한 틱에 같이 열리지 않게 첫 건립 시점을 떼어 놓는다.
6. **설계 판단 둘.** ① 진귀·국보 제보는 현지 팀이 있으면 자동 집중(`Tip.autoFocused`), 유일만 버튼.
   운영 기준선 정책은 유일 제보에 대응한다. ② 자동 매각 기본값은 12시드로 다시 재고 정한다.
