Heroes of Hammerwatch II
구현 비교와 검증 보고서

원작 위키와 공식 자료를 확인한 뒤 만든 독자적인 브라우저 액션 로그라이트입니다. 원작과 같은 완성도 또는 기능 동일성을 달성했다고 평가할 수는 없습니다.

중요: 실제 플레이 검증은 차단되어 미완료입니다.
클라우드 미리보기는 502 연결 오류를 반환했고, 서버가 표시한 localhost 주소는 브라우저에서 명시적으로 차단되었습니다. 다른 경로로 제한을 우회하지 않았습니다. 아래 ‘구현’은 코드 및 제한된 자동 검사 상태이며, 실제 사용자 조작으로 검증되었다는 뜻이 아닙니다.

1. 원작에서 확인한 핵심

올바른 대상은 Heroes of Hammerwatch II 위키입니다. Hammerwatch II나 첫 Heroes of Hammerwatch의 위키와 구분했습니다. 공식 Steam 페이지와 개발사 사이트도 참고했습니다.

  • 영구 장비/캐릭터 성장과, 해당 원정에서만 유지되는 장신구·스킬 강화를 분리
  • 기본 7개 클래스, 클래스별 3개 전문화, 8개 환경, 4인 협동, New Game +
  • 길드 홀 등급으로 마을 건물·강화가 해금되며 목재·돌·철 등을 사용
  • 천둥새가 소지 자원의 절반을 마을로 운반. 장비와 경험치는 사망 후에도 유지
  • Forest/Caves부터 Dark Halls까지 6개 막과 서로 다른 보스 구조

사망 시 미운송 자원의 40% 손실은 출시 무렵 커뮤니티의 일관된 설명과 위키의 Chapel 손실 감소 효과를 근거로 채택했습니다. 현재 패치의 정확한 상수라고 단정하지 않습니다.

3. 화면 비교 기준

공식 숲 스크린샷의 실제 픽셀을 확인했습니다. 원작은 작은 캐릭터, 황토색 풀과 길, 침엽수/주황 단풍, 보라 회색 절벽, 촘촘한 식생, 화면 하단 금속 프레임 HUD를 사용합니다. 이번 구현은 독자적인 수목·타일·캐릭터·조명으로 해석했지만, 원작보다 지형과 스프라이트가 훨씬 단순합니다.

이번 빌드의 실제 브라우저 스크린샷은 확보하지 못했습니다. 생성 이미지나 코드 렌더링을 실제 플레이 화면처럼 제시하지 않습니다.

4. 실행한 검사

  • JavaScript 문법 검사 통과
  • 100개 씨드 × 6층 = 600개 맵의 12개 방 연결성 검사 통과
  • 7개 클래스, 18개 고유 장신구, 6개 건물 정의 검사 통과
  • 격리된 모의 DOM/Canvas에서 모든 클래스 스킬, 층별 렌더 함수, 장비, 보스 사망 후 처리 실행
  • 모의 런타임에서 저장/복구 및 사망60%·승리100% 정산 계산 확인
  • 재개 대기 중 안내/사운드 조작으로 저장이 지워지는 문제 수정
  • 초반 상자에서 목재와 돌을 모두 얻도록 수정하여 첫 마을 강화 경로 확보

5. 아직 필요한 실제 플레이 검사

  1. 새 게임 → 이동·조준·전투·회피·스킬·포션
  2. 상자·전리품·장비 장착·3택1 장신구
  3. 운송 → 사망 → 자원 정산 → 마을 강화 → 재도전
  4. 보스3종·최종 승리·NG+를 상태 주입 없이 완주
  5. 원정 중 새로고침·재개·브라우저 재실행 저장
  6. 터치·작은 화면·실제 프레임 성능·장시간 안정성
