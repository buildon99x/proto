# 햇살냥 0.2 직접 요청 구현 범위와 호스팅 제안

## 유지할 것
현재 따뜻한 크림·원목·세이지 색감의 3D 카페, 창가·테이블·소파·캣타워, PC/모바일 조작, 방 3개와 권장50명/최대100명, 서버 권위 상호작용을 유지합니다. 참고 이미지의 흰색 배경 공간·문구·그림 파일을 복사하거나 기존 카페를 교체하지 않습니다.

## 고양이
제공한 세 이미지를 직접 확인했습니다. 통통하고 낮은 몸, 큰 둥근 머리, 아주 짧은 다리, 삼각 귀, 작은 점눈과 w형 입, 부드러운 크림/삼색/회색 줄무늬/치즈/푸른 회색 등 털무늬를 원본 절차적 3D 모델에 적용합니다. 진한 얇은 실루엣과 단순한 얼굴로 읽기 쉽게 하며 고양이별 색·무늬 차이를 살립니다. 쓰다듬기·깃털·공 반응과 군중 렌더링 예산은 유지합니다.

## 넓이 정확히 두 배
바닥26×26을 (26√2)×(26√2), 약36.77×36.77로 확대합니다. 676→1352 제곱단위로 정확히2배이며 각 축2배(면적4배)가 아닙니다. 실제 이동 영역24×24도 각 축√2로 확대합니다. 가구/고양이/방문객 자체 크기는 유지하고 가구 위치·벽·창·서버 충돌영역을 같은 공통 공간 설정으로 조정합니다. 시점·줌 범위는 넓어진 공간에 맞추되 기존 분위기를 유지합니다.

## 일반 방문자 흐름
링크 열기 → 방 선택(혼잡도/빈자리) → 입장. 서버 주소 입력은 없앱니다. 앱이 배포 설정 또는 같은 출처의 /ws를 사용합니다. 방 이동·나가기·재입장과 짧은 연결 끊김의 자동 재접속을 지원합니다. 만석이면 다른 방을 안내하고, 서버 장애라면 간단한 재시도 안내를 표시합니다. 실제 연결 없는 상태를 온라인처럼 꾸미지 않습니다. 가입·결제·채팅은 추가하지 않습니다.

## 공개 실시간 운영 방식
**권장: 지속 실행 Node/ws 서버 유지.** 기존 검증된 서버를 승인된 상시 호스트에 배치하고 HTTPS/WSS·정확한 출처 허용·자동 재시작·상태 점검을 적용합니다. 기존 Vercel 화면에 WSS 주소를 자동 설정하거나, 같은 호스트에서 정적 화면과 /ws를 함께 제공하여 방문자는 링크 하나만 사용합니다. 기존 호스트가 있으면 우선 사용합니다.

대안: Vercel Functions WebSocket + 외부 공유 저장소. 현재 Vercel은 WebSocket을 지원하지만 같은 방의 접속이 다른 함수 인스턴스로 갈 수 있고 함수 시간 제한으로 연결이 종료됩니다. 따라서 현재 메모리 World를 그대로 올리지 않고 원자적 방 소유권/임대·fencing, 입력/스냅샷·재접속 상태 공유를 구현해야 합니다. 기능은 가능하지만 이번 게임에는 변경·운영 복잡도가 더 큽니다. Vercel Daemons의 현재 beta는 background용·production전용으로 별도 검토 없이 대체 호스트로 간주하지 않습니다.

## 공개 비용·안전 기준
기존300소켓 테스트의 합산 송신약21.6MiB/s는 공개 운영에 큽니다. 공개 전에 최초 전체 스냅샷 이후 변경분 전송, 반복 이름/색 메타데이터 분리, 먼 방문객의 낮은 갱신 빈도와 보간, 유휴 상태 전송 감소를 적용하고 동일20Hz 입력 부하로 비교 측정합니다. 모든 방문객 위치는 표시하며 인원을 숨기지 않습니다. 접속/메시지 속도 제한, 누락/허용되지 않은 Origin 거부, 재접속 예약·정원·느린 연결 보호, 서버 재시작 복구/명확한 재입장 안내를 검증합니다.

## 현재 차단 사항과 승인 범위
공개 방문은 요청받았지만 사용 가능한 상시 호스트·프로젝트 관리 권한·공유 저장소·비용 한도는 아직 확인 중입니다. 새 유료 서비스 가입/결제/자격증명 생성은 하지 않습니다. 고양이/공간/주소 없는 입장은 사용자의 직접 요청에 따라 구현합니다. 공개 서버 운영 방식과 신규 비용 승인은 이 문서로 확정되지 않습니다. 호스트/비용이 확정되기 전 공개 실시간 연결 완료를 약속하지 않습니다. 기존 main 병합·다른 프로젝트 변경은 포함하지 않습니다.

## 검증
- 면적2배 수치, 서버/화면 경계·충돌 일치, PC/터치, 방 이동/만석/재접속 회귀 테스트.
- 독립 브라우저 두 개와 다른 네트워크에서 실제 공유 고양이 상태·상호작용 확인.
- 3×100 합성 소켓,20Hz 입력, 전송량·실제 틱 간격·지연·메모리 기록; 사람300명 품질과 구분.
- WebGL 가능한 환경에서 참고 느낌·실제3D·모바일 조작/시각 검증. 현재 dot의 WebGL 비활성화 한계를 통과로 처리하지 않습니다.
