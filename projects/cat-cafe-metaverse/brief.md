# 햇살냥 고양이 카페 / CatCafeMetaverse
A welcoming original low-poly 3D space where visitors share a café and play with cats. User requested this new project in proto, desktop and mobile touch, multiple rooms and 50–100 visitors per room. On 2026-10-31 the user explicitly approved a separate persistent server for this project only. No paid hosting, account setup, main merge or live public room service is included.

Initial scope: three themed rooms, recommended 50 / hard capacity 100, authoritative visitors and cat play, pet/feather/ball, reconnect, accessible connection status, actual OhMyGame existing-folder integration. Eighteen cats per room (six markings) reduce contention. No chat/accounts/payments/UGC.
