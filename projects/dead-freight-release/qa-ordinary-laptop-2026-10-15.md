# Dead Freight — 노트북 일반 입력 검증 (2026-10-15)

Canal Ward에서 **상태 주입 없이 이동→전투→수집→탈출→재출격**을 완료했다. 같은 테스트 브라우저의 실제 종료·재실행, 중단 원정 복구, 자연 피격 사망→재출격도 확인했다. 실제 청음은 미검증이다.

## 실행과 증거의 구분

설치된 Chrome 150.0.7871.127의 Puppeteer 자동 입력 경로와 실제 WebGL 렌더링을 사용했다. 저장소 playtest-capture 방식의 독립 테스트 브라우저이며 보안 설정·샌드박스 플래그를 바꾸지 않았다. 기존 CUA는 0x80070003으로 동작하지 않는다.

새 `local-qa` 프로필에서 시작했다. 게임·카메라 객체 참조를 노출하는 관찰용 생성자/렌더 래퍼를 사용해 현재 위치·적·카메라 각도를 읽었다. 게임플레이 상태·체력·적·아이템·현금·저장 데이터를 직접 변경하지 않았고, 순간이동·처치 함수·데미지 함수·적 비활성화·저장 데이터 주입을 사용하지 않았다. 모든 행동은 실제 페이지 버튼과 키보드 입력이었다. 이는 자동 플레이 증거이며 사람의 마우스 조작감 합격은 아니다.

이전 `qa-laptop-2026-10-15.md`의 조건 준비용 테스트와 이번 일반 입력 테스트는 별개다. 이전 제작·수리 UI 검증은 여전히 준비된 재료·잔액을 사용한 테스트이며, 이번 원정에서 얻은 재료로 제작까지 이어간 것은 아니다.

3. 낮은 다리로 운하 횡단, 동쪽 강변을 따라 펌프까지 이동.
4. 펌프 표적을 포함한 적7명 처치, 총78발·명중52회. 실제 피격으로 체력89.92·방탄복26.28이 됨.

8. 발사 없이 시장으로 걸어 들어가 실제 적 투사체에 피격. 방탄복0·체력0이 되어 사망하고 Start로 재출격. 사망 후에도 보관함은 앞선 탈출 기록과 동일하고 현금1170 유지. 최종 기록은 성공1회·실패2회(중단 복구와 실제 사망)이며 다음 원정이 활성화됨.

## 발견 및 수정

일반 플레이 화면에서 Canal Ward의 방향 HUD가 `중계소 계약`, 원정 안내가 숲의 `6초` 탈출로 표시됐다. 현재 원정 지역에 따라 `펌프 계약`, `동쪽 페리: 아카이브+증표8초 / 서쪽 윈치: 증표12초`로 바꿨다. 일시정지 중 다음 지역을 바꿔도 활성 원정의 안내는 유지한다. 기존 지역 회귀검사와 실제 수정 후 브라우저 화면으로 확인했다. 전투·맵·보상·저장 규칙은 변경하지 않았다.

## 화면·자동검사·청음의 경계

일반 플레이와 실제 종료·재실행에서 얻은 PNG10장을 보관했다. 시장 회수, 펌프 전투 후, 탈출 결과, 재출격, 중단 복구, 수정 안내/HUD, 자연 사망·재진입 화면을 직접 열어 검수했다. 화면은 실제 렌더 결과이며 정적 목업이 아니다.

청음 도구가 없어 실제 출력의 음질·동기·밸런스를 확인하지 못했다. 파형 검사로 청음 통과를 대신하지 않았다. 전경 상대 마우스 느낌, 입력 지연·성능, Black Pines 일반 완주, Canal 서쪽 윈치 탈출, 모든 난이도·장비 조합, 동시 탭 경합은 이번 통과 범위에 포함하지 않는다. 액체 금속 AI는 기존 지시대로 dot 구현·노트북 테스트의 후속 단계로 유지한다. main 병합·공개 기본 배포는 하지 않았다.
