# Browser evidence runners

These scripts record laptop QA, not application implementation. Run from a workspace containing the tested checkout named `dead-freight-silt-qa`, with installed Chrome at the recorded Windows path. Set `DF_QA_PUPPETEER` to a local puppeteer-core module path, or use the workspace's isolated `qa-tools/node_modules/puppeteer-core`. No browser security flags are used. Each runner serves only the checkout's built static app on its own loopback port and uses a fresh temporary browser profile.

`normal-2` is the successful ordinary SILT encounter. `fixtures-2` contains successful penetration/aperture/reward checks and a deliberately retained failed cover-placement assertion; `fixture-cover` is the corrected explicit fixture. `regression-canal`, `regression-forest`, and the final west runner use ordinary input. `lifecycle` explicitly seeds damage, placement and workshop inventory; its individual checks disclose this setup. Video review decodes the original silent canvas WebM at normal speed.

Scripts retain their capture paths and observer code for reproducibility. Failed attempt evidence is retained and must not be reported as successful QA. File names containing `normal` in fixture folders are historical helper naming, not a claim that their setup was ordinary gameplay.
