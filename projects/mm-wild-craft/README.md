# Wild & Craft

작은 몬스터 친구들과 탐험하고 함께 캠프를 키우는 브라우저 솔로 게임. 탐험 → 전투·포획 → 작업 배치 → 자동 생산·운반 → 제작 → 보스의 한 세션 순환을 구현합니다.

## 실행
저장소 루트: `pnpm --filter mm-wild-craft dev`, `pnpm --filter mm-wild-craft test`, `pnpm --filter mm-wild-craft build`.
app 디렉터리에서는 `npm run dev`, `npm run lint`, `npm test`, `npm run build`도 지원합니다.

키: A/D 또는 방향키 이동, Space 점프, E 채집, J 공격, Q 브레이크, F 포획, R 동행, H 회복, B 캠프, T 제작, M 도감, I 가방, Esc 닫기/휴식. 터치 이동/점프 및 행동 버튼도 제공합니다.

목재를 모아 목검을 만들고 첫 슬라임을 포획하세요. 캠프로 귀환해 보관함에 배치하면 실제 목재를 운반합니다. 두 번째 종류를 만나 생산 시설을 열고, 장비를 강화해 숲 끝의 수호자에게 도전하세요.

진행은 현재 브라우저에 로컬 저장됩니다. 설정에서 내보낸 파일로 따로 보관할 수 있습니다. 손상된 저장은 자동으로 덮어쓰지 않습니다. MSW 서버 연동, 멀티플레이, 오프라인 생산은 포함하지 않습니다.

## 재구성과 원문
2026-10-06 클라우드 환경 교체 후 사라진 작업본을 이전 코드·수정 기록에서 재구성했습니다. 종전 빌드와 바이트 동일하다고 주장하지 않습니다. 원문 설계서와 응답은 원래 SHA와 일치하게 복구해 보관합니다. 공개 저장소에는 원시 HTML/게시물 JSON/내부 인용 메타데이터/비공개 미리보기 설정을 포함하지 않습니다. 공개 참고 링크는 data/source/web-references.json에 정리했습니다. `python3 projects/mm-wild-craft/tests/smoke/verify-source.py`로 검증합니다.

검증 현황은 eval.md에 기록합니다. 사용자 승인된 비공개 테스트 사이트에는 app/dist 게임 빌드만 업로드하며 저장소와 원문은 포함하지 않습니다.
