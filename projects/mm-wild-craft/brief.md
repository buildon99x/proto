# Wild & Craft
Korean solo browser game following the archived design's exploration → combat → capture → camp workers → automation → crafting → stronger exploration loop. Six collectible species, one guardian, six facility types, fifteen recipes. Cozy original procedural art, clear keyboard/touch controls, local save and complete first-session tutorial.
