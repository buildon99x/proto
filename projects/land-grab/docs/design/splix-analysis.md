# splix.io 분석 — 무엇을 그대로 가져오고 무엇을 바꾸는가

조사일 2026-09-14. splix.io 본체는 사내 프록시에서 차단돼 접속하지 못했고,
공개된 게임 서버 소스(`jespertheend/splix`, MIT, `gameServer/src`)와
사용자가 제공한 플레이 스크린샷 4장, 그리고 2차 자료로 규칙을 확인했다.
"소스"는 서버 코드에서 직접 읽은 사실, "화면"은 스크린샷에서 관찰한 것,
"2차"는 위키·가이드 기반이라 오차 가능성이 있다.

구현은 규칙만 가져왔다. splix 코드를 옮겨 적지 않았고, 스킨·패턴·로고 등
브랜드 자산은 쓰지 않는다.

## 1. 확인된 수치

| 항목 | 값 | 출처 |
| --- | --- | --- |
| 이동 속도 | `0.006 타일/ms` = 초당 6칸 (한 칸 ≈ 166.7ms) | 소스 (`PLAYER_TRAVEL_SPEED`) |
| 시작 영토 | 반지름 2 → `5 × 5` | 소스 (`PLAYER_SPAWN_RADIUS`) |
| 기본 아레나 | `600 × 600`, 아레나 모드는 중앙에 `16 × 16` 구덩이 | 소스 (`Game.js`) |
| 보장 시야 | 플레이어 주변 20칸 사각형, 갱신 청크 5칸 | 소스 |
| 타일 값 | `-1` 경계, `0` 빈 땅, `1+` 플레이어 번호 | 소스 (`Arena.js`) |

## 2. 확인된 규칙

**사망 조건** (소스, `Player.js`)

1. 아레나 경계에 닿음 (`x <= 0`, `y <= 0`, `x >= width-1`, `y >= height-1`) 또는 구덩이 타일.
2. 자기 꼬리에 닿음 — 단 **방금 만든 마지막 두 칸은 제외**한다.
3. 다른 플레이어의 꼬리에 닿음.
4. 꼬리를 물고 있는 두 플레이어가 같은 칸에서 정면 충돌.

**사망 후** (소스): 소유 타일 전부 빈 땅으로, 꼬리 삭제. 체력·목숨 개념이 없다(2차).
영토 삭제는 "확정 사망" 타이머가 지난 뒤 한 번만 일어난다(지연 보정용).

**방향 전환** (소스)

- 180° 반대 방향 금지.
- 입력은 큐에 들어가 **칸 경계에서** 반영된다.
- **같은 좌표에서 방향 전환을 두 번 보낼 수 없다.** 한 칸에서는 먼저 누른 입력이 이긴다.

**스폰** (소스, `Game.js`): 무작위 위치를 뽑고 **가장 가까운 벽을 계산해 그 반대쪽을 향해** 출발시킨다.
아레나 모드에서는 구덩이를 피해 Y를 다시 뽑고, 정지 상태로 시작한다.

**점령** (소스, `arenaWorker/updateCapturedArea.js`) — 이 프로젝트에서 가장 중요한 이식 대상.

1. 플레이어 영토의 경계 상자를 **한 칸 넓혀** 그 안만 훑는다. 전체 맵을 훑지 않는다.
   한 칸을 넓히는 이유는 채우기의 출발점이 반드시 영토 바깥에 있어야 하기 때문이다.
2. 채우기는 넓힌 경계 상자의 **모서리에서 출발**한다. 내 영토와 이미 채워진 칸이 장벽이다.
3. **살아 있는 다른 플레이어의 상하좌우 칸을 출발점으로 추가한다.**
   즉 상대가 들어 있는 영역은 "바깥"이 되어 한 칸도 넘어오지 않는다.
   상대 주위를 크게 둘러싸는 것만으로 넓은 땅을 공짜로 먹던 구멍을 막는 규칙이다.
   상대가 내 영토 위에 서 있으면 네 방향이 다 막혀 아무 효과가 없다.
4. 끝까지 채워지지 않은 칸이 점령 대상이다. 서로 떨어진 조각도 자연히 처리된다.

**점령 영역 안의 남의 꼬리**는 그대로 남는다. 소유권만 바뀐다.

**안전지대의 한계** (2차): 자기 땅 위에 있어도 상대가 내 꼬리를 끊으면 죽는다.
일시정지 중에도 죽는다 — splix의 일시정지는 무적이 아니다.

## 3. 화면에서 읽은 것 (제공된 스크린샷 4장)

- 보드는 간격을 둔 **둥근 사각 타일**의 격자다. 평면 색칠이 아니다.
- 영토는 꽉 찬 색, **꼬리는 사선 빗금**이라 한눈에 구분된다. 둘을 같은 색으로 두되
  질감으로 나누는 방식이다.
- 머리는 한 칸보다 **큰 원**이고 진행 방향으로 살짝 튀어나온 꼬리 이음매가 있다.
- 점령은 즉시 칠해지지 않고 **삼각 쐐기가 번지듯** 채워진다.
- 사망은 영토가 **삼각 파편으로 부서지고**, 충돌 지점에서 **링 충격파**가 퍼진다.
  충격파 색은 죽인 쪽(붉은색)이다.

이 다섯 가지는 "무슨 일이 일어났는지"를 읽게 만드는 장치라 그대로 가져왔다.
색 팔레트와 스킨 무늬는 가져오지 않았다.

## 4. 그대로 이식한 것

초당 6칸, `5 × 5` 시작 영토, 가장 가까운 벽의 반대쪽으로 출발,
180° 금지, 칸 경계 입력 큐, **한 칸당 한 번만 방향 전환**,
"마지막 두 칸은 자기 꼬리로 치지 않음", 경계 상자를 한 칸 넓혀 채우기,
**상대 위치를 채우기의 출발점으로 추가**, 경계 충돌 사망,
정면 충돌 시 꼬리 보유자 사망, 사망 시 영토 전부 중립화,
땅 1점 + 킬 500점.

"마지막 두 칸 예외"와 "상대 위치가 출발점"은 사소해 보이지만 빠지면 규칙이 무너진다.
전자가 없으면 영토를 막 벗어난 순간 자기 꼬리에 걸려 죽고,
후자가 없으면 상대를 크게 둘러싸는 것이 최적 전략이 된다.

## 5. 이식하지 않은 것과 이유

| 항목 | splix | 여기 | 이유 |
| --- | --- | --- | --- |
| 맵 | `600 × 600` + 카메라 추적 + 미니맵 | `60 × 60` 고정, 한 화면 | 싱글 판이라 정보 은폐가 긴장이 아니라 답답함이 된다. 전체가 보이면 AI와의 영토 경쟁이 곧바로 읽힌다. |
| 판 길이 | 무제한(죽을 때까지) | 90초 | 프로토타입은 한 판이 끝나야 평가가 된다. |
| 목숨 | 없음, 즉사 후 재입장 | 플레이어 3개, AI 무한 | 즉사 후 리스폰만 있으면 90초 판에서 학습 기회가 없다. AI를 무한으로 두어야 남은 시간이 경쟁으로 남는다. |
| 상대 | 실시간 다수 인간 | AI 2~3명, 난이도 3단계 | 서버 없이 완결. |
| 지연 보정 | 600ms / 5칸 되돌리기 | 없음 | 로컬 시뮬레이션이라 되돌릴 대상이 없다. |
| 일시정지 | 무적 아님 | 완전 정지 | 싱글이라 악용 대상이 없다. |
| 꼬리 취소 | `arena` · `drawing` 모드 전용 | 없음 | 기본 모드에 없는 규칙이다. |
| 혼(Space) | 연출용 브로드캐스트 | 없음 | 신호를 보낼 상대가 없다. 차별화 안에서 다시 검토한다. |
| 스킨 | 색 13종 + 무늬 29종, 일부 유료 | 고정 4색 | 브랜드 자산이라 가져오지 않는다. |
