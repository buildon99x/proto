# splix.io 분석 — 무엇을 가져오고 무엇을 바꾸는가

조사일 2026-09-14. splix.io 본체는 사내 프록시에서 차단돼 접속하지 못했고,
공개된 게임 서버 소스(`jespertheend/splix`, `gameServer/src`)와 2차 자료로 규칙을 확인했다.
아래 "확인" 표시는 소스에서 직접 읽은 값이고, "2차"는 위키·가이드 기반이라 오차 가능성이 있다.

## 1. 확인된 수치

| 항목 | 값 | 출처 |
| --- | --- | --- |
| 이동 속도 | `0.006 타일/ms` = 초당 6칸 (한 칸 ≈ 166.7ms) | 확인 (`config.js` `PLAYER_TRAVEL_SPEED`) |
| 시작 영토 | 반지름 2 → `5 × 5` | 확인 (`PLAYER_SPAWN_RADIUS`) |
| 타일 값 | `-1` 경계, `0` 빈 땅, `1+` 플레이어 번호 | 확인 (`Arena.js`) |
| 보장 시야 | 플레이어 주변 20칸 사각형 | 확인 (`MIN_TILES_VIEWPORT_RECT_SIZE`) |
| 리더보드 갱신 | 3,000ms / 미니맵 부분 갱신 250ms | 확인 |
| 점수 | 땅 1칸 = 1점, 킬 1회 = 500점 | 2차 |
| 조작 | 방향키 · WASD · IJKL, `P` 일시정지, `O` 리더보드, `Space` 혼(연출) | 2차 |

## 2. 확인된 규칙

**사망 조건** (확인, `Player.js`)

1. 아레나 경계에 닿음 (`x <= 0`, `y <= 0`, `x >= width-1`, `y >= height-1`) 또는 구덩이 타일.
2. 자기 꼬리에 닿음 — 단 **방금 만든 마지막 두 칸은 제외**한다.
3. 다른 플레이어의 꼬리에 닿음.
4. 꼬리를 물고 있는 두 플레이어가 같은 칸에서 정면 충돌.

**사망 후** (확인): 소유 타일 전부 빈 땅으로, 꼬리 삭제. 체력·목숨 개념이 없다(2차).

**방향 전환** (확인): 180° 반대 방향 금지. 입력은 큐에 들어가 **칸 경계에서** 반영된다.

**점령** (확인, `Arena.js` + `arenaWorker/`):

- 꼬리 꼭짓점과 시작 영토로 **경계 상자(bounding box)** 를 만들어 그 안만 훑는다. 전체 맵을 훑지 않는다.
- 살아 있는 다른 플레이어의 **현재 위치는 채우기의 장벽**이 된다. 그 칸은 뺏기지 않는다.
- 점령 영역 안에 있던 남의 꼬리는 그대로 남는다.

**안전지대의 한계** (2차): 자기 땅 위에 있어도 상대가 내 꼬리를 끊으면 죽는다.
일시정지 중에도 죽는다 — splix의 일시정지는 무적이 아니다.

## 3. 이 프로토타입이 다르게 가는 지점

| 항목 | splix.io | 땅따먹기 | 이유 |
| --- | --- | --- | --- |
| 맵 | 거대한 아레나 + 따라다니는 카메라 + 미니맵 | `60 × 60` 고정, 한 화면에 전부 | 싱글 판이라 정보 은폐가 긴장이 아니라 답답함이 된다. 전체가 보이면 AI와의 영토 경쟁이 곧바로 읽힌다. |
| 판 길이 | 무제한(죽을 때까지) | 90초 | 프로토타입은 한 판이 끝나야 평가가 된다. |
| 목숨 | 없음, 즉사 후 재입장 | 플레이어 3개, AI 무한 | 즉사 후 리스폰만 있으면 90초 판에서 학습 기회가 없다. AI를 무한으로 두어야 남은 시간이 경쟁으로 남는다. |
| 상대 | 실시간 다수 인간 | AI 2~3명, 난이도 3단계 | 서버 없이 완결. |
| 일시정지 | 무적 아님 | 완전 정지 | 싱글이라 악용 대상이 없다. |
| 혼(Space) | 연출용 버스트 | 없음 | 상대에게 신호를 보낼 대상이 없다. |
| 조작 | 키보드 전용 | 키보드 + 스와이프 + 방향 패드 | 런처가 모바일에서도 열린다. |

## 4. 그대로 가져오는 것

초당 6칸, `5 × 5` 시작 영토, 180° 금지, 칸 경계 입력 큐,
"마지막 두 칸은 자기 꼬리로 치지 않음", 경계 충돌 사망,
정면 충돌 시 꼬리 보유자 사망, 점령 시 상대 위치를 장벽으로 취급,
경계 상자로 채우기 범위 한정, 땅 1점 + 킬 500점.

"마지막 두 칸 예외"는 사소해 보이지만 없으면 영토를 막 벗어난 순간 자기 꼬리에 걸려 죽는다.
"상대 위치가 장벽"도 마찬가지로, 없으면 상대를 영토 안에 가두는 순간 이상한 소유권이 생긴다.
