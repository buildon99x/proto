# Nintendo Switch Sports 배드민턴 기준:100점 루브릭

98점은 목표이며 현재 달성 판정이 아니다.20항목×5점.비주얼25/조작25/사운드15/UX15/경기20. 구현 전에 v1.0을 고정한다.

미검증은 null;0점과 구별. 확인항목 합계/확인가능배점과 미검증배점을 함께 표시하고100으로 환산하지 않는다. 모든 항목이 검증되기 전 종합점수·98점 달성 주장 금지. 자동검사는 별도 기술 게이트. 같은 문제3회 비개선이면 원인·대안 접근·다음 재평가를 기록하고 단순 매개변수 반복 중단.

평정0–5는 자동검사 통과율이 아니라 명시 조건에서의 관찰 평가다.단일 검토자 의견에는 보편적 사용자 경험/닌텐도 동등성이라는 의미가 없다.5점은 각 행의 추가조건까지 필요하다.

## 비교의 범위

Nintendo의 고유 캐릭터/로고/UI/사운드/배경은 복제하지 않는다.공식 문서가 밝힌 자동적인 간편 조작,샷 타이밍,스매시와드롭의 완급,높고 흔들리는 셔틀의 강한스매시 기회만 연구 근거로 삼는다.내부 AI·입력 허용창·물리 파라미터는 추정하지 않는다.

## 3회 정체 규칙

문제별 iteration ledger에 시도 번호/원인 가설/변경/동일 측정/점수/결과를 남긴다.점수 또는 주된 관찰 지표가3회 연속 나아지지 않으면,측정 오염·엔진 설정·아트 원본·인터랙션 설계 중 원인을 분해한다.다른 접근을 적용하고 새 증거로 평가한다.조건·가중치를 낮추거나 미검증 항목에 점수를 채워 목표에 도달하지 않는다.
