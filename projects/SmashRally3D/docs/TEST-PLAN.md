# Verification methods
- Unit tests cover solver strength/fallback, eligibility, contact phase/plane/approach, finite limbs, full-speed reversal feet, delayed noisy AI samples, point idempotence and winner-next-serve. Numerical1000 launches and ten domain games are simulations, not browser/human play.
- `visual-play.mjs`: ten active UI games, five EASY/five NORMAL. Controller uses visible HIT NOW and SUPER label, sends clear/drop/default throughout every match, and observes score/shot/foot geometry via read-only telemetry. It never reads internal contactAt for command scheduling. Records each match's shot sequence, input count, score, longest rally, software FPS/heap and global stance displacement. Full per-point command sequences were not logged; do not infer unrecorded tactical coverage.
- Stance metric compares rendered ankle positions only in continuous RALLY time (gap<120ms), same foot cycle, neither sample swinging, both hop<1mm. Point resets/jumps/new games are excluded. It measures rendered world-space ankle displacement, not just logical foot targets. Gate3mm. First candidate failed0.297m and is archived; fix is revalidated separately.
- `contact-gallery.mjs`: real mouse-generated impacts; query freezes the collision snapshot for geometry inspection. All five shots must come from legal natural rally geometry. Screenshot/paused mode is not counted as normal match gameplay.
- `mobile.mjs`: CDP tap/swipe at22px threshold before release, stable gesture-start target, pause and portrait/landscape. Emulation is not physical touch-latency/Safari proof.
- `recovery.mjs`: mute/FX settings, UI pause/resume and injected WebGL context loss/reload. Headless visibility behavior is disclosed separately from device lifecycle.
- `loss-rematch.mjs`: natural loss after withholding returns, visible losing result and PLAY AGAIN. This is lifecycle coverage, not tactical balance.
- Software Chromium151/Angle SwiftShader can run around10FPS here; never substitute these observations for PC60/mobile30 device targets. Offline WAV rendering/event scheduling are not hearing tests.
- Root release build: `corepack pnpm build:vercel`. Current branch Vercel status may be confirmed by GitHub; direct external execution/access level requires separate success.
