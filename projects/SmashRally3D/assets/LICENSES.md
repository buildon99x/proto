# Assets and dependencies
Original procedural court, character rig, racket, shuttle and motion authored for this project. Original synthesized Web Audio impacts; no sampled commercial audio. System fonts only. No Nintendo assets. PlayCanvas MIT; Vite MIT; TypeScript Apache-2.0; dependency licenses remain in installed packages. Original GLB models and nine animation clips are generated by tools/generate-assets.py and loaded by PlayCanvas container assets. Fixed-clock racket reach poses supplement GLB torso clips. All sources are committed.

0.2.0 athlete source: tools/generate-athletes.py plus original primitive author and src/motion-data.json. Seventeen weighted joints, nine full-body exported clips; no external mesh, mocap or texture. Runtime pose/IK is authored in src/motion.ts; no Nintendo extraction or commercial animation sampling.
